Тема:

«Модели и расход» — v3, три вкладки

Третья итерация: оптика v2 «приборная панель» (вердикт-полоса, KPI-лента, карточки квот, слоты как маршруты) сохранена, но структура собрана заново — три вкладки вместо шести: «Квоты и деньги · Модели по умолчанию · Применение». Пресеты растворены в слотах (цепочка правится прямо в раскрытом слоте), специальности уехали в свёрнутый блок «Исключения», диаграмма «Расход по дням» уступила место ссылке «Подробная аналитика →» (переедет в этап 2).
Все данные в примерах — живой снимок прода на 07.08.2026: три глобальных пресета «Основной — Сильный/Средняя/Слабая» по 5 шагов, личных пресетов нет; исключений 2 из 14 (Дизайнер — общая, Исполнитель — личная владельца); из 47 мест 10 на tier:medium, 37 — на бесплатных, tier:strong и tier:weak не назначены ни одному месту — макет показывает это честно, а не прячет. Плюс новые данные провайдеров: третье окно квоты GLM, счётчик сессий и уровень подписки Kimi, лимит ключа OpenRouter, подарочный остаток DeepSeek, здоровье FreeLLM.

2. Чем v3 отличается от v2

Оптика та же — «приборная панель» из v2. Поменялась структура и честность пустых мест.

Структура
Три вкладки вместо шести
«Квоты и деньги · Модели по умолчанию · Применение». Вкладки «Пресеты», «Специальности» и «В чате» удалены: первые две растворены в слотах и исключениях, третья слилась с «Применением». Меньше навигации — меньше мест, где настройка «прячется».
Пресеты
Растворены в слотах
Цепочка правится прямо внутри раскрытого слота: шаги двигаются ↑↓ и удаляются ✕. «Сохранить как пресет» появляется только когда цепочку изменили — пресет нужен, чтобы применить её во втором месте. Сами пресеты остаются в списках выбора модели.
Специальности
Свёрнутый блок «Исключения»
Внизу «Моделей по умолчанию»: пустое — «Исключений нет · настроить», текущее — «Исключения: 2». Раскрытие — та же матрица с фильтром «С настройками · 2» и сегментом «Для всех / Только для меня». Две настройки из четырнадцати не заслуживают вкладки.
Аналитика
Ссылка вместо диаграммы
Диаграмма «Расход по дням» уехала в «Подробную аналитику» (этап 2). На первой вкладке остаётся строка-переход — раздел отвечает на «всё ли в порядке», а не «как менялся расход».
Честность
Пустые слоты не прячутся
На проде tier:strong и tier:weak не назначены ни одному месту. Слоты показывают «0 мест · работает только через уровень у персон и задач» и подсказку-переход «Назначьте её исполнителю задач или сложным местам →» — пустота читается как состояние, а не как поломка.
Новые данные
Квоты стали богаче
До трёх окон на провайдера (GLM: 5ч / неделя / веб-поиск), счётчик параллельных сессий Kimi «занято 3 из 5» (снимок, не шкала), плашка «Подписка: Standard», лимит ключа OpenRouter «$2 из $10» с предупреждением, расход по периодам «по данным OpenRouter», подарочные $5 у DeepSeek, здоровье FreeLLM — в KPI-ленту.

5. Спецификация для реализации

Для Киры: что берётся из системы как есть, что нового, какие данные нужны от бэкенда.

Каркас и токены
  • Модалка — штатная: MODAL_W.wide = 720, R.modal = 20, SHADOW.modal, фон C.bgMain. На мобиле — шторка с грабом.
  • Новых токенов нет. Счётчик сессий — сегменты на C.track / заполненные C.info; скелетон — C.bgSelected + пульс (выключается prefers-reduced-motion); плашка «Подписка: Standard» — тот же приём, что «Тариф: Max» (C.bgCard + C.border); подписи окон квоты расширены до 64px — это layout, не токен.
  • Вкладок три: quotas / slots / apply. Вердикт-полоса в шапке общая для всех вкладок, кнопка «К квотам →» ведёт на quotas.
Данные от бэкенда (вместо свободного Note)
  • Типизированные поля баланса провайдера: SubscriptionTier (строка, «Standard»), SessionsUsed/SessionsLimit (снимок), KeyLimitUsd/KeyRemainingUsd, GiftBalanceUsd, SpendByPeriod { day, week, month, source }, FreeLlmHealth { platformsAlive, platformsTotal, requests24h, successRate24h }. Поле Note остаётся фолбэком для всего, что не типизировано.
  • Не-админу бэкенд отдаёт проценты квот и состав провайдеров; денежные поля (BalanceUsd, KeyRemainingUsd, SpendByPeriod) не сериализуются вовсе — а не прячутся на фронте.
Правила поведения
  • «Сохранить как пресет…» видна только в dirty-состоянии слота (цепочка разошлась с пресетом-источником). «Сохранить» пишет цепочку в сам слот; пресет нужен для повторного применения.
  • Слот с 0 мест всегда показывает подсказку-переход на «Применение» — пустой слот не должен читаться как поломка.
  • Стратегия «Бесплатно» рендерится disabled (не скрывается), если нет ни одного бесплатного провайдера и не настроена Ollama.
  • Битая ссылка на удалённый пресет: warning-рамка, фолбэк «настройка по умолчанию», чип открывает список выбора.
Риски и честные замечания
  • Плитка «По тарифам API» — не «расход». Сумма $3 411 считается по тарифам по всем ходам скопом, включая реально оплаченные (DeepSeek, OpenRouter) — разделить по источнику оплаты из данных нельзя, поэтому ни «расход», ни «сэкономлено» в этой плитке не используем.
  • Лимит ключа OpenRouter живёт только в «Деньгах» — пределом со шкалой и предупреждением. Из «Квот подписок» убран: одно число в двух местах разными единицами читалось как два разных лимита.
  • KPI четыре: плитки про бесплатное слиты в одну («37 из 47 · успех 94%») — теснота на 720px снята без потери смысла.
  • Счётчик сессий Kimi живёт в раскрытии карточки: поминутный снимок, на который пользователь не влияет. Вид (сегменты, не шкала) и подпись «моментальный снимок, не расход» сохранены.
