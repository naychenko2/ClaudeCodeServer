# Модалка «MCP-серверы»

Макет: [mcp-servers-modal.html](mcp-servers-modal.html) (обе темы и мобильная раскладка — кнопки в шапке;
«Пустой список» и «Диалог удаления» тоже переключаются оттуда).

## Проблема

MCP-серверы — внешние инструменты чатов и персон (задачи, заметки, Miro, файловый сервер). Сегодня их
состав зашит в код: пользователь не видит ни списка, ни статуса, а когда у сервера протухает авторизация,
инструмент просто молча перестаёт работать — человек узнаёт об этом по бессмысленным ответам ассистента.
Экран должен отвечать на три вопроса: **что у меня подключено, живо ли оно и кому оно доступно.**

## Решение

Модалка из меню аватара, рядом с пунктом «Поставщики моделей». Не полноэкранный раздел: это настроечная
поверхность низкой частоты без навигируемого содержимого (решение зафиксировано в плане волны 4).
Структура повторяет сестринский диалог «Поставщики моделей» — полоса вкладок, карточки с точкой статуса,
те же токены: два соседних пункта меню не должны выглядеть как из разных продуктов.

Четыре вкладки:

1. **Серверы** — карточки. Точка статуса, название, бейдж происхождения, транспорт (`stdio`/`http`),
   тумблер «Включён», «Проверить». Три вида записей: **свои** (полное управление: тумблер, правка,
   удаление), **встроенные серверы продукта** (tasks, notes, wsp… — компактными плитками, только статус)
   и **«наследство»** из старого конфига (бейдж + подсказка пересохранить). Встроенные свёрнуты в плитки
   намеренно: их восемь, полноразмерными карточками они похоронили бы свои серверы под собой.
2. **Добавить** — сегмент `stdio | http | JSON-фрагмент`. stdio: команда + аргументы + переменные
   окружения; http: адрес + заголовки. Пары «ключ — значение» с флажком «секрет». JSON-путь — вставка
   готового `mcpServers` из конфига Claude Code / Claude Desktop.
3. **Доступ** — матрица «проект × сервер» с тумблерами (сервер включён везде, пока не выключен в проекте)
   и read-only таблица «персона × сервер» со ссылкой «Студия →»: редактирование доступа персон живёт в
   студии персоны, здесь только обзор — чтобы перед удалением было видно, кого это заденет.
4. **Диагностика** — таблица вызовов инструментов: счётчики, отказы, последний сбой с текстом и временем.
   Только для администратора (эндпоинт отдаёт данные всех владельцев) — на вкладке бейдж «админ».

## Статусы и их тон

| Статус | Точка | Тон |
|---|---|---|
| Работает | `C.success` | спокойный, с числом инструментов и временем проверки |
| Не проверялся | `C.textMuted` | **не ошибка**, а «ещё не спрашивали» — самый частый на старте; строка-приглашение «нажмите „Проверить"» |
| Нужен вход | `C.warning` | приглашение к действию, а не красная тревога: кнопка «Войти» accent'ом, под ней «токен истёк 12 августа» |
| Не отвечает | `C.danger` | единственный по-настоящему красный статус: причина (таймаут 10 с) и когда проверяли |

Цвета точек наследуют логику `DOT_COLOR` из `modelProvidersShared.ts` (success / warning / muted),
добавляется только danger для «Не отвечает» — семантического места у него в существующей тройке нет.

## Ключевые состояния

- **Проверка идёт.** Точка пульсирует warning'ом, строка статуса меняется на «Проверяем… обычно 2–3
  секунды», кнопки карточки гаснут. Остальной список остаётся живым — блокируется только своя карточка.
  В макете клик по «Проверить» честно симулирует эти 2.4 с.
- **Пустой список.** Свои серверы ещё не добавлены: «Пока подключены только встроенные серверы продукта.
  Добавьте свой — например, Miro или файловый сервер — и он станет доступен в чатах и персонам» + CTA,
  ведущая на вкладку «Добавить». Встроенные плитки при этом остаются на месте — продукт не выглядит
  пустым, пустота показана только там, где пусто.
- **Удаление.** Подтверждение `MODAL_W.confirm`: «Сервер отключится у N персон и во всех проектах.
  Секретные значения будут стёрты». Кнопка удаления — `C.danger`, это разрушительное действие.
- **Длинные значения.** Команды и URL (бывают 200+ символов) — моноширинным, в одну строку с ellipsis
  и полным значением в `title`. Секреты — маскированы (`••••••••`), после сохранения вместо значения
  только отметка «задано».

## Спецификация для реализации (Кира)

- Ширина модалки — `MODAL_W.wide` (720), как у «Поставщиков моделей». Диалог удаления — `MODAL_W.confirm`.
- Карточка сервера — поверхность `C.bgWhite`, рамка `C.border`, радиус `R.xl` (12). Плитки встроенных —
  паттерн `ProviderTiles` (та же сетка, та же точка). Заголовки групп — `groupHeaderStyle` из
  `modelProvidersShared.ts`.
- Тумблер — готовый `ui/Toggle` (42×25; в матрице доступа — тот же, уменьшенный 34×21 через props
  `width`/`height`, новый компонент не нужен). Кнопки — `ui/Button`; «Войти» — primary/accent,
  «Проверить» — secondary.
- Вкладки — разметка и стили 1:1 из `ModelProvidersTabsModal.tsx` (полоса с `borderBottom`,
  активная — `C.accent`). Бейдж «админ» на «Диагностике» — `C.accentLight`/`C.accent`; сама вкладка
  не рендерится для не-админа, как `providers`/`apply` у соседа.
- Секретные поля: флажок «секрет» — нативный checkbox с `accent-color: C.accent`; в форме
  редактирования значение не приходит с бэка вообще — поле disabled с плейсхолдером «задано».
- Мобильная раскладка: модалка — шторка (`R.sheet`, `SHADOW.sheet`, grabber-полоска сверху); таблицы
  «Доступа» и «Диагностики» — в коробке с `overflow-x: auto`, карточки — на всю ширину. Тач-цели
  кнопок карточки — не меньше 40px по высоте строки действий.
- Состояние проверки — локальное per-card (`checking` в сторе хука `useMcpData`), никаких глобальных
  спиннеров на модалку. Тумблеры сохраняются оптимистично со счётчиком версий — паттерн уже есть в
  `useProviderData`/`handleSaveLayer`, копируется вместе с ним.
- Цвета — только `C.*`, перед коммитом `npm run lint:design` зелёный. Новых значений в шкалах
  не вводится: всё собрано из существующих токенов.

## Границы этого макета

Поток OAuth (кнопка «Войти» → authorize URL → callback) — волна 7 плана; здесь задано только место
кнопки и тон статуса «Нужен вход». Уровень проекта (секция в EditDialog проекта) — отдельный кусок
волны 4, в этой модалке не показан. Тексты статусных строк («проверен сегодня в 14:32», «токен истёк
12 августа») — образцы формата, а не финальный copydeck; смысловые формулировки из постановки
(пустой список, предупреждение удаления) перенесены дословно.
