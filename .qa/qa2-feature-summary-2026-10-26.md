## 1. «Обновлено N назад» (F15, дефект f2da9354) — принято

Значения `brief.updatedAt` сняты из ответа `GET /api/tasks/features/{id}`, текст — из DOM
(`[data-testid="brief-updated"]`), время чтения DOM зафиксировано тем же прогоном.

| случай | `brief.updatedAt` (ответ API) | текст в DOM | сходится |
|---|---|---|---|
| свежая фича (событие за 11 с до чтения) | `2026-10-26T11:49:41Z` | `обновлено только что` | да |
| событие 3 ч назад | `2026-10-26T08:49:41Z` | `обновлено 3 ч назад` | да |
| закрытая фича (событие 2 суток назад) | `2026-10-24T11:49:41Z` | `обновлено 24.10, 14:49` | да (дата закрытия; локальная зона браузера UTC+3) |
| без событий (`updatedAt` = null) | — | строки `обновлено` нет вовсе | да |

- Счёт идёт по `updatedAt` (время последнего **записанного** события состояния), а не по
  `computedAt` (момент ответа): в свежей фиче `computedAt` на 3 с позже `updatedAt`, и строка
  всё равно «только что» — до фикса она была бы «только что» всегда, потому что `computedAt`
  всегда свежий. Это и был дефект f2da9354.
- «0 мин» не печатается ни в одной строке (порог — полные минуты, `agoText`).
- Ветка «событий нет» (`updatedAt` = null) на живых данных недостижима: у любой фичи есть эпик,
  а его `CreatedAt` и есть событие. Проверена подменой ответа API на живом стенде
  (`page.route` → `brief.updatedAt` удалён): элемент `brief-updated` отсутствует, остальная
  карточка рисуется нормально.

- Неизвестный код (`mystery_reason_42`) и пустой код (null) — правка `tasks.json` при остановленном
  бэке: строка «Сейчас» = `Исполнитель встал` (без двоеточия и без кода), машинного кода на странице

   из UI-кита, на 360 у него `minHeight: 40`. Тот же элемент отмечен в QA1, к F15–F18/B11–B13

2. **Формулировки при неизвестном/пустом коде остановки расходятся между поверхностями**: строка
   «Сейчас» говорит `Исполнитель встал` (по решению R-F17 п.5 — неизвестный код не называется),
   блок «Остановлена» и плашка задачи — `Исполнение прервано` (общий фолбэк
   `executorStopVisual`). Машинного кода нет нигде — требование критерия выполнено; расхождение
   формулировок — наблюдение, отдельной карточки не завожу.
3. **«0 из 0 шагов приняты»** на фичах, у которых план не нарезан: счётчик берёт шаги плана,
   которых у таких фикстур нет. Артефакт фикстуры, к приёмке не относится.
