# Вкладка «Встречи» в панели «Ферма» — предложение v1

**Статус: принят Андреем 18.11.** Решения при согласовании:
- вкладка называется **«Встречи»** (вместо «Транскрибация»): на рельсе 380 все четыре подписи
  помещаются (296 px из 378), на телефоне 360 тоже (293 из 334); только на листе <340 px неактивные
  вкладки показываются иконкой;
- панель «Локальные модели» переименовывается в **«Ферма»**; сводная карточка на вкладке «Стенды»,
  которая сейчас называется «Ферма», становится **«Узлы»**, чтобы слово не повторялось;
- открытые вопросы ниже Андрей отдельно не решал — для v1 берутся умолчания: вкладка только смотрит,
  без действий; порог «Завис?» 5 мин; сбои и встречи за сутки, но не больше 20 строк; видит только
  админ. «Пишет в» сравнивается с узлом, на котором работает CCS (уточнить при постановке бэкенда).

Привязка: задача `fbffcba2` (role=design), featureId `76117203-5303-4cc6-bd1b-05616823105f`.
Макет: [local-model-transcription-v1.html](local-model-transcription-v1.html), шесть состояний, две темы,
ширины 380 / 360 / 320.

## Сценарий и проблема

Андрей открывает панель и за пару секунд хочет понять три вещи: жив ли конвейер, что он жуёт прямо сейчас,
и не потерялось ли что-то по дороге. 18.11 четыре встречи «пропали»: конвейер работал, но писал на ai, а
«Встречи» читают с worker. Табло в консоли (`status.py`) этого не показывает, и в CCS такого места нет.

## Решение

Четвёртая вкладка панели рядом с «LLM · Медиа · Стенды» — «Встречи», только для админа (как «Стенды»). Сверху вниз,
по убыванию срочности:

1. **Баннер** (Notice) — только при тревоге: «Конвейер не отчитывался 23 мин», «Сервис остановлен»,
   «4 встречи не попали в Dify».
2. **Конвейер**: плашка статуса (Идёт пачка / Ожидание / Завис? / Остановлен), «Обновлено N назад»,
   «Где работает» (узел · pid) и **«Пишет в»** (узел · каталог). Последнее поле — прямой ответ на 18.11:
   если узел записи не тот, где читают «Встречи», строка становится жёлтой.
3. **Сейчас**: файл, папка, полоса этапов «Распознавание → Сводка → В Dify», сколько идёт, длина записи,
   место в пачке. Пустое состояние: «Ничего не обрабатывается» и когда закончилась последняя пачка.
4. **Очередь**: две плитки «Ждут распознавания» и «Ждут сводку», под ними раскрывающийся список файлов.
5. **Сбои за сутки**: красная карточка, видна только когда сбои есть; комментарий из журнала целиком.
6. **Последние встречи**: имя, папка, время, длина, спикеры, комментарий журнала; касание открывает .md во
   «Встречах». Пять строк и «Показать ещё».
7. **Сверка с Dify**: три папки, «Локально / В Dify», плашка «сходится» или «не хватает N».
8. **Зависимости**: распознавание, сводки, Dify, сетевая папка — точка и слово (в норме / медленно / не
   отвечает / не проверялось).

Точка на вкладке (6 px, как у «Стендов»): красная при «Завис?», «Остановлен» или сбое зависимости, жёлтая
при расхождении с Dify или «Пишет в» не туда.

**«Завис?»** — производное: state.json старше порога (предлагаю 5 мин при живом pid; при штатном шаге
обновления ~10 с). Значения блоков «Сейчас» и «Очередь» гаснут до `C.textMuted`, время «идёт» краснеет.

## Узкая лента

С подписью «Встречи» четыре вкладки помещаются в рельс и в лист 360. На листе <340 px неактивные вкладки показываются только
иконкой (`aria-label` + Tooltip), активная — с подписью. На рельсе 380 все подписи влезают в шапку.
Остальное — одна колонка; длинные имена режутся многоточием с полным именем в `title`, в таблице сверки
папки без общего префикса `Video-`. Проверено скриптом: ни на одной ширине и ни в одном состоянии нет
горизонтального переполнения.

## Токены и компоненты (для Киры)

Новых цветов и компонентов нет. Остров/лист, `InlineSegmented sm` — как в панели. `Card` (C.bgCard,
C.borderLight, R.xl, SP.md); карточка сбоев — C.dangerBg / C.dangerBorder, заголовок C.dangerText.
Плашки `Badge`: «Идёт пачка» C.accentLight/C.accent, «Ожидание» и «сходится» C.bgInset/C.success,
тревога C.dangerBg/C.dangerText, расхождение C.warningBg/C.warningText, папка C.infoBg/C.info моно.
Плитки очереди — `HwTile`. Строка встречи — `PressableArea`, мин. высота 44, hover C.bgSelected, фокус —
контур C.accent. Полоса этапов: пройден C.success, текущий C.accent, впереди C.track. Скелеты загрузки —
C.bgInset, без нулей вместо данных.

## Открытые вопросы к Андрею

1. «Пишет в»: откуда конвейер знает свой каталог вывода и какой узел «правильный»? Можно сравнивать с
   узлом, где живёт CCS, или с настройкой.
2. Нужны ли действия (перезапуск сервиса, повтор упавшего файла) — в v1 вкладка только смотрит.
3. Порог «Завис?» — 5 минут подходит?
4. Глубина «Последних встреч» и «Сбоев» — сутки / 20 строк достаточно?
5. Вкладка только для админа?

## Черновик данных с бэкенда (финализируется после «ок»)

Один снимок `GET /api/local-model/transcription` (admin), опрос раз в 5 с только при открытой вкладке
(как остальные вкладки панели). Источник — файлы конвейера на узле (агент узла или прямое чтение, когда
сервис переедет на worker).

| Блок | Поля | Источник | Свежесть |
|---|---|---|---|
| Конвейер | `phase` (idle/batch/stopped), `updatedAt`, `host`, `pid`, `alive`, `outputHost`, `outputDir` | `logs/state.json`, `systemctl is-active`, конфиг конвейера | каждый опрос |
| Сейчас | `file`, `folder`, `stage` (asr/summary/dify), `stageStartedAt`, `durationMin`, `batchIndex`, `batchSize` | `state.json`, `summary_state.json` | каждый опрос |
| Очередь | `asrQueue[] {file, folder, since}`, `summaryQueue` (число) | `state.json`, `summary_state.json` | каждый опрос |
| Сбои | `fails[] {at, folder, file, minutes, comment}` за 24 ч | `logs/journal.tsv`, type=fail | каждый опрос (хвост файла) |
| Встречи | `recent[] {at, folder, file, minutes, speakers, comment, mdPath}` | `journal.tsv` type=ok, путь .md во «Встречах» | каждый опрос |
| Сверка | `dify[] {folder, local, inDify}`, `checkedAt` | журнал systemd «сверка с Dify» (раз в 30 мин) | раз в 30 мин |
| Зависимости | `deps[] {key, ok/slow/down/unknown, checkedAt}` | пинг ComfyUI/CcsAudioWorker, Strata, Dify, монтирование папки | раз в 30–60 с на сервере |

Статус «Завис?» и точку вкладки считает бэкенд (`level`), фронт его не выводит сам.
