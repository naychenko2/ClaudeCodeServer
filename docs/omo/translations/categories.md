# Категории делегирования

Восемь профилей постановки (по схеме `BuiltinCategoryNameSchema`) — это тон задания и уровень
модели, а не имена инструментов: субагента ты зовёшь как обычно.

| Тип работы | Профиль | Уровень | Как формулировать задание |
|---|---|---|---|
| Трудная логика, архитектура, разбор запутанного | `ultrabrain` | сильная | только ясная цель, без пошаговых инструкций |
| Автономная работа над запутанной проблемой | `deep` | сильная | ОДНА цель = ОДИН вызов; несколько целей — несколько параллельных вызовов |
| UI, вёрстка, стилизация, анимация | `visual-engineering` | средняя | укажи дизайн-систему; требуй токенов вместо хардкода |
| Творческая, неконвенциональная работа | `artistry` | сильная | задай рамки результата, а не способа |
| Документация, README, проза | `writing` | средняя | аудитория, объём, тон; без ИИ-штампов |
| Тривиальное: правка одного файла, опечатка | `quick` | слабая | по пунктам: ОБЯЗАТЕЛЬНО СДЕЛАТЬ / ЗАПРЕЩЕНО ДЕЛАТЬ / ОЖИДАЕМЫЙ РЕЗУЛЬТАТ |
| Прочее, умеренное усилие | `unspecified-low` | слабая | та же явная структура, что у `quick` |
| Прочее, большое усилие в нескольких модулях | `unspecified-high` | сильная | цель плюс явные границы объёма |

Два правила поверх таблицы:

- Чем слабее уровень, тем явнее задание: слабой модели нужны нумерованные шаги, запреты
  и критерии приёмки; сильной — цель и свобода в способе.
- Уровень — слот настроек, а не конкретная модель: за «сильной» у разных провайдеров стоят
  разные модели, поэтому в задании называй уровень, а не имя модели.

## Адаптации

- В рантайм идёт только эта таблица; развёрнутые профили всех восьми категорий (промпт-довески,
  ворота выбора, предупреждения вызывающему) вынесены в `category-profiles.md` — раньше они
  целиком вставлялись в постановку каждой задачи (~30 КБ на запуск).
- Модели оригинала OmO (gemini/kimi и прочие) и перечисления «Claude Haiku · DeepSeek Flash · GLM 4.7»
  заменены именами слотов: конкретное имя врёт при смене провайдера, а выбор модели субагента
  всё равно за вызывающим (`model=` в вызове) либо за назначением места.
