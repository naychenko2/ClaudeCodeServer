Особые правила для специальностей — два варианта

Замечание человека (14.08): в показанной вкладке была таблица «специальность × три уровня», и в ней появлялся горизонтальный скролл. Ответ не в том, чтобы починить таблицу, — её идея неверна для этих данных: 14 специальностей × 3 уровня = 42 ячейки, а задано обычно около пяти. Сетка показывает 37 пустых клеток и заставляет тридцать семь раз читать «как у всех». Ниже — два варианта без единой пустой ячейки. Оба держат жёсткие рамки: никакого горизонтального скролла вплоть до 320px, правка не глубже двух уровней вложенности, три слоя («Для всех» / «Только для меня» / «Пользователю…» — последний видит только администратор), строка «Любая специальность» на месте и раскрыта первой, «Сейчас пойдёт» сохраняется в каждой точке правки.

Вариант A — «Список правил»обозримость

Вкладка показывает только то, что реально задано: карточка «Любая специальность» и пять строк-фраз «кто · какой уровень → чем закрыт». Тап по строке раскрывает редактор прямо под ней (первый уровень вложенности), выбор модели или цепочки — та же единая панель, что везде (второй уровень). «Добавить правило» ведёт по трём помеченным шагам в одной панели — без перелистываний. Кликните строку «Дизайнер» и кнопку «Добавить правило».

Честное сравнение: что выигрывает каждый и чем платит

Оба варианта укладываются в рамки; разница — в том, что человек видит первым и как мыслит о задаче.

Критерий
A · Список правил
B · Карточки специальностей
Первый экран
+ Видны все 5 заданных правил разом — ответ на вопрос «что у меня вообще настроено?» без единого тапа
− За сводкой («Средняя → GLM 5.2») не видно, что у роли есть ещё два пустых уровня; правило на второй уровень той же роли добавляется из раскрытия
Модель мышления
«Точечная поправка»: одна фраза = одно отличие от нормы. Ближе к тому, как человек формулирует задачу вслух
«Досье роли»: все три уровня специальности рядом. Удобно настраивать новую роль целиком за один заход
Добавление правила
+ Мастер из трёх шагов в одной панели: роль → уровень → чем закрыть. Нельзя потеряться
− Два тапа до пустых полей: раскрыть «Без своих правил» → тап по названию. Прямой кнопки «добавить» нет — её роль играет список
Правка существующего
Раскрытая строка показывает только один уровень — тот, что задан; сегментом можно переключить уровень, не закрывая строку
+ Все три поля перед глазами, перестановка между уровнями одной роли — без переключений
Рост данных
При 20 правилах список длиннеет, но остаётся плоским; поможет поиск по строкам (дорожка в реализацию)
+ Список никогда не длиннее числа специальностей (14) — сводки сжаты по строке на роль
Мобила 320px
Строка переносится в две строки (имя + значение), редактор — вертикальный; самая плотная раскладка из двух
Карточка уже столбик по природе; чуть выше по вертикали за счёт трёх полей даже у свёрнутой сводки
Цена реализации
Новый компонент строки + мастер; редактор строки — по сути та же карточка уровня из «Моделей по умолчанию»
+ Почти готовый паттерн: строки-аккордеоны уже живут в ExceptionsBlock — раскладка меняется, поведение остаётся

Рекомендация дизайнера: A — если чаще читают «что отличается от нормы» (так выглядит типичный сценарий: проверить одну поправку); B — если чаще заводят новые роли целиком. Выбор за человеком; после выбора вариант переносится в index.html как вкладка раздела.
