Полоса контролов композера — приоритетное схлопывание

Живая полоса

Ползунок меняет ширину полосы (320…1100 px). Ступень считается по бюджету: free = ширина − padX − левый блок − «⋯» − зазоры; перебираем форму правой группы A-wide → A → B → B2 → C, берём первую, при которой активные бейджи влезают целиком; если и при C не влезают — понижаем бейджи по рангу снизу вверх (имя пилюли механики → чип «Авто» → цикл в «⋯» → бейдж КР в «⋯»). Пилюля механики остаётся всегда. Порядок бейджей исправлен: [пилюля механики][бейдж КР][цикл] — обрезка справа больше не съедает самое важное.

Ступени правой группы

Форма правой группы выбирается по бюджету, а не по порогам 640/900. Порядок жертв подписей внутри неё — по важности для человека: усилие первым (на дефолте «Усилие» — имя контрола, ноль информации за 100 px), собеседник вторым (кто ведёт чат важнее уровня рассуждения), модель последней (имя модели держится до предела). Номиналы: A-wide 534 · A 384 · B 313 · B2 222 · C 160.

Лестница жертв: предельный набор (три бейджа)

Все три бейджа активны. Правая группа дошла до C, места всё ещё не хватает — дальше понижаем бейджи по рангу снизу вверх. Пилюля механики (ранг 1) не жертвуется никогда: она меняет смысл кнопки «Отправить» прямо сейчас. Пустая полоса (бейджей нет) — в конце.

Компактная пилюля механики

[иконка 28×28 → настройки][✕ 26×28 → снять]. Разделитель между сегментами — не волосяная линия: в тёмной теме C.accentMuted на C.accentLight исчезает. Вместо него сегмент ✕ получает постоянную заливку C.accentMuted — граница читается в обеих темах. Понажимайте сегменты: тач-состояние :active — тень внутрь (SHADOW.press), touch-action: manipulation.

Бейдж КР без чипа «Авто» → строка-свитч в поповере

Командная реализация

Штаб разбивает задачу на волны и раздаёт их исполнителям. Координатор следит за ходом и собирает итог.

Уведённые в «⋯»: цикл и бейдж КР

Пункт меню — это не обрезанный бейдж, а полноценная строка: иконка, название, состояние одной строкой и тумблер. Клик по строке бейджа КР открывает его обычный поповер.
