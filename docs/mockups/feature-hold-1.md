# Пауза и черновик фичи — макет 1

Макет: [feature-hold-1.html](feature-hold-1.html) (переключатели темы, варианта и состояния вверху).
Привязка: эпик волны 4 `ba38ba28-d8a6-489d-a23a-1d6f153456a2`, задача макета `234cbc79`, шаг-потребитель
**W4-HOLD-F2** (кнопки, lane=front). Контракт — [feature-lifecycle-shared-chat-cut-2026-10.md](../research/feature-lifecycle-shared-chat-cut-2026-10.md), раздел 1.

## Сценарий и проблема

Человек видит, что фича ушла не туда (или ему нужен worktree), и хочет **остановить всё сразу** —
не гоняясь по чатам исполнителей с «Стоп». Позже он возвращается и **продолжает с того же места**.
Вторая история: фичу завели, план готовят, но **шаги запускать ещё рано** — это черновик.

Обе плашки — не тревога. Если покрасить паузу как «ждёт вас» (голубой) или как «стоит» (красный),
человек будет получать сигнал «действуй» про то, что сам же и остановил.

## Решение

### Теги (StatusTag): два новых тона

| state | Подпись | Тон | Фон | Текст | Рамка | Глиф |
|---|---|---|---|---|---|---|
| `paused` | «на паузе» | `hold` | `C.bgInset` | `C.textPrimary` | `inset 0 0 0 1px C.border` | «‖» 10 px, `currentColor` перед подписью |
| `draft` | «черновик» | `draft` | `transparent` | `C.textSecondary` | `1px dashed C.textMuted`, поле 0 6 (компенсирует рамку) | нет |

Размеры — как у остальных тегов: `FS.xs`/600, строка 16, поля `SP.xxs SP.xs`, `R.sm`. Точки `C.info` у
обоих нет. В `FeatureRunTagTone` добавить `'hold' | 'draft'`, в `featureRunStatusTag` — две ветки.
Индексный `featureStatusTag` (список): `paused` → `{ label: 'На паузе', tone: 'hold' }`, `draft` →
`{ label: 'Черновик', tone: 'draft' }`, ветки — **до** запасного пути по `attention`.

Почему `C.textMuted` для пунктира, а не `C.dashed`: в тёмной теме `C.dashed` сливается с фоном
(та же причина, что у глифа `absent`, замечание M1).

### Глифы (FeatureGlyph, 16×16 viewBox)

- `hold` — круг r 7, заливка `C.bgInset`, обводка `C.textMuted` 1; два бруска 1.9×6.8 (x 5.3 и 8.8, y 4.6, rx 0.6), `C.textSecondary`.
- `draft` — кольцо r 6.2, без заливки, обводка `C.textMuted` 1.5, `strokeDasharray="2.4 2"`.

### Размещение кнопок: два варианта

**A — кнопка в шапке (рекомендую).** Тулбар 1280: `тег · [Пауза] · [главное действие] · ⋯`.
«Пауза» — `Button size="sm" variant="secondary"` с глифом «‖» (`ICON_SIZE.xs`). Справа от неё
остаётся цветное главное действие («Мерж…» при `merge_pending`), поэтому по весу их не спутать.
На 360 тулбар держит только ⋯ (как сейчас): «Поставить на паузу…» — **первый пункт** шторки с
подсказкой «Прервёт N идущих шагов» (`FS.sm`, `C.textMuted`), если N > 0.

**B — чип в мете.** «Пауза» встаёт в строку меты рядом с веткой, на обеих ширинах. Отвергаю:
мета — строка фактов, кнопка в ней ломает смысл; на 360 чип 40 px перекидывает мету на два ряда;
чип с рамкой рядом с тегом читается как ещё один тег. Оставлен в макете для сравнения.

В обоих вариантах одинаково:

- **Пауза on → главное действие «Снять паузу»** (`variant="primary"`, глиф ▶). На 360 — в блоке
  состояния (как «Ответить» у тревоги), `minHeight: 40`.
- **Черновик → главное действие «Запустить фичу»** (primary, ▶); на 360 — в блоке, рядом ghost
  «Открыть ключевой чат». «Пауза» в черновике не показывается (контракт: `manual` поверх `draft` — 409).
- **«Вернуть в черновик»** — пункт ⋯, только пока у фичи нет ни одного запуска шага
  (бэк должен отдать признак; до него пункт не показываем).
- **Где кнопки «Пауза» нет:** `merging`, `merged`, `closed`, `draft`, `paused`. Пункта в ⋯ тоже нет.
  Разрешена при `running`, `waiting`, `stopped`, `merge_pending`, `not_started`, `idle`.

### Блок состояния (FeaturePageAlert)

| state | Фон | Рамка | Глиф | Текст |
|---|---|---|---|---|
| `paused` | `C.bgInset` | `1px solid C.border` | `hold` 14 | **«Фича на паузе {dur}.»** Поставили вы. Новые шаги не запускаются. Ниже — «Прервано N шагов — продолжатся с того же места после снятия паузы:» и строка «{Персона} · {stepRef}» через « · », `FS.sm`/`C.textSecondary`. N = 0 — строки нет. |
| `draft` | `transparent` | `1px dashed C.textMuted` | `draft` 14 | **«Черновик.»** Шаги не запускаются — разрез, план и дизайн идут как обычно. Запустите фичу, когда план готов: куратор начнёт конвейер. |

`{dur}` — от `Hold.Since` через `formatDuration`. `role="status"`, `aria-live="polite"`, как у тревоги.
При `paused` блок тревоги (`attention`) не рисуется: `paused` стоит выше `stopped` и `waiting`.

### Подтверждение паузы

Если идёт хоть один ход исполнителя фичи — модалка (`Modal`, `MODAL_W.confirm` (380)):
- заголовок «Поставить фичу на паузу?»;
- «Идущие шаги прервутся сразу: **{Персона} · {stepRef}** и …»;
- `C.textSecondary`: «Файлы в worktree останутся как есть. Новые шаги не запустятся, пока вы не снимете паузу, — тогда прерванные продолжатся с того же места.»;
- кнопки: ghost «Отмена», primary «Поставить на паузу» (не danger: действие обратимо). Фокус при открытии — на «Отмена», Esc закрывает.

Идущих ходов нет — без модалки, сразу запрос и тост. «Снять паузу» и «Запустить фичу» — без подтверждения.

### Состояния кнопок и ответы

- hover — `C.bgSelected` (secondary), focus — `SHADOW.focus` (штатно у `Button`).
- loading — `Button loading`: «Ставлю паузу…», «Снимаю паузу…», «Запускаю…»; повторный клик заблокирован.
- успех — тост: «Фича на паузе» / «Прервано N шагов. Снять паузу — на странице фичи.»;
  «Пауза снята» / «Продолжены N шагов, куратор в курсе.»; «Фича запущена» / «Куратор начинает конвейер.»
  Страница обновляется по событию агрегата, оптимистично тег не меняем.
- ошибка 409 — тост с причиной из ответа; фолбэки: `merging` — «Мерж уже идёт — его не останавливают посреди»;
  `draft` после запуска шага — «У фичи уже запускались шаги — в черновик не вернуть». Прочее — «Не получилось: {сообщение}».
- 403 человеку не придёт (ручка режет только сервисный токен) — отдельного текста не заводим.

### Список фич (FeatureGroupHeader)

- Статус: `paused` → «на паузе · {dur}», цвет `C.textPrimary`, вес 600; `draft` → «черновик · {dur}», `C.textSecondary`, вес 400.
- Глиф строки — `hold` / `draft` (14). **Кромки слева нет** (`alarm = null`): это не тревога.
- `kind` в `featureDisplayState`: новые `'hold' | 'draft'`.
- Отдельной группы и новых чипов фильтра нет: bucket `idle` сам опускает их ниже работающих, фильтр «открытые» их показывает.

## Мобила и тёмная тема

- 360: тулбар — только ⋯ (40); тег — в мете; «Снять паузу»/«Запустить фичу» — в блоке, высота 40;
  шторка ⋯ — пункты 44, «Поставить на паузу…» первым.
- Тёмная тема: `C.bgInset` темнее `C.bgWhite` — плашка «на паузе» читается как утопленная, кромка
  `C.border` держит контур; пунктир черновика — `C.textMuted` (не `C.dashed`). Проверено в макете переключателем.

## Чего нет в API сейчас (для бэка)

- `FeatureRun.Hold { reason, since }` и `FeatureIndexRow.HoldReason` — по контракту (шаг бэка W4-HOLD-B).
- Список прерванных паузой шагов (персона, stepRef) для блока — можно вывести из задач с
  `ExecutorStoppedAt` ≥ `Hold.Since`; если бэк не отдаёт, блок показывает только число.
- Признак «у фичи уже был запуск шага» — для пункта «Вернуть в черновик».
- Число идущих ходов для подсказки в ⋯ и модалки — из `run.now` (уже есть).
