# Переработка фильтра чатов — предложение

## Проблема

Список чатов зарастает. Главный источник шума — чаты-исполнители задач: задача
выполнена, а её чат остаётся в списке навсегда. Текущий фильтр (поповер в
`FilterBar.tsx`) не помогает:

- поповер перегружен: тип, странный срез «Последние 5 мин», персона — и всё;
- нет поиска по названию — в длинном списке чат находится только глазами;
- нет среза по статусу чата (работает / ждёт ответа / с ошибкой);
- чаты выполненных задач не спрятать никак.

## Общие решения во всех трёх вариантах

- **«Архив задач»** — новое понятие: чаты, чья задача выполнена (status=done).
  По умолчанию скрыты из основного списка, но не удалены: читаются,
  продолжаются, находятся поиском в своём срезе. Формулировка тумблера —
  «Скрывать чаты выполненных задач» (включён по умолчанию).
- Срез «Последние 5 мин» заменён на статусы жизни чата: **В работе /
  Ждут меня / С ошибкой** — это то, что человек реально ищет.
- Поиск по названию — во всех вариантах.
- «Показать только»: закреплённые / временные / групповые.
- Сводка активных фильтров + счётчик скрытых + empty state с осмысленным
  выходом. Мобильная раскладка — шторка, не hover-поповер.

## Варианты

### A — Поповер 2.0 (`chat-filter-variant-a.html`)

Эволюция текущего: тот же триггер «Фильтр», поповер пересобран — поиск,
статусы, тип, тумблер архива (подсвечен, когда включён), персона, «только…».

- ✅ Минимальный дифф от текущего кода: меняется только содержимое поповера.
- ✅ Привычная ментальная модель — пользователи ничего не переучивают.
- ❌ Всё по-прежнему за одним кликом: частый срез «ждут меня» — это открыть
  поповер, тапнуть чип, закрыть. Три действия вместо одного.
- ❌ Скрытие архива живёт только внутри поповера — не видно, «куда делись»
  чаты, пока не откроешь.

### B — Быстрые срезы (`chat-filter-variant-b.html`)

Постоянно видимая полоса чипов над списком: **Актуальные** (дефолт: всё,
кроме архива) / В работе / Ждут меня / Задачи / Закреплённые / **Архив
задач**. Поиск — всегда в шапке. Под чипами — строка-обратная связь
«Архив задач скрыт: 2 чата · Показать». Редкие фильтры (тип, персона,
особенности, «архив вперемешку») — в диалоге «Настроить фильтры».

- ✅ Частые срезы — один тап без открытия чего-либо.
- ✅ Архив — явный «ящик» в конце полосы со счётчиком: видно, что там 2 чата.
  Механика скрытия объясняет сама себя.
- ✅ Строка «что скрыто» с действием — лучшая обратная связь из трёх.
- ❌ Занимает две строки над списком постоянно (поиск + чипы).
- ❌ Чипы фиксированы: свой набор срезов не собрать.

### C — Представления (`chat-filter-variant-c.html`)

Фильтры как именованные «окна» на список. Системные: **Актуальные** (дефолт),
**Все**, **Архив задач**; свои сохраняются из текущего набора («Ждут меня»,
«Только Майя»). Меню таба: переименовать / дублировать / стартовое / удалить.

- ✅ Системное решение: архивный шум исчезает концептуально — живёшь в
  «Актуальных», архив — соседний таб.
- ✅ Свои представления закрывают сценарии, которые мы не предусмотрели.
- ❌ Дороже всех: новая сущность, её персистентность, меню таба, миграция.
- ❌ Сложнее освоить: табы + воронка + «сохранить как» — три механики сразу.

## Рекомендация

**Вариант B — как основа.** Он закрывает главную боль (архив задач виден и
понятен без единого пояснения), даёт мгновенные срезы и при этом не вводит
новых сущностей: реализация — тот же `chatFilters`-стор плюс полоса чипов
и диалог. Из C стоит забрать идею «сохранить текущий набор как представление»
**второй фазой**, если появятся запросы на свои срезы, — полоса чипов B
естественно расширяется до табов C.

Вариант A — запасной, если хочется минимальный дифф: он тоже честно решает
архив (тумблер подсвечен, сводка «без архива задач»), но оставляет частые
срезы за двумя кликами.

## Открытые вопросы к реализации

1. **Дефолт скрытия архива**: включён для всех сразу или только при
   количестве архивных чатов ≥ N (например, 3)? Предлагаю: всегда включён,
   строка-обратная связь (B) показывается только когда архив непуст.
2. Персистентность: скрытие архива — глобально для всех scope или per-scope,
   как сейчас остальные фильтры? Предлагаю per-scope (единообразно).
3. Статус «С ошибкой» (Error/Orphaned) — показывать ли такие чаты
   отдельным срезом или достаточно диалога «Настроить»? В макетах — в диалоге
   (B) и поповере (A/C) как чип «только».
