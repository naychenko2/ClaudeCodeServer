Граф — документ в центре, «Граф» — панель в рельсе справа

Раскладка повторяет workspace: слева чаты, в центре открытый документ «Граф зависимостей» (закрывается крестиком — как файл), справа рельса инструментов с открытой панелью «Граф»: режимы отображения (связи), поиск, легенда, god-узлы и паспорт выбранного типа. Кликни узел в графе — паспорт заполнится в панели справа.
