## Сценарий 5. Карточка в ленте чата

Агент создал черновик живым ходом (MCP `draft_create` + `draft_write_file`) → карточка появилась в ленте.
«Посмотреть файлы» → окно `feed-demo4 · 0.3.0` (установленная база 0.2.0), вкладка «Изменения», diff
`panel/index.html` — «Версия 3» → «Версия 4». Правка агента при открытом окне: `0.4.0` → `0.5.0`,
«Файлы» 4 → 5, «Изменения» 2 → 3, новый `commands/help.md` с `+`. Скриншоты: `06-feed-before.png`,
`07-feed-changes-before.png`.

**Находка (дефект `88e06318`):** в карточке **в ленте** при правке агента окно теряет состояние просмотра —
вкладка «Изменения» слетает на «Файлы», выбранный файл сбрасывается («Выберите файл»). Данные при этом
свежие. Причина (по коду): `draftsStore.bump()` обнуляет `preview` → `DraftCard` на `if (!preview) return null;`
не рисует детей → `FilesDrawer` размонтируется и теряет свой `useState`; в карточке «Плагинов» (`useDraftCard`)
предпросмотр не обнуляется — там состояние окна сохраняется. Карточка дефекта заведена на Киру.
