Файлы черновика · v1

Спека для реализации (кратко; полная — в отчёте задачи)

Сценарий. Перед «Принять» человек отвечает себе на три вопроса: что в пакете, что в конкретном файле, что поменялось против установленной версии. Плюс четвёртый — как будет выглядеть панель. Всё — в одном окне, переключение одним тапом, без футера.

Вкладки

Каждая вкладка помнит свой выбранный файл. «Файлы» — дерево всего пакета с метками изменений (+ ~), справа код. «Изменения» — дерево только изменённых, первой строкой «Сводка» (права, секреты, счётчики); удалённые — зачёркнутые. Изменённый файл в «Файлах» показывает переключатель «Файл | Изменения» — один клик до diff без смены вкладки. «Панель» — живой предпросмотр в рамке острова; вкладки нет, если в пакете нет панелей.
