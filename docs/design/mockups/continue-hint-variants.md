# Подсказка «Продолжить в новом чате»: варианты и спецификация

Макет: [continue-hint-variants.html](continue-hint-variants.html). Каждый вариант показан на десктопе (колонка чата 720 px) и на 390 px, в светлой и тёмной теме, вместе со строкой контекста и полем ввода. Переключатели в шапке макета: полоса эскалации над полем, длинное число (1,2M), открытый или закрытый поповер варианта B. Высоту подсказки макет меряет по живой вёрстке и пишет в подпись кадра.

## Проблема

Человек полдня ведёт один чат, контекст перевалил за порог. Ему нужен короткий сигнал: дальше дороже, можно начать с чистого листа. Сейчас `ContinueHint` — это `Notice tone="info"` с двумя кнопками `sm` в столбик:

- **+94 px над полем** и на десктопе, и на 390 px. Высоту задаёт столбик кнопок (32 + 4 + 32), а не текст.
- Подсказка встаёт **между строкой контекста и полем ввода** (`ChatPanel.tsx`, после `<ContextRow>`). Губа строки рассчитана на то, чтобы прилегать к карточке поля, а тут она висит в воздухе.
- Синяя рамка `C.info` — единственное холодное пятно среди тёплых полос строки. Сообщение при этом не тревожное, это совет.

## Варианты

| | Над полем (десктоп / 390) | Из чего собран | Плюсы | Минусы |
|---|---|---|---|---|
| Сейчас | +94 / +94 | `Notice info`, `Button sm` ×2 | не пропустишь | самая высокая полоса, разрывает губу, чужой тон |
| **A** — чип в строке контекста | 0 / 0 | `Chip soft` + `onRemove`, `touch` на мобиле | места не берёт, стоит в ряду, который читают перед отправкой | на 390 съедает место у «Чем», лестница ряда сжимается раньше; без git и объекта ряда нет, чипу негде жить; подписи ряда считает бэкенд, этот чип стал бы исключением |
| **B** — точка на кольце контекста + пункт в поповере | 0 / 0 | `RingPillBadge`, пип `C.accent`, `Button xs` в поповере | над полем пусто; шкала, «Сжать» и «Продолжить» в одном месте | точку в шапке легко не заметить, взгляд у поля; совет виден только после клика |
| **C** — тонкая полоса над строкой | **+32 / +36** | геометрия `UndoNotice` («Выбор снят · Вернуть») | одна строка у поля; выглядит как часть строки контекста; губа снова прилегает к полю; новых значений в шкалах нет | всё же +32 px; «Не сейчас» — это ✕ с подсказкой, а не слова |
| **D** — Notice в одну строку | +42 / +46 | `Notice info`, `Button xs primary`, `IconButton` ✕ | самый заметный из компактных | холодный тон остаётся; на 390 от текста остаётся «Контекст 312K» |

## Рекомендация: C

Совет должен быть виден там, где человек пишет. Поэтому B не подходит: он тихий до невидимости. A ломает строку контекста: в ней только факты о выборе, ценой её занятости. D просто сжимает сегодняшнюю проблему. C берёт форму, которую строка контекста уже умеет показывать («Выбор снят · Вернуть»), и стоит на треть от текущей высоты.

Если Андрею нужен совсем нулевой след, второй выбор — B. Тогда подсказка перестаёт быть подсказкой и превращается в функцию в поповере. Для фичи «экономим подписку» это потеря.

## Спецификация C для Киры

### Где стоит

**Над строкой контекста, внутри её хоста**, ровно там же, где сегодня `UndoNotice` (`ContextRowView.tsx`, блок `data-context-row-host`). Между строкой и полем ввода подсказки больше нет.

- `ContextRow` получает необязательный проп `notice?: ReactNode` и прокидывает его в `ContextRowView`.
- В `ContextRowView`:
  - в обычной ветке `{props.notice}` рендерится сразу после `{props.offer && <UndoNotice …/>}`, обе полосы могут стоять одна над другой;
  - в ветке `!showsRow(props)` (нет ни ветки, ни объекта) хост рисуется, если есть `offer` **или** `notice`, с тем же отступом `${SP.xs}px 0 ${SP.sm - 2}px`.
- В `ChatPanel.tsx` убрать обёртку с `padding: 0 SP.md SP.xs` после `EscalationStickyBanner` и передать `<ContinueHint …/>` в `ContextRow` через `notice={showContinueHint ? … : undefined}`. Условие `showContinueHint` не меняется.

### Общий примитив, а не третья копия

Полосу «Выбор снят · Вернуть» сегодня рисует голый div в `UndoNotice`. Вынеси её разметку в `RowNotice` (`components/chat/RowNotice.tsx`): иконка, текст, действие-ссылка, необязательный ✕. Переведи на него `UndoNotice` и новую `ContinueHint`. Иначе через месяц у двух соседних полос разъедутся рамка и отступы — ровно эту историю записывал `Notice.tsx` (дизайн-ревью 4.7, S2).

### Геометрия и токены

| Часть | Десктоп | Мобила (`isMobile`) |
|---|---|---|
| Полоса | `height: 28`, `margin: 0 0 ${SP.xs}px`, `padding: 0 ${rightPad}px 0 ${SP.sm}px`, `gap: SP.sm`, `border: 1px solid C.border`, `borderRadius: R.lg`, `background: C.bgPanel`, `fontSize: FS.sm`, `color: C.textSecondary`, `display: flex`, `alignItems: center` | `height: 32`, `padding: 0 ${rightPad}px 0 ${SP.sm}px`, остальное то же |

`rightPad` (правый отступ) — `SP.xs` (4 px), когда есть ✕ «Не сейчас» (zаточен под крестик), и `SP.sm` (8 px) без ✕ (как у «Вернуть»/UndoNotice); на мобиле без ✕ не 0.
| Иконка | `Gauge`, `ICON_SIZE.xs`, `ICON_STROKE`, цвет наследуется (`C.textSecondary`), `flexShrink: 0` | то же |
| Текст | `<span>` с `flex: 1`, `minWidth: 0` и многоточием (`ellipsis` из `RowChip`). Число — `<b>` с цветом `C.textHeading` и `fontWeight: 600` | то же |
| «Продолжить» | `<button type="button">`: без фона и рамки, `padding: 0`, `color: C.accent`, `fontSize: FS.sm`, `fontWeight: 600`, `gap: SP.xs`, справа `ArrowRight` `ICON_SIZE.xs`, `flexShrink: 0`, `borderRadius: R.sm` | то же |
| ✕ «Не сейчас» | `<button type="button">` 20×20, `X` `ICON_SIZE.xs`, `color: C.textMuted`, `borderRadius: R.sm`, `flexShrink: 0` | 32×30 (вся внутренняя высота полосы), иконка та же |

Тексты (`formatContextK(tokens)` → `312K`, `1,2M`):

- десктоп: «Контекст **312K** · дешевле продолжить в новом чате», ссылка «Продолжить»;
- мобила: «Контекст **312K**», ссылка «В новый чат».
- ✕: `aria-label="Не сейчас"`, `title="Не сейчас — напомню, когда вырастет ещё на 100K"`.

На узкой десктопной колонке (раскладка «чат | файл») текст режется многоточием, а ссылка и ✕ не сжимаются.

### Состояния

| Состояние | Что видно |

| hover «Продолжить» (десктоп) | подчёркивание, `textUnderlineOffset: 2` |
| hover ✕ | фон `C.bgSelected`, цвет `C.textSecondary` |
| tap (мобила) | для обеих кнопок фон `C.bgSelected` на `:active`, hover-стилей нет |
| focus-visible | `boxShadow: SHADOW.focus` у кнопки, `outline: none` |
| клик «Продолжить» | `onOpen()` открывает существующий `ContinueChatDialog`; полоса остаётся видимой под модалкой, как сейчас |
| клик ✕ | `onSnooze()`; полоса сразу исчезает и вернётся через +100K (логика `hintSnoozedAt` без изменений) |
| идёт ход / офлайн / встроенный чат / чат уже продолжен | полосы нет (условие `showContinueHint` прежнее) |
| рядом «Выбор снят · Вернуть» | обе полосы стоят столбиком над строкой, у каждой `margin-bottom: SP.xs` |
| рядом полоса эскалации | эскалация остаётся там, где стоит сейчас (над полем), подсказка — над строкой; друг на друга не налезают |
| длинное число (1,2M) | помещается и на десктопе, и на 390, проверено в макете |
| загрузка, ошибка | у полосы своих нет: ошибку запроса показывает диалог тостом |

### Тёмная тема

Новых цветов нет, все токены есть в обеих темах `theme.css`. В тёмной теме `C.bgPanel` (#272320) на `C.bgMain` отделяется рамкой `C.border` (#3D3830). Ссылка `C.accent` (#E38A6A) на `C.bgPanel` читается, см. кадры «тёмная» в макете.

### Что сохранить

- `data-testid="continue-hint"` на полосе; кнопкам дать `data-testid="continue-hint-open"` и `data-testid="continue-hint-snooze"`.
- `role="status"` на полосе.
- Компонент остаётся в `ContinueChat.tsx` с прежней сигнатурой `{ tokens, onOpen, onSnooze }` плюс `isMobile`.
- Витрину `UiKitPage` обновить (там уже есть `ContinueHint`). Проверить тест `components/chat/__tests__/ContinueChat.test.ts`.

### Проверка готовности

1. Десктоп и 390 px, обе темы: полоса ровно 28/32 px и стоит над строкой контекста, строка прилегает к полю.
2. Чат без git и без объекта: полоса есть, отступы как у «Вернуть» в той же ситуации.
3. «Продолжить» открывает диалог, ✕ прячет до +100K.
4. `npm run lint:design` зелёный.
