Что проходить кликами

1) строка фичи → страница → ✕ / «К списку»; 2) «Ждёт тебя» → «Ответить Александру»: открывается чат по маршруту, в шапке чип «к фиче · Ход»; 3) вкладки и «Все 44 шага этапа»; 4) «Материалы»: план читается внутри вкладки, файл открывается в центре вместо страницы; 5) «Разбор» — одна страница, якоря прокручивают её; 6) «Закрытые» → «Обзор фич» → «Разбор».

Пометки

«К / Б»: К — поле есть в ответе features/{id}, имя в подсказке; Б — нужно от бэка. «Компоненты»: рамкой обведён каждый блок, сверху — имя компонента продукта, с которого снята геометрия.

Откуда числа

Шаги, люди, документы и времена событий — из трекера на 10.11. Минуты, токены и доллары в «Разборе» — образцы значений поля, замера в прототипе нет.
