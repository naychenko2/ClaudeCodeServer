Тема:

Длинное название заметки доступно на таче

Дефект F7: в списке заметок названия режутся ellipsis, а на тач-устройстве полное название недостижимо в принципе — hover-tooltip (title на строке, NotesList.tsx:294) работает только на десктопе, а long-press открывает контекстное меню, где названия нет (NotesList.tsx:649-655). Предложение: у контекстного меню появляется шапка с полным названием — оно же уже показано в ConfirmDialog удаления, паттерн продукту знаком.

До (прод, long-press по строке)

Меню даёт действия, но не отвечает на вопрос «по какой заметке я держал палец» — две строки «Концепция новой…» неотличимы.

Краевые случаи

Очень длинное название (300+ символов) — шапка переносится без обрезки, меню растёт вниз; страховка позиционирования уже есть (top: Math.min(y, innerHeight − 240)), её хватает, потолок сместим до −280. Меню папки (kind === 'folder') — та же шапка с именем папки. Десктоп — поведение едино: правый клик даёт то же меню с шапкой, tooltip по hover никуда не девается. Короткое название — шапка в одну строку, меню не пухнет.

Спецификация для Киры

1. NotesList.tsx, рендер ctxMenu (~строки 600-679): перед первым пунктом добавить блок-шапку — padding: '7px 10px 6px', название fontSize: FS.sm, fontWeight: 600, color: C.textHeading, whiteSpace: 'normal', wordBreak: 'break-word', lineHeight: 1.35, мета-строка fontSize: FS.xs, color: C.textMuted (источник · дата). После шапки — существующий divider. Для kind === 'folder' то же самое с именем папки.
2. Шапка не кликабельна (pointerEvents: 'none'), чтобы не перехватывать тап на «Открыть».
3. Потолок позиционирования меню: window.innerHeight - 240 → - 280 с учётом шапки.
4. Токены: только C.textHeading/C.textMuted/FS.xs/sm — всё в шкале, обе темы без доработок. Регрессия: структура пунктов и ConfirmDialog не меняются.
