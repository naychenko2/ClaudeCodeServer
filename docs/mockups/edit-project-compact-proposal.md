# Компактный диалог «Редактировать проект» — предложение v1

Макет: [edit-project-compact.html](edit-project-compact.html) (интерактивный, 4 сцены, переключатель темы).

## Проблема

Диалог `EditDialog.tsx` стекует до 8 блоков: иконка/имя, группа, карточка-список,
lead-баннер, MCP-серверы, история файлов (Git), фон рабочего пространства, офлайн-синхронизация.
В полном составе это больше 1100px вертикали — модалка превращается в скроллящуюся ленту,
где «Сохранить» и форма теряются из вида. При этом большинство нижних секций — это
возможности, которые настраивают один раз, а не читают каждый день.

## Решение: сворачиваемые секции со сводкой статуса (не табы)

Секции-возможности (MCP, Git, фон, офлайн) сворачиваются в строки 44px:
иконка + название + **однострочная сводка состояния** справа + chevron.
Верхняя «форма» — иконка/имя, группа, карточка-список (путь/промпт/скрытые/правила) —
остаётся развёрнутой: это идентичность проекта, за ней в диалог приходят чаще всего.

```
+------------------------------+------------------------+
| (icon) Название              |  «Авто · 128 коммитов» |
| История файлов (Git)         |                    (v) |
+------------------------------+------------------------+
```

### Почему аккордеон, а не табы

1. **Сводка видна в свёрнутом виде.** «MCP · 2 из 3», «Git · Авто · 128 коммитов»,
   «Фон · Свой · Янтарный» — статус каждой возможности читается без единого клика.
   Табы это прячут: чтобы понять, включён ли git, пришлось бы открывать вкладку.
2. **Переменный состав не ломается.** Секции условны (MCP — только при наличии серверов,
   фон — за флагом и только владельцу). Табы с появляющимися/исчезающими вкладками путают;
   аккордеон-строки просто не рисуются.
3. **Чёткая граница «форма vs самостоятельные блоки».** Кнопка «Сохранить» футера
   сохраняет форму (имя/группа/промпт/правила), а секции-возможности сохраняются сами
   (MCP — мгновенно, git — по клику на карточку, фон — своими кнопками). Аккордеон
   визуально отделяет их от формы — сейчас эта граница размыта, и пользователь жмёт
   «Сохранить» в надежде, что оно применит и тумблеры ниже.
4. **На мобильной шторке аккордеон — естественный паттерн.** Строки 44px — готовые
   tap-зоны, раскрытие не меняет ширину, не добавляет горизонтальную навигацию.

Lead-баннер («У проекта нет руководителя») **остаётся развёрнутым и условным** — это
призыв к действию, его нельзя прятать за клик: он должен ловить взгляд, пока руководителя нет.

## Сводки в заголовках (словарь)

| Секция | Состояния сводки |
|---|---|
| MCP-серверы в проекте | «N из M включено» · «Ничего не включено» |
| История файлов (Git) | «Не ведётся» · «Ручная · 42 коммита» · «Авто · 128 коммитов» · «Авто · push вкл» · ошибка: «Ошибка — откройте» (danger) |
| Фон рабочего пространства | «Стандартный» · «Свой · Янтарный» · «Рисуем фон…» · «Не получилось» (danger) |
| Офлайн-доступ | «Выключен» · «Все файлы доступны офлайн» (success) · «Синхронизируется…» |

Цвета сводки: нейтральная — `C.textMuted`; «включено/работает» — `C.successText`;
ошибка — `C.dangerText` 600. Данные для сводок уже грузятся при открытии диалога
(git-статус, список серверов, фон, sync-метки) — новых запросов не появляется,
сворачивание меняет только рендер.

## Высоты (десктоп, модалка 500px)

| Состав | Было | Стало |
|---|---|---|
| Минимум (без группы/lead/MCP/фона) | ≈ 640px | ≈ 560px |
| Максимум, все секции свёрнуты | > 1100px | ≈ 750px |
| Максимум + одна секция раскрыта (git) | > 1100px + скролл | ≈ 850px |

Даже в максимальном составе диалог целиком виден на ноутбучном 768px-экране
со всеми свёрнутыми секциями.

## Спецификация для Киры

**Новый компонент `AccordionSection`** (можно прямо в EditDialog.tsx или
`features/projects/dialogs/`): обёртка `{ icon, title, summary, summaryTone?, defaultOpen?, children }`.

- Контейнер: `background: C.bgWhite`, `border: 1px solid C.border`, `borderRadius: R.xl`,
  `overflow: hidden`.
- Заголовок-кнопка: `padding: 10px 14px`, `minHeight: 44`, flex gap 10;
  иконка `C.textMuted` (15px, lucide: Plug / GitBranch / Image / Download);
  название `FS.base` 600 `C.textHeading`; сводка `FS.sm` `marginLeft: auto`,
  ellipsis; chevron `ChevronDown` 14px, `transform: rotate(180deg)` при open
  (transition 150ms).
- Hover (только десктоп): `background: C.bgSelected`.
- Тело: `borderTop: 1px solid C.borderLight`, `padding: 10px 12px 12px` —
  внутрь переезжает **существующее содержимое секций без переработки**
  (GitModeCards, список MCP-тумблеров, BackgroundSection-превью и кнопки, sync-строка).
  У самих секций снимается их текущий контейнер-карточка (она теперь = контейнер
  аккордеона) и заголовок-кэпшн (он теперь в заголовке строки).
- Состояние раскрытия — локальный `useState` на секцию, независимое;
  по умолчанию **все свёрнуты**, включая первый заход.
- Условность не меняется: `McpProjectSection` по-прежнему не рендерится без серверов,
  фон — только владельцу за флагом. Условная строка просто не рисуется.
- A11y: заголовок — `<button type="button">` с `aria-expanded`, тело — `role="region"`
  с `aria-labelledby`.

**Мобила (<768px)**: тот же компонент; заголовок и так ≥44px, hover не применять,
кнопки действий внутри раскрытых тел остаются `fullWidth` (как сейчас у фона).
Сводки можно ужать («Авто · 128», «Выкл») — в словаре выше полные варианты,
короткие берутся обрезкой чисел коммитов и хвоста.

**Не трогаем**: вложенные view 'prompt'/'rules' (отдельные Modal 620/560),
сетевое поведение секций, порядок секций.
