ВАРИАНТ C: Чипы активных фильтров + добавление

Фильтр задач — чипы всегда на виду

Гибрид: применённые фильтры живут постоянной строкой чипов под шапкой — видно, ЧТО именно отфильтровано, и каждый чип снимается одним кликом на ×. Добавление — через чип «+ Фильтр» (компактный поповер с полным составом) или кнопку Funnel в шапке. Пустая строка схлопывается до нуля. На мобиле добавление — боттом-шит, строка чипов остаётся и скроллится горизонтально.

На мобиле строка чипов остаётся (скроллится горизонтально, снятие — тапом по ×), а добавление уезжает в боттом-шит с крупными чипами и кнопкой «Показать N задач».

Плюсы

  • Лучшая обратная связь из трёх: состав фильтра читается всегда, не числом, а словами.
  • Снятие фильтра — один клик на ×, без открытия панелей и дропдаунов.
  • Пустая строка схлопывается до нуля: не тратит высоту, когда фильтров нет.
  • Масштабируется на метки: каждая метка — просто ещё один чип в строке.

Минусы

  • При 4+ фильтрах строка скроллится горизонтально — хвост чипов прячется.
  • Доступные значения не видны до открытия поповера: добавление всё ещё два клика.
  • Два места добавления (чип «+ Фильтр» и кнопка в шапке) — нужна дисциплина, чтобы не путать.

Когда выбрать

Фильтры включают надолго и часто правят по одному («убрал срочные — оставил свои»). Мой фаворит для списка задач: 34px в обмен на постоянную видимость состава.
