## Трактовка постановки

«Вкладка Окно» в запросе — это окно «Использование» (квоты, балансы). Сливаем его и «Поставщики
моделей» в один раздел «Модели и использование»: «Использование» становится первой вкладкой и
**заменяет** вкладку «Провайдеры» — статусы провайдеров переезжают в неё компактной таблицей
внизу. В меню аватара вместо двух пунктов остаётся один. Вкладка «В чате» удаляется. Если
«Окно» имелось в виду другое — скажите, поправлю.

## Проблема → решение (по пунктам)

**1. Два окна об одном.** «Использование» и «Поставщики моделей» — соседние пункты меню,
отвечающие на один вопрос «на чём и сколько я еду». Решение во всех вариантах: одна модалка,
вкладки `Использование · Модели по умолчанию · Специальности · Пресеты · Применение`.
В «Использовании» три группы: квоты подписок (полосы), балансы, все провайдеры (статус-точка,
число моделей, бейдж **«бесплатный»**, подсказка для ненастроенных).

**2. «Модели по умолчанию».** Боль: полоса чипсов-провайдеров в две строки каждый + контекст
«Общие/пользователь» в меню-кнопке. Три ответа:
- **A:** один селект «Все три уровня через: …» (в пунктах те же тройки) + слоты строками с
  триггером справа; панель выбора раскрывается под строкой. Контекст — видимые пилюли
  «Общие · Андрей · Мария · Ещё N».
- **B:** три карточки-профиля «Качество / Баланс / Эконом» — сохранённые тройки, клик
  проставляет все слоты разом. «Эконом» — бесплатная стратегия прямо в слотах. Слоты ниже —
  «тонкая настройка»; при ручной правке появляется «Сохранить как профиль».
- **C:** таблица слотов с колонкой «Где используется» (N мест) — видна цена смены слота.

**3. «Специальности».** Боль: 9 раскрывашек, внутри сетка 2×3 «Для всех/Только для меня»,
до правки 2–3 клика. Общий ход всех вариантов: **двуслойность поднимается наверх** в
переключатель «Для всех / Только для меня» — ячейки перестают быть сдвоенными, матрица
сжимается вдвое. Дальше варианты расходятся: A — таблица с триггерами в ячейках и «⚙»
(права/инструменты/уровень по умолчанию) в строке-детали; B — список со сводкой уровней в
строке + шторка настройки справа; C — нативные селекты прямо в ячейках (ноль кликов).
Наследование «специальность → любая → уровень» показано текстом, пустая ячейка — «—».

**4. «Пресеты».** Боль: все карточки раскрыты, контентная зона пустая, «личный/общий» — каша.
Решение: свёрнуты по умолчанию — имя + цепочка чипсами одной строкой + бейдж слоя («для всех»/
«мой»); редактор только у раскрытого (A) или мастер-деталь «список слева, редактор справа»
(B). Не-админ у общего пресета видит режим чтения + «Скопировать в мои». Пустое состояние —
кнопка «Создать пресет» вместо вечного черновика.

**5. «Применение» + бесплатные провайдеры.** Кнопок быстрой настройки становится три:
«Назначить автоматически» / **«Экономно · бесплатные модели»** / «Локально · Ollama».
«Экономно» проставляет местам лучшие модели провайдеров с пометкой «бесплатный» (новое поле
у провайдера; Free LLM — первый такой): сложным местам — лучшая бесплатная, простым — самая
лёгкая. Нет ни одного бесплатного — кнопка скрыта (как «С локальной моделью» без Ollama).

**6. «В чате».** Удаляется: превью подмен уже живёт в ленте чата (DividerPill), дублировать
его статичной картинкой в настройках не нужно.

## Сравнение вариантов

| | A «Строки» | B «Профили» | C «Матрица» |
|---|---|---|---|
| Смена всей тройки слотов | 2 клика (селект) | 1 клик (карточка) | 3 правки по одной |
| Точечная правка слота | 2 клика | 2 клика | 1 клик |
| Специальности: обзор | хороший (таблица) | средний (сводки) | отличный |
| Специальности: правка | 2 клика | 2 клика (шторка) | 1 клик |
| Пресеты | строки-аккордеон | мастер-деталь | как в A |
| Мобила | одна раскладка, честная | шторка поверх шторки | нужна вторая раскладка |
| Новых сущностей | 0 | профили (хранить, синкать) | 0 |
| Риск | низкий | концепция «профиля» требует поддержки | select не вмещает пресет+описание |

**Моя рекомендация — A как основа**, с двумя заимствованиями: колонка «Где используется»
из C в подсказку слота (одной строкой «3 места: новый чат, исполнитель задач…») и, при желании,
карточка «Эконом» из B как отдельный пункт быстрого селекта («Все три уровня через: … / Лучшие
бесплатные»), не как новая сущность «профиль». B красив, но «профиль» — это новый хранимый
объект поверх слотов, пресетов и мест: дорого и пересекается с пресетами-цепочками. C быстрее
всех в правке, но платит двумя раскладками (десктоп/мобила) и ужатыми подписями.

## Отклонения от системы

Новых токенов нет: цвета/размеры/радиусы — `theme.css`/`design.ts`. Новые компонентные приёмы:
(1) компактный триггер-модель в строке — уже существует как `ActionRow` в «Применении»,
просто переиспользуется в слотах и специальностях; (2) контекст-пилюли — тот же паттерн, что
чипы провайдеров сейчас, только короче; (3) бейдж «бесплатный» — готовая пара
`success-bg`/`success-text`. В B шторка специальности — тот же `PanelZone`-класс, что шторки
панелей, внутри модалки.

## Границы задачи

Макеты статичны: сохранение, `useProviderData`, роутинг — не затрагиваются. Пометка
«бесплатный» требует бэкенд-поля у провайдера (`LlmProviders` конфиг, проброс в
`/api/llm/info`) — отдельная строка в задаче Денису; без неё кнопка «Экономно» не появится.
Реализация выбранного варианта — Кира, по этому макету и гайду `docs/design/guidelines.md`.

## Итерации

1. **v1** — три варианта (A/B/C), все состояния, мобила, обе темы.

2. **Финал** ([model-providers-final.html](model-providers-final.html)) — гибрид по выбору заказчика:
   - **Использование — из A** (квоты/балансы/провайдеры с бейджем «бесплатный», без изменений).
   - **Модели по умолчанию — из C**: таблица «Уровень | Модель (инлайн-селект) | Где используется»,
     контекст «Общие / пользователь» — сегмент над таблицей. Селект «все три уровня разом» из A не
     вошёл: эту роль берут кнопки «Применения», чей смысл сменился — не «тонкая правка», а «сменить
     стратегию целиком».
   - **Специальности — из C**: матрица с инлайн-селектами, двуслойность поднята в сегмент
     «Для всех / Только для меня», «⚙» раскрывает права/инструменты строкой-деталью (приём из A).
   - **Пресеты — из A**: свёрнутые строки, цепочка чипсами одной строкой, бейдж слоя, редактор
     только у раскрытого.
   - **Применение — из A, но кнопок две вместо трёх**: «Экономно · бесплатные модели» и
     «Локально · Ollama» слиты в одну **«Экономно · бесплатные и локальные»** — локальная модель
     тоже бесплатная, отдельная кнопка дублировала смысл. Стратегия `applyPreset('tiers-local')`
     поглощается новой `'tiers-free'`: сложным местам — лучшая бесплатная (облачный «бесплатный»
     провайдер приоритетнее локали, если он есть и сильнее), простым — самая лёгкая. Видимость:
     кнопка показывается, если есть хотя бы один провайдер с пометкой «бесплатный» ИЛИ настроена
     Ollama; иначе — disabled с подсказкой (показано в §4 финала).
   - **Токены приведены к действующим**: в финале — точная копия значений `theme.css` для обеих
     тем (исправлены отклонения черновиков: `--c-dashed`, `--c-overlay`, `shadow-dropdown/modal/sheet`),
     ширина модалки — `MODAL_W.wide = 720px` (в черновике C было 760), шрифты/отступы/радиусы —
     только шкалы `FS/SP/R/SHADOW` из `design.ts`. Новых токенов по-прежнему нет.

3. **Финал, правки после приёмки** (фон окна, полнота «Использования», список специальностей):
   - **Фон модалки исправлен на `C.bgMain`** (кремовый в светлой теме) — ровно как в
     `ui/Modal.tsx`; белым он быть не может, `C.bgWhite` остаётся только у контентных поверхностей
     внутри (чипы окон, таблицы, строки, пилюли). Заголовок — PT Serif 22px (мобила 21), вес 500,
     отступы 28px — метрики штатной модалки, собственных стилей окна при реализации не нужно.
   - **«Использование» — перенос без потерь.** Во вкладку переехало всё содержимое нынешнего
     `UsageScreen.tsx`: строка-вывод «Ближе всего к пределу…», раскрываемые строки квот с чипами
     окон (шкала, сброс, бейдж «Исчерпано»), свежесть данных, бейдж роутинга и «Тариф: Max»,
     тренды-спарклайны, плитки денег с историей и «пополнить ↗», группа «Кредиты», полоса
     «Наш расход» с периодом и «Подробная аналитика →», состояния «не удалось получить» /
     протухшие данные (приглушённая шкала) / пустое состояние. «Не подключены» растворились в
     полосе «Все провайдеры» (ключ конфига у ненастроенного). Новинка слияния — только бейдж
     «бесплатный».
   - **Специальности — все 12 видны сразу.** Ссылка «показать все» убрана: все специальности из
     `SpecialtyCatalog` (+ строка «Любая») — в одной прокручиваемой таблице с липкой шапкой,
     бейдж вкладки 12. На мобиле — те же карточки списком с прокруткой внутри шторки.
   - **Строки квот — бегунки до клика (приём из черновика A).** Свёрнутая строка провайдера
     показывает мини-шкалы окон с подписями и процентами («окно 62%», «неделя 31%») — статус
     читается без раскрытия; клик открывает детали: чипы окон со сбросами, бейдж роутинга и
     тариф, тренд-спарклайн, кабинет. На мобиле бегунки переносятся под имя провайдера.

4. **Вариант v2 «приборная панель»** ([model-providers-v2.html](model-providers-v2.html)) —
   полная переработка оптики диалога по заказу «примени дизайнерские навыки на полную»:
   - **Смена оптики: от «настроек» к «пульту».** Первый экран отвечает на вопрос «всё ли в
     порядке?»: вердикт-полоса с главным событием дня и кнопкой-переходом «К квотам →», лента
     KPI (горячая квота / деньги на счетах / расход за период / мест на бесплатных моделях),
     диаграмма «Расход по дням» в реальных цветах провайдеров. Вкладки — маршруты мысли
     пользователя: «Обзор → Использование → Маршруты → Специальности → Пресеты → Применение».
   - **Слоты переосмыслены как маршруты.** «Модели по умолчанию» показывает не три селекта,
     а три цепочки-пересадки: слот = ссылка на пресет, раскрытие показывает полную цепочку
     и счётчик мест, которые она обслуживает («Выбор сменит маршрут для 10 мест»).
   - **Пресеты — схема пересадок.** Шаги цепочки пронумерованы, у каждого виден провайдер
     и источник оплаты (квота / $-цены / бесплатно); описание пресета — поле ввода.
   - **Специальности — фильтр «С настройками».** Матрица по умолчанию показывает всех, но
     чип-фильтр «С настройками · 2» оставляет только строки с переопределениями — редкая
     настройка больше не тонет в списке из 14.
   - **Все примеры — живой снимок прода на 07.08.2026**, а не выдуманные плейсхолдеры:
     квоты (Claude 2: неделя 99%, сброс сегодня в 18:00; GLM 79/81; Kimi 5/54), балансы
     (DeepSeek $39.75 свежий, OpenRouter $10.00 протух «на 31 июля» — реальный кейс stale),
     «квота недоступна» у Alibaba (реальный кейс), цепочки пресетов «Основной — Сильный /
     Средняя / Слабая» из `specialty-settings.json`, переопределения специальностей
     (Дизайнер глобально, Исполнитель у владельца), назначения мест из `local-actions.json`
     (37 из 47 фоновых мест на FreeLLM), цвета — `GROUP_COLORS`/`SOURCE_COLOR` из
     `UsageScreen.tsx` (glm→0, minimax→1, claude→2, …). Состояния §4 (протухшие данные,
     лимит, недоступная квота) построены на этих же реальных случаях.

5. **Версия v3 «Три вкладки»** ([models-spend-v3.html](models-spend-v3.html)) — структурная
   пересборка v2 под утверждённую постановку. Оптика v2 сохранена целиком (вердикт-полоса,
   KPI-лента, карточки квот, слоты-маршруты, схема пересадок); поменялся скелет раздела:
   - **Раздел переименован в «Модели и расход», вкладок стало три:** «Квоты и деньги ·
     Модели по умолчанию · Применение». Вкладки «Пресеты», «Специальности», «В чате» удалены
     как самостоятельные — их содержимое растворено в оставшихся трёх.
   - **Пресеты растворены в слотах.** Цепочка правится прямо внутри раскрытого слота: шаги
     пронумерованы, двигаются ↑↓, удаляются ✕. «Сохранить как пресет…» появляется только в
     dirty-состоянии (цепочка разошлась с пресетом-источником) — пресет нужен, чтобы применить
     цепочку во втором месте; для одного слота хватает «Сохранить». Сами пресеты остаются
     в списках выбора модели — и в слотах, и в исключениях.
   - **Специальности → свёрнутый блок «Исключения»** внизу «Моделей по умолчанию»: пустое —
     «Исключений нет · настроить», текущее — «Исключения · 2». Раскрытие — та же матрица
     с фильтром «С настройками · 2» и сегментом «Для всех / Только для меня». Две настройки
     из четырнадцати не заслуживают вкладки.
   - **Диаграмма «Расход по дням» заменена ссылкой «Подробная аналитика →»** (диаграмма
     переедет в этап 2). Первая вкладка отвечает на «всё ли в порядке», а не «как менялся
     расход» — карточка-переход занимает одну строку вместо целой полосы.
   - **Пустые слоты показаны честно.** На проде tier:strong и tier:weak не назначены ни одному
     месту: слоты «Сильная» и «Слабая» показывают «0 мест · работает только через уровень
     у персон и задач» и подсказку-переход «Назначьте её исполнителю задач или сложным
     местам →» на вкладку «Применение». Пустота читается как состояние, а не как поломка.
   - **Новые данные провайдеров** (коммиты 532de244/81ad52ed, поле `Note` типизируется):

   **Правки приёмки (v3.1, 07.08.2026).** Структура не тронута, четыре точечные правки —
     все три «честных замечания» выше закрыты:
   - **KPI «Расход за 5 дней» переформулирован в «По тарифам API · 5 дней»** со значением
     «$3 411» и подписью «столько стоил бы тот же объём». Выбран честный вариант, а не
     «Сэкономлено подпиской»: в данных разделения по источнику оплаты нет — сумма считается
     по тарифам по всем ходам скопом, включая реально оплаченные деньгами (DeepSeek,
     OpenRouter), поэтому «сэкономлено» было бы таким же враньём, только приятным. Слово
     «расход» из плитки убрано вовсе (в «Деньгах» остаётся — там это настоящие траты).
   - **Лимит ключа OpenRouter убран из «Квот подписок»** — остаётся только в «Деньгах»,
     пределом со шкалой и предупреждением. Одно число, показанное в двух местах разными
     единицами (% и $), читалось как два разных лимита. У не-админа карточка лимита тоже
     убрана: лимит ключа — про деньги, а денег в его виде нет.
   - **Две KPI про бесплатное слиты в одну:** «Бесплатно работают 37 из 47 · успех 94%» —
     обе отвечали на один вопрос «как мне живётся на бесплатном». KPI стало четыре,
     теснота на 720px ушла сама, резать плитку тарифов не понадобилось.
   - **Счётчик параллельных сессий Kimi убран с поверхности карточки в раскрытие** —
     «занято 3 из 5» меняется поминутно, пользователь на это не влияет и решений по этому
     не принимает. Вид (ряд сегментов, не шкала расхода) и подпись «моментальный снимок,
     не расход» сохранены в деталях карточки.
