Редактор картинок — v2

Новая раскладка: слева — все инструменты сворачиваемыми секциями, в центре — холст, справа сверху — поле промпта, под ним — настоящий чат проекта, привязанный к картинке. «Обсудить с Claude» больше нет: его заменяет чат, из которого агент сам запускает генерацию или предлагает промпт. Описание — image-editor-v2-proposal.md.

Верхняя строка — управление макетом, не часть продукта. На холсте можно рисовать по-настоящему.

Сценарий А — агент запускает сам: в чате нажмите подсказку «Убери вон ту лампу и сделай вечер» (или напишите своё и отправьте) → ответ агента, промпт появляется в поле сверху, агент сам меняет модель и число вариантов (видно слева в «Чем рисовать» и у поля «Вариантов»), в ленте карточка «Запущена генерация · ≈ $0.10 · 2 варианта» со строкой «Изменил: модель → FLUX Fill, вариантов: 2» и «Отменить» → по готовности «Показать варианты».
Сохранить как: в вариантах (или «Сохранить как…» в шапке) → диалог: имя, папка, расширение по формату. Выберите папку images/generated/ — имя hero.v2.png там занято: предупреждение и «Взять hero.v3.png». Впишите своё имя и выберите images/blog/ → тост «Сохранено в проект: …» → «Показать в дереве» подсвечивает файл. Редактор и чат переходят на новый файл — это видно в первой строке ленты чата. «Применить» сохраняет сразу, без диалога, следующей версией рядом.
Тихие строки: ручной запуск «Сгенерировать» или быстрого действия пишет в ленту «Вы запустили: …». Снимок холста прикладывается к сообщению, только если холст изменился с прошлого сообщения — иначе чип в композере «без изменений».
Сценарий Б — агент предлагает: подсказка «Придумай промпт для обложки блога» (или любое сообщение со словом «придумай») → карточка промпта с «Вставить в промпт» и «Сгенерировать».
Остальное: секции слева сворачиваются по заголовку; «Образцы» → «+ Образец» → «С компьютера» / «Из файлов проекта…», роль под образцом, крестик удаляет. Композер: «+» — вложения, чип персоны — выбор собеседника (только здесь, как в основном чате), микрофон — голос. Шапки у чата нет: текущий файл назван в первой строке ленты, под ней после первого сообщения — «Новый чат» и «↗ Открыть в полном чате». Стрелка «назад» в шапке → экран проекта: чат картинки виден в списке чатов, «Редактировать» открывает его снова. На «Телефон 390» — холст на весь экран, промпт снизу, «Инструменты» и «Чат» — шторки.
