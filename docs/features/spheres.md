# Сферы

> Для людей и персон. Решения и цена — [ADR-024](../adr/ADR-024-spheres.md). Работает за флагом `spheres` (меню «Экспериментальные функции»); выключен — всё как раньше, сферы остаются обычными группами проектов.

## Что это

**Сфера** объединяет проекты одной темы («Банк», «Дом»). У неё своё имя, цвет, значок, **устав** (поле «Чем занимается сфера»), команда персон и память — они живут дольше любого проекта. Проект без сферы называется «Без сферы».

Сферы — это бывшие **группы проектов** на вкладке «Проекты»: существующие группы становятся сферами на месте, данные не переносятся. Проект входит в сферу и выходит из неё через меню проекта: «Перенести в сферу…» и «Убрать из сферы» (подтверждение — если у сферы есть команда). **Состав сферы меняет только человек**: персона через MCP этого сделать не может.

## Три зоны персоны

В форме персоны зона выбирается одним списком с группами:

| Зона | Что видит персона |
|---|---|
| «Во всех моих данных» | все проекты владельца (глобальная) |
| «В сфере «Банк»» | проекты сферы — их файлы, задачи, знания; состав динамический |
| «В проекте «…»» | один проект |

Персона сферы доступна во всех проектах сферы (список персон, @упоминания, чаты). Проект вошёл в сферу — персона его видит, вышел — перестаёт со следующего вызова. Если зона персоны пуста (флаг выключен, сфера удалена) — она не видит ничего, а не «всё». Зону персоны сферы меняет только человек в интерфейсе.

## Граница MVP

Зона сужает **файлы, задачи и знания проектов**. **Заметки и самостоятельные базы знаний по зоне пока не сужаются** — персона сферы видит их так же, как до сфер. Не входят в первую версию: чат сферы, «наследие проекта» при архивации, заметки сферы, наследование настроек проектом, дайджест.

## Две полки памяти

- **Память проекта** — как раньше.
- **Память сферы** — отдельная полка; её читают персоны сферы и глобальные персоны. В проекте сферы recall складывает обе полки; ключ полок — проект текущего чата.
- Писать в память сферы могут персоны этой сферы и глобальные. Автообучение в сферу не пишет.
- **«Перенести в сферу»** (человек — кнопкой, персона — `sphere_memory_adopt`) **перемещает** запись из памяти проекта в память сферы, а не копирует. Если процесс упадёт между двумя шагами, запись может оказаться на обеих полках.

Инструменты `sphere_memory_search/list/remember/forget/adopt` появляются у агента только при включённом флаге.

## Устав

Текст устава входит в системный промпт каждого хода в проектах сферы как стабильная секция: конвенции, тон, запреты темы наследуются без копирования. Правка устава, состава команды и переключение флага перезапускают CLI чата.

## Проект ушёл из сферы

Чат с персоной сферы в проекте, который из сферы вышел, не продолжается — персону молча не подменяем. Ход получает отказ:

> {Имя} работает только в проектах сферы «…». Смените собеседника.

с кнопкой «Сменить собеседника»; вернуть проект в сферу — через меню проекта. Задача с таким исполнителем вне зоны не стартует по той же причине.

## Удаление сферы

- Пока в сфере есть **персоны сферы**, удалить её нельзя (409): их нельзя молча расширить до глобальных — сначала переведите их в другую зону или удалите.
- Иначе сфера удаляется **вместе с памятью** — стор и датасет Dify; один диалог «Удалить сферу и N записей памяти».
- Проекты остаются, переходят в «Без сферы».

## Известные ограничения

- У страницы сферы нет собственного URL.
- Выключили флаг — агент-файлы персон сферы остаются в `.claude/agents` проектов до ручной очистки (данные не утекают).
