# Редизайн пикера инструментов в привязках персоны

## Проблема
Шаг «Цель» для типа «Инструмент» (`TargetPicker` в `PersonaBindingsPanel.tsx`) сейчас
показывает плоский список строк `PickRow` без иконок, без групп и без индикации
текущего состояния инструмента у персоны. Пользователь не видит:
- включён ли инструмент по умолчанию (через `Persona.Tools` / пресет роли);
- выключен ли он уже привязкой `off`;
- уже ли есть привязка и в каком режиме.

Это ведёт к дублирующим привязкам и неосмысленному выбору режима.

## Решение
Показывать каталог инструментов как группированный список строк,
где каждый инструмент несёт:
1. Собственную иконку в стиле `BindingTypeIcon` — цветная круглая
   подложка с тоном группы.
2. Текущее состояние у этой персоны: «включён по умолчанию», «выкл»,
   «привязка: авто/всегда/выкл».
3. Группировку по смыслу: Базовые, MCP-серверы, Рабочее пространство,
   По специальности, Опасные.
4. Для уже привязанного инструмента — не дублировать, а открывать шаг 3
   с текущим режимом для редактирования. Кнопка «Добавить привязку»
   меняется на «Сохранить изменения».

## Группы инструментов (по `ToolCatalog`)
- **Базовые**: tasks, notes, web (гейтятся `Persona.Tools`, по умолчанию включены).
- **MCP-серверы**: personas, consultants, codegraph, notifications, widgets
  (включаются только привязкой).
- **Рабочее пространство**: projects, chats, files, knowledge.
- **По специальности**: git, kb, personas-manage, personas-automation,
  notes-annotations, browser (дефолт зависит от `Persona.Specialty`).
- **Опасные**: destructive (визуально отграничен: danger-фон, иконка, предупреждение).

## Состояния строки
| Состояние | Визуал | Действие по клику |
|---|---|---|
| Включён по умолчанию | Мягкий success-тон / текст «включён по умолчанию» | Переход на шаг 3, режим `auto` по умолчанию; при сохранении добавляется привязка, которая переопределяет дефолт. |
| Выкл (без привязки) | Muted текст «выключен в настройках персоны» | Переход на шаг 3; режим `auto`. |
| Уже есть привязка | Бейдж режима (`авто`/`всегда`/`выкл`) + подсказка | Открыть шаг 3 с текущим режимом; кнопка «Сохранить изменения» вместо «Добавить». |
| Опасный (destructive) | Danger-фон группы, предупреждение перед шагом 3. | Дополнительная пометка в шаге 3: «Безвозвратное удаление». |

## Состояния экрана
- **Загрузка**: скелетон-список из 6 строк с серыми плашками.
- **Пусто / не найдено**: текст «Ничего не найдено» / «Список пуст» внутри карточки.
- **Ошибка**: красная строка с кнопкой «Повторить».

## Мобильная раскладка
- Группы сохраняются.
- Строка растягивается на всю ширину, тач-цель не меньше 44 px.
- Длинные подсказки переносятся, label и hint не обрезаются ellipsis.
- Темы: светлая/тёмная переключаются через `data-theme`.

## Итерации
1. v1 — групповой список, минимум изменений в коде.
2. v2 — двухзонный layout: каталог слева, текущие привязки справа (desktop) / стек (mobile).
3. v3 — карточки с inline-переключателем режима, убирает отдельный шаг 3 для инструментов.

## Рекомендация
Начать с **v1**. Он вписывается в существующий `TargetPicker`
без переделки степпера, но решает главную боль (состояние + группировка).
v2 стоит рассмотреть, если список привязок у персоны длинный и хочется
видеть контекст рядом. v3 — если решим, что для инструментов не нужен
отдельный шаг условия, а режим можно менять сразу.
