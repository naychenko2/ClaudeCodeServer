CSP: frame-ancestors

developer.mozilla.org · обновлено 12 марта 2026

Директива frame-ancestors задаёт родителей, которым разрешено встраивать страницу через <frame>, <iframe>, <object> или <embed>.

Синтаксис

Content-Security-Policy: frame-ancestors 'none'

Значение 'none' запрещает встраивание кому угодно — именно его отдают GitHub и Stack Overflow.

  • 'self' — только собственный origin;
  • <host-source> — перечисление доменов;
  • 'none' — запрет для всех.

Иконка панели в рельсе — Newspaper, подпись «Чтение». Активная панель подсвечена accentLight, как остальные.

Очень длинная строка без пробелов

https://developer.example.com/docs/Web/HTTP/Headers/Content-Security-Policy/frame-ancestors?utm_source=chat&utm_campaign=very-long-tracking-parameter-value

Переносится по любому символу (overflow-wrap: anywhere) — горизонтальной прокрутки у прозы не бывает.

Код шире панели

Content-Security-Policy: default-src 'self'; frame-ancestors 'none'; script-src 'self' 'nonce-r4nd0m'; img-src 'self' data: https://cdn.example.com

Блок кода и таблица прокручиваются каждый в своей коробке, страница по горизонтали не едет.

Длинный заголовок в шапке обрезается ellipsis в одну строку; полный — в title и первой строкой статьи.
