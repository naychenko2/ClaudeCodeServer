# Автозакрытие попапов чата при переключении чатов

## Проблема

Пользователь открывает попап в тулбаре чата (поповер чипа контекста/стоимости, меню тегов, поповер участников, меню «Зафиксировать» в гит-баре), затем переключается на другой чат в списке. Попап **остаётся открытым** и показывает данные предыдущего чата.

Корень: `ChatPanel` не перемонтируется при смене сессии. `Composer` защищён вручную (`key={session.id}`, `ChatPanel.tsx:1936`), а компоненты тулбара — нет, их локальные стейты попапов переживают переключение.

## UX-правило

Попап, привязанный к данным конкретного чата, **не переживает переключение чата** — закрывается мгновенно при смене `session.id`. Попапы уровня приложения (меню «Разделы» в хабе, фильтры списков) не привязаны к чату и не трогаются.

## Спецификация для реализации (Кира)

### 1. `BadgeShell` — проп `resetKey` (`chat/ChatHeaderBar.tsx:106`)

```tsx
function BadgeShell({ ..., resetKey }: { ...; resetKey?: string }) {
  const [open, setOpen] = useState(false);
  // Попап показывает данные конкретного чата — при смене чата закрываем
  useEffect(() => { setOpen(false); }, [resetKey]);
```

Все использования в `ChatHeaderBar` (`CostBadge` :251, `ProviderCostBadge` :360, `CtxBadge` :504, `FalCostBadge` :575, `GlifCostBadge` :641, объединённый `MobileCombinedBadge` :723) получают `resetKey={session.id}` — пробросить из пропсов бара.

### 2. Остальные попапы бара — один эффект (`ChatHeaderBar.tsx`, у стейтов :949/:982)

```tsx
// Автозакрытие попапов тулбара при переключении чата
useEffect(() => { setTagMenu(null); setParticipantsOpen(false); }, [session.id]);
```

### 3. Гит-бар — меню области коммита (`ProjectGitBar.tsx`)

`useEffect(() => setCommitMenu(null), [session?.id])` — рядом с существующим keydown-эффектом.

### Что НЕ меняем

- `Composer` и его меню — уже закрываются через `key={session.id}`.
- Попапы хаба/списков (меню «Разделы», фильтры) — не привязаны к чату.

## Проверка

1. Открыть поповер чипа контекста → переключить чат → поповер закрыт.
2. То же для меню тегов и меню «Зафиксировать».
3. Переключение между двумя чатами одного проекта и между проектами — попапы закрыты в обоих случаях.
4. Повторное открытие попапа в новом чате работает штатно (стейт не «залип»).
5. `npx tsc -b` зелёный.
