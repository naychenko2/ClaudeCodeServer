Поле маршрута: состояние ошибки

Форма ручного ввода маршрута локального действия в разделе «Поставщики моделей». Пользователь ввёл значение, не подходящее ни под один формат маршрута — поле подсвечено, под ним конкретный текст ошибки и всегда видимая подсказка о форматах, кнопка «Сохранить» заблокирована. Все цвета — из design.ts / theme.css, новых токенов нет (добавлен один производный --shadow-focus-danger — мягкое danger-свечение той же геометрии, что focus-ring).

1. Ошибка в контексте формы · светлая и тёмная

Карточка-остров маршрута лежит на фоне модалки «Модели и расход» (C.bgMain). Значение tier:powerful — префикс верный, но уровень не из списка (strong / medium / weak). Слева от поля — ссылка «Выбрать из списка»: она открывает RoutePicker, где префикс подставляется сам, поэтому ручной ввод нужен только для редких случаев.

2. Тексты ошибок под вариант ввода

Один стиль подсветки — разные сообщения. Текст всегда называет, что именно не так, и даёт починку. Так пользователь не гадает по красной рамке, а читает, что исправить. Сообщения совпадают с классификацией маршрута на бэкенде (LocalActionOverridesStore, LocalActionsAdminController).

tier:powerful Неизвестный уровень. После tier: ждём strong, medium или weak.
strong Пропущен префикс. Уровень задаётся как tier:strong — выберите его из списка, и префикс подставится сам.
preset: Не указан пресет. После preset: нужен id пресета, например preset:eco-chain.
preset:old-name Пресет не найден среди общих пресетов. Место общее — личный пресет сюда не подставить.
direct: Не указана модель прямого адаптера. После direct: — id модели, например direct:glm-4.7.
glm 4.7 В id модели не может быть пробелов. Подразумевалось glm-4.7 или glm4.7?
claude-sonnet-55 Модель отсутствует в каталоге. Проверьте id — доступные модели приходят в /api/models.
local Локаль недоступна этому месту. Агентным местам («Чаты и персоны») нужна агентная модель — локальная и direct: не подходят.

3. Состояния поля (для сравнения)

Ошибка — отдельное состояние со своим цветом рамки и фона, а не «красный фокус». Фокус остаётся акцентным (оранжевым); ошибка — danger (красно-кирпичный). Успех не кричит: тонкая success-рамка, без заливки — для ошибки подтверждение важнее, поэтому «ок» живёт только в активной кнопке.

4. Уже сохранённый кривой маршрут

На проде уже лежит кривой маршрут (ввели до валидации). В списке действий он подсвечивается danger-цветом прямо в строке — не маскируется под обычное значение. Клик по строке открывает ту же форму с предзаполненным значением и ошибкой — починить можно в один шаг.

tier:powerful сохранён кривой маршрут · «powerful» не существует
До исправления действие идёт по фолбэку (выбранное → локаль → claude) — значение не блокирует работу, но висит как долг.

6. Спецификация для реализации

Токены (без нововведений).
Рамка ошибочного поля — C.danger; фон — C.dangerBg; текст ошибки — C.dangerText, FS.sm; подсказка о формате — C.textMuted, FS.xs. Геометрия поля — существующий FIELD-токен (C.bgWhite, R.xl, padding 10px 13px), шрифт моно — FONT.mono, т.к. в маршруте важны двоеточия и регистр. Иконка ошибки — lucide-react CircleAlert 14px.

Один производный токен. --shadow-focus-danger — то же, что shadow-focus, но цветом C.danger вместо C.accent. Завести в theme.css для обеих тем (значения уже есть в шапке этого макета).
Состояния и поведение.
• Валидация — по blur и по изменению после первой ошибки (не на каждое нажатие: иначе краснеет во время набора).
• aria-invalid="true" + aria-describedby связывают поле с текстом ошибки.
• Кнопка «Сохранить» (Button primary) — disabled, пока значение невалидно; существующий disabled-стиль компонента (opacity .55, без shadow-button).
• Ссылка «Выбрать из списка» открывает RoutePicker: выбор оттуда подставляет корректный маршрут с префиксом — ручной ввод уходит.
• Ошибка снимается, как только значение стало валидным; success-рамка (C.success) — необязательна, подтверждение живёт в активной кнопке.
• Список действий: сохранённый кривой маршрут подсвечивается C.dangerText на C.dangerBg прямо в строке — не маскируется под значение.
Мобила. Шторка R.sheet на C.bgMain, поле на всю ширину, кнопки в столбик во всю ширину, tap-цели ≥ 40px. Тёмная тема — те же токены, отдельной вёрстки нет: C.dangerBg/C.dangerText/C.danger заведены в :root[data-theme="dark"] с проверкой контраста (dangerText на bgCard ≈ 5.4:1, AA).
