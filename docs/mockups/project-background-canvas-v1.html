Цвета проектов — палитра имён

Генератор подбирает цвет по смыслу и даёт ему имя. Нимб холста собирается из rgb-триплета цвета; тушь дудла остаётся нейтральной. Ниже — примеры пар «цвет → имя» для свайл-превью и диалога.

изумрудный#5E8B4E
морской#1A9DAF
сливовый#6C5CB0
терракотовый#D97757
горчичный#8A6A28
индиго#3E7CA6
кирпичный#B4452F

Стандартный и сгенерированный — рядом, светлая тема

Слева — сегодняшний нейтральный холст (оранжевый нимб ISLAND.glow). Справа — сгенерированный: нимб цвета проекта + дудл по смыслу. Цвет виден в зазорах между островами и сквозь полупрозрачные msgBg-пузыри — лента остаётся читаемой.

Сгенерированный фон — тёмная тема и длинная переписка

Та же история в тёмной теме: тушь дудла светлеет одним токеном --canvas-ink, нимб остаётся изумрудным. Ниже — длинная переписка: несколько сообщений, длинный ответ ассистента, блоки правок. Лента лежит на полупрозрачных msgBg-листах — цветной холст просвечивает, текст остаётся читаемым.
