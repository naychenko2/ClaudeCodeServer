Ошибки прошлых дней сворачиваются под кат

Дефект F9: в чате «Приветствие» на 832 висят три полноразмерных красных баннера от 13 августа (скриншот 03-chats-empty.png). Каждый — case 'error' из ChatItemView.tsx:1714 во всю ширину. Ошибка недельной давности — уже не тревога, а архив; но вес у неё в ленте как у свежей. Предложение: сегодняшние ошибки остаются полными баннерами, прошлых дней — собираются в компактную группу «Завершённые с ошибкой».

Краевые случаи

Одна ошибка за день — группа не создаётся: одиночная запись прошлого дня сразу рисуется компактной строкой (без заголовка-ката). Ошибки разных дней — своя группа на каждый день, живёт под своим дневным разделителем. Свежая ошибка пришла — сегодняшние всегда баннеры; в полночь вчерашний баннер при следующем открытии чата переедет в группу. Ошибка с «Повторить», пока ход идёт — не сворачивается никогда, правила видимости canRetry && online не меняются.

Спецификация для Киры

1. Группировка на уровне построения ленты (ChatPanel, до рендера ChatItemView): ошибки (type === 'error') с датой < сегодня склеиваются в { type: 'error_group', date, items: ChatItem[] } по каждому дню. Сегодняшние error проходят как раньше.
2. Новый case 'error_group' в ChatItemView.tsx: заголовок — карточка C.bgCard/C.borderLight, радиус R.lg; треугольник ▶ с поворотом 90° при раскрытии (PANEL_ANIM); счётчик — плашка C.dangerBg/C.dangerBorder/C.dangerText. Состояние раскрытия — локальный useState, в историю не пишется.
3. Строка ошибки: фон C.dangerBg, рамка C.dangerBorder, радиус R.md, текст FS.sm одной строкой с ellipsis (+ title с полным текстом на десктопе; на тач длинный текст открывается тапом по строке — раскрывается до полного). Кнопка повтора 26×26, те же условия canRetry && online, тот же обработчик, что у «Повторить» баннера.
4. Одиночная ошибка прошлого дня рендерится той же компактной строкой без группы.
5. Тёмная тема: цвета только из шкалы danger* — в обеих темах уже есть. Регрессия: сегодняшний баннер и session_ended не тронуты.
