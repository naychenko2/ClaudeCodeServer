360 · первый экран фичи

R1 · три пресета вместо девяти чипов. «Меня ждут» = ждут + остановлены, «В работе» = идут + очередь + пауза, «Все» = открытые. Тонкий выбор по видам — в поповере фильтра как раньше.Теряем: один клик до «только на паузе».
R2 · строка фичи в две строки. Название и %, одна фраза состояния, полоса 3 px. Аватары, ⚠N и давность ушли.Теряем: ⚠ расхождения трекера в списке — он остаётся на странице фичи.
R4 · тег состояния один. Он в тулбаре, а в сводке тега и «обновлено» больше нет.Ничего не теряем: тулбар видно всегда.
R6 · действие одно. Кнопка «Ответить / Мерж…» стоит только в полосе тревоги. В тулбаре и сводке её нет.Ничего не теряем: тревога есть на всех вкладках.
R7 · срок одной строкой. Источник, альтернатива и «почему» открываются по «почему ›».Теряем: разбор оценки на виду. По сути это справка.
R8 · «Разбор» = История + Статистика. Это ретроспектива: одна вкладка, внутри переключатель «Лента · Цифры».Теряем: один клик до статистики.
R9–R11 · «Ход» без шкалы по умолчанию. Этапы списком, у текущего — кто сейчас работает. Дорожки и ось — по «на шкале времени».Теряем: паузы и интервалы с первого взгляда. Они нужны в разборе, а не каждый день.
