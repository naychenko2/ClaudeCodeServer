1 · Дашборд-инспектор (админский режим, pivot по умолчанию)

Сценарий: «на что ушли токены в июле?» — раскрываешь дерево, панель справа всегда показывает выбранный узел; выбран ход — его паспорт. Скелет «Инспектора» (B) дополнен двумя строками из «Полотна» (C): pivot-цепочка задаёт порядок уровней дерева, фильтры-чипы сужают данные. Всюду только токены — стоимость в деньгах не показывается нигде. Персональный режим — то же дерево без уровня «Пользователь».

2 · Pivot: пользователь сам собирает иерархию

Порядок уровней дерева — как в сводных таблицах: чипы перетаскиваются (⋮⋮), удаляются (×), добавляются из меню «+ уровень». Разрезы: пользователь (только админ-режим), проект, чат/задача, персона, провайдер, модель, источник. «Ход» — всегда терминальный уровень: его нельзя поставить в середину, он существует только внутри детального окна — чип нарисован пунктиром с подписью окна. Если pivot закончился агрегатом (без «хода»), паспорт узла предлагает «Показать ходы среза» — тоже только в пределах окна. Фильтры-чипы и pivot независимы: фильтр сужает данные, pivot задаёт порядок группировки.

3 · Паспорт узла-агрегата — один шаблон на любой уровень pivot

Панель справа не зависит от раскладки: выбран проект, модель или персона — сводка одинаковая: токены за период, средний ход, стек источников, топ моделей, динамика. За границей окна динамика приглушена и отделена пунктиром. Бесплатные модели — просто серия источника (зелёная), без денежной подачи. У fal.ai токенов нет — он показывается счётчиком генераций вне шкалы токенов.
