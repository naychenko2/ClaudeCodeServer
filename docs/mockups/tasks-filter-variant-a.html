Фильтр задач — поповер из шапки

Кнопки Plus (новая задача) и Funnel (фильтр) переезжают в шапку панели, dashed-кнопка во всю ширину уходит. По клику на Funnel — дропдаун поверх списка с полным составом фильтров. Активный фильтр виден по бейджу-числу на кнопке (счёт по группам: Статус + Исполнитель = «2»). Шапка остаётся drag-хендлом: контролы компактные (26–28px) и помечены draggable=false.

На мобиле поповер не работает (нет места справа) — фильтр уезжает в боттом-шит с крупными tap-целями и кнопкой «Показать N задач».

Плюсы

  • Привычный паттерн дропдауна, повторяет ToolbarOverflowMenu доски — переиспользуем поведение.
  • Не ест высоту списка: закрытый фильтр не занимает ни пикселя.
  • Весь состав фильтров в одном месте, легко расширить (метки добавятся секцией).

Минусы

  • Слабая обратная связь: при закрытом поповере видно только число, а не ЧТО отфильтровано.
  • Снять один фильтр — два клика (открыть, ткнуть чип).
  • Перекрывает верх списка — на короткой панели закрывает первую группу задач.

Когда выбрать

Фильтрация — эпизодическое действие («нашёл и закрыл»), панель узкая, важно сохранить максимум высоты под задачи. Самый дешёвый в реализации вариант.
