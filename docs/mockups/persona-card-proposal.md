# Карточка персоны: хедер и контентная зона

Макет: [persona-card-v1.html](persona-card-v1.html) — обе темы (переключатель в шапке),
ширины 560 / 832 / 1100 / 390, пустое состояние и загрузка.

Поводом стал прогон на узком контейнере: карточка персоны в центральной зоне воркспейса
при открытых боковых панелях. Разбор показал три дефекта хедера и два — контентной зоны.

## Проблема

### H1. Из карточки нет выхода (блокер)

`PersonasPage.tsx:244,255` отдаёт стрелку «Назад» только мобиле
(`onBack={isMobile ? clearSelection : undefined}`), а проп `onClose` у `PersonaToolbar`
не передаётся ни разу — крестик не рисуется нигде. Расчёт был на список персон рядом:
ушёл из карточки, выбрав другую. При зажатом панелями контейнере списка не видно, и
карточка становится ловушкой — выйти можно только через общую навигацию приложения.

### H2. Хедер не умеет сужаться

`Toolbar` (`components/Toolbar.tsx:29`) — одна строка `display:flex` с фиксированной
высотой и без `flexWrap`. Внутри всё, кроме блока идентичности, объявлено `flexShrink: 0`:

| Элемент | Ширина | Сжимается |
|---|---|---|
| Аватар | 32–40 | нет |
| Идентичность (роль/имя/бейджи) | `flex:1, minWidth:0` | **до нуля** |
| «✎ Редактировать» | ~150 | нет |
| ⋮ | 32 | нет |
| PillSwitch, 5 вкладок с подписями | ~360 | нет |
| ✕ Закрыть | 32 | нет |

Сумма несжимаемого — около 600px. Контейнер уже — и содержимое выдавливается за правый
край: первыми уходят «Память», «Задачи» и крестик, то есть ровно то, чем закрывают карточку.

### H3. Наезд действий на идентичность

Следствие H2: блок идентичности схлопывается в ноль, и его вторая строка
(«Проект · Здоровье», бейдж зоны, «★ по умолчанию») визуально ложится под кнопку
«Редактировать».

### C1. Лента активности душит визитку

`PersonaPreview.tsx:825` — `aside { width: 300, flexShrink: 0 }` против
`mainColumn { flex: 1, minWidth: 0 }`. Промежуточного порога между «мобила ≤600» и полным
десктопом нет, поэтому на контейнере 560 визитке остаётся ~110px и заголовок рвётся по
слогам: «Коорди / натор / програ / ммы».

### C2. Одно и то же показано трижды

Вкладка «Профиль» содержит развёрнутые превью четырёх других вкладок — «Умения и правила»,
«Проактивность», «Память», «Задачи». Те же сущности ещё раз перечислены чипами фактов
сверху. В сумме девять секций подряд: чип → секция-превью → собственная вкладка.

## Решение

### Хедер — приоритетная деградация

Порядок исчезновения задаётся явно, а не достаётся случайно от порядка в разметке:

1. «Редактировать» теряет подпись → карандаш;
2. вкладки уходят во вторую строку, во всю ширину, с горизонтальным скроллом;
3. идентичность обрезается многоточием до пола `minWidth: 140`;
4. бейджи «Проект» и «★ по умолчанию» сокращаются до иконок.

Выход из карточки и ⋮ не исчезают ни при какой ширине. Выход встаёт **первым элементом
слева** — не последним справа, где он и уезжал за край.

Перенос — `flexWrap: 'wrap'` + `minHeight` вместо фиксированной `height`, без JS-порогов
по ширине окна: окно врёт, реальную ширину режут боковые панели.

### Контентная зона — раскладка по месту

Колонки получают базис и переносятся сами, когда обе не помещаются:

| Было | Стало |
|---|---|
| `previewGrid: { display:'flex', gap:28 }` | `+ flexWrap: 'wrap'` |
| `mainColumn: { flex: 1, minWidth: 0 }` | `flex: '1 1 380px'` |
| `aside: { width: 300, flexShrink: 0 }` | `flex: '1 1 300px', minWidth: 0` |

Порог получается сам: 380 + 28 + 300 = **708px контейнера**. Шире — две колонки как
сейчас, уже — лента честно уезжает под визитку во всю ширину. В стеке ленте нужен потолок
`scrollMaxHeight={280}` (как уже сделано в `PersonasHub` на планшете), иначе она отожмёт
характер и правила за экран.

Чипы фактов — с `flex-wrap` на `grid` `repeat(auto-fill, minmax(150px, 1fr))`: ровные ряды
вместо рваного последнего.

### Контентная зона — ревизия иерархии

Новый порядок вкладки «Профиль» — по вопросу «зачем человек сюда пришёл»:

```
hero (аватар 80, роль, имя, @handle, описание)
[Поговорить]
приветствие-бабл
--- Настройки ------- 4 чипа: Модель, Доступ, Возможности, Зона
--- Разделы персоны -- 4 карточки-навигатора со счётчиком
--- Характер --------- текст, свёрнут по умолчанию
--- Правила ---------- текст
--- Что выключено ---- только если есть off-tool привязки
```

Что меняется по составу:

- **Убираются** развёрнутые секции «Умения и правила», «Проактивность», «Память», «Задачи» —
  у каждой есть своя вкладка, в визитке они занимали четыре экрана прокрутки.
- **Появляется** блок «Разделы персоны»: четыре карточки `[иконка] Название / счётчик ›`,
  клик — переход на соответствующую вкладку. Счётчик несёт ровно ту информацию, ради
  которой раньше разворачивали секцию: «12 привязок · 3 правила», «5 в работе · 18 всего».
- **Чипы фактов** сокращаются с семи до четырёх — остаются те, у которых своей вкладки нет:
  Модель, Доступ, Возможности, Зона. «Умения», «Задачи», «Память» уходят в навигатор.
- **«Что выключено»** остаётся секцией: это предупреждение, а не раздел.

Девять секций → четыре плюс навигатор.

## Спецификация для реализации

**`components/Toolbar.tsx`**
- `Toolbar`: `flexWrap: 'wrap'`, `rowGap: SP.sm`, `height` → `minHeight`
  (десктоп `TB.heightDesktop`, мобила `TB.heightMobile`), `padding` по вертикали `SP.sm`
  в перенесённом состоянии.

**`features/personas/PersonaToolbar.tsx`**
- Выход рисуется **первым** ребёнком, до аватара; берётся `onBack ?? onClose`.
- Блок идентичности: `minWidth: 140` вместо `minWidth: 0`.
- «Редактировать»: подпись скрывается ниже ~900px контейнера → остаётся иконка
  `Pencil` с `title`. Порог — по контейнеру (`ResizeObserver`) либо контейнерным
  запросом; **не** по `useWindowWidth`.
- `PillSwitch`: обёртка `flex: '1 0 100%'` в перенесённом состоянии, `overflowX: 'auto'`.

**`features/personas/PersonasPage.tsx`**
- `onBack` — всегда, не только на мобиле (`onBack={clearSelection}`); в центре воркспейса
  вместо него `onClose`.

**`features/personas/PersonaPreview.tsx`**
- `previewGrid` + `mainColumn` + `aside` — по таблице выше.
- `PersonaActivityFeed`: `scrollMaxHeight={280}` в стековом состоянии.
- `factsRow`: `grid` `repeat(auto-fill, minmax(150px, 1fr))`, состав — 4 чипа.
- Секции `knowledgeSection` / `automationSection` / `memorySection` / `tasksSection`
  заменяются блоком «Разделы персоны»; счётчики берутся из тех же данных, что и раньше
  (`bindings`, `automationRules`, `taskCounts`, `memoryText`).
- Обработчики уже есть: `onOpenKnowledge`, `onOpenAutomation`, `onOpenMemory`, `onOpenTasks`.

**Иконки — только lucide-react, как везде в проекте.** Уже импортируются в
`PersonaToolbar.tsx`: `ChevronLeft` (назад), `X` (закрыть), `Pencil` (редактировать),
`EllipsisVertical` (ещё), `Star` (по умолчанию) и вкладки `User` / `Book` / `Zap` /
`Layers` / `CheckSquare`. Для блока «Разделы персоны» — те же иконки вкладок, чтобы
карточка навигатора и вкладка, куда она ведёт, читались как одно. `ChevronRight` —
стрелка карточки (уже используется в `PersonaActivityFeed`), `MessageSquare` — кнопка
«Поговорить». Размеры — из `ICON_SIZE`, толщина — `ICON_STROKE`; своих значений не вводим.

**Токены.** Новых значений не нужно: карточка навигатора — `C.bgWhite` + `C.border` +
`R.xl`, иконка `R.md` на `C.bgSelected`, hover — `borderColor` акцента персоны. Всё из
существующих шкал.

## Критерии приёмки

Ширины 390 / 560 / 832 / 1440, обе темы:

1. Выход из карточки виден и нажимается на каждой ширине.
2. Ни один элемент хедера не срезан правым краем; вкладки доступны все пять.
3. Заголовок роли не рвётся по слогам; при нехватке места — многоточие.
4. Ниже 708px контейнера лента активности стоит под визиткой во всю ширину, с потолком.
5. Вкладка «Профиль» не содержит развёрнутых превью других вкладок; навигатор ведёт в них.
6. Пустая персона: навигатор показывает «нет привязок / нет правил / пока пусто /
   нет поручений», лента — «Персона ещё ничего не делала».
