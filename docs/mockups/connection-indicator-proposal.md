# Индикатор связи вместо тостов «Связь восстановлена»

Дизайнер: Майя · Постановка: Александр · Статус: на согласовании с пользователем

## Задача

При нестабильном WiFi (планшет, десктоп) состояние связи мигает offline ↔ online, и на
каждом возврате вылетает тост «Связь восстановлена / Обновляем…» (App.tsx:392-413).
Повторяющиеся тосты раздражают. Заменяем тосты спокойной постоянной индикацией:
возврат в онлайн — всегда тихий, сигналить имеет смысл только потеря связи.

Инвентарь до изменения: тост перехода offline → online; точка внизу сайдбара
(ConnectionStatus.tsx, на мобиле недоступна — сайдбар скрыт); заглушка композера
«Отправка недоступна офлайн».

## Варианты

| # | Подход | Плюсы | Минусы |
|---|--------|-------|--------|
| 1 | Точка+текст в шапке чата ([v1](connection-indicator-v1.html)) | Всегда на виду, работает на мобиле, минимум шума | Легко не заметить без привычки |
| 2 | Плавающая плашка внизу, только при проблемах ([v2](connection-indicator-v2.html)) | Понятный текст, видна только когда нужно | Появлением перекрывает контент; без гистерезиса мигает |
| 3 | Тонкая полоса 3px сверху окна ([v3](connection-indicator-v3.html)) | Совсем не мешает | Незаметна, сигнал только цветом (доступность) |
| 4 | Расширение ConnectionStatus + счётчик обрывов ([v4](connection-indicator-v4.html)) | Знакомый паттерн, счётчик показывает масштаб | На мобиле спрятан в меню; счётчик повышает тревожность |

Макеты: [v1](connection-indicator-v1.html) · [v2](connection-indicator-v2.html) ·
[v3](connection-indicator-v3.html) · [v4](connection-indicator-v4.html) — самодостаточные
HTML, переключатель светлой/тёмной темы в правом верхнем углу.

## Рекомендация дизайнера

Комбинация **1 + 2**: постоянная точка в шапке (для тех, кто привык смотреть статус) +
плашка снизу только на время проблем (пояснение для остальных). Возврат — тихий:
плашка исчезает, точка зеленеет, тостов нет.

## Второй раунд: маркер вокруг аватарки

Пользователь уточнил направление: индикатор должен жить вокруг аватарки пользователя и
быть максимально малозаметным — об офлайне уже говорит заглушка композера, от индикатора
нужен только тихий пассивный маркер. Макеты: [connection-indicator-avatar-v1.html](connection-indicator-avatar-v1.html)
(4 варианта в одном файле: кольцо-контур, точка-наклейка, обесцвечивание, секторное кольцо;
состояния различаются формой и положением, не только цветом).

Рекомендация дизайнера: **кольцо-контур** (сплошное = онлайн, пунктир = нестабильно,
обрыв = офлайн) + `title`/`aria-label` для скринридера. Если нужен совсем минимальный
маркер — точка-наклейка, но офлайн-форма на ней уже на грани читаемости при 22px.

## Решение (пользователь, 22.08)

Гибрид **1 + 3**: онлайн и нестабильно — из варианта 1 (кольцо-контур: сплошное /
пунктир с пульсом), офлайн — из варианта 3 (аватарка обесцвечивается и перечёркивается
диагональю; кольцо в офлайне убираем — сигнал один, двойной маркер не нужен).

- Онлайн: цветная аватарка + сплошное кольцо `C.success`.
- Нестабильно: цветная аватарка + пунктирное кольцо `C.warning` с мягкой пульсацией.
- Офлайн: grayscale + приглушение аватарки, диагональная черта; кольца нет.
- Возврат: мгновенно и молча, тоста нет. `title`/`aria-label` на всех состояниях.

## Техническое условие (Александр)

Какой бы вариант ни выбрали, индикатор обязан иметь **гистерезис на слое состояния** —
иначе новая плашка будет мигать ровно как старый тост:

- офлайн объявляется только по подтверждению (`confirmOffline`, уже в коде);
- проблемное состояние UI показывает с задержкой ~3 с устойчивого офлайна —
  короткий блип не должен успевать красить интерфейс;
- возврат в онлайн — мгновенно и молча.

Без этого смена визуального языка проблему не решает.
