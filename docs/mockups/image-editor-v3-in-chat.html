Редактор картинок v3 — всё в основном чате проекта

Отдельного окна редактора нет. Картинка живёт в ленте как карточка-стопка (нить картинки). Крупно и с пометками — в попапе «Редактировать» у картинки, персонажи — в панели «Персонажи». Над композером живут полосы: «Git» (по умолчанию), «Картинки», позже «Видео», «Звук», «Локальные файлы». Человек переключает их сам; при выборе картинки полоса сама переходит на «Картинки», а после снятия выбора возвращается прежняя. Режим композера «Картинка» — только при выбранной картинке. Это макет: код продукта не менялся. Описание — image-editor-v3-in-chat-proposal.md.
