Редактор видео в проекте

Кликабельный макет AI Home: разложить картинки проекта цепочкой опорных кадров, выбрать переход между соседними кадрами (сгенерировать движение, склеить, вставить готовое видео или продлить клип), подрезать клипы на таймлайне, добавить музыку и собрать mp4 рядом с исходниками. Всё за флагом video-editor. Описание — video-editor-proposal.md.

Верхняя строка — управление макетом, не часть продукта. Предпросмотр играет по-настоящему: кнопка ▶ под плеером, клик по линейке таймлайна перематывает.

Сценарий целиком кликами: «Файлы» → у папки images «Новый фильм» (экран 2) → «Выбрать картинки из проекта» → отметьте 4 картинки → «Добавить» (экран 3) → карточка между кадрами 1 и 2 → «Сгенерировать» (экран 4) → «Сгенерировать» внизу (экран 5) → варианты (экран 6) → «Взять вариант» → переход 2 → 3 → «Склейка» (экран 8) → переход 3 → 4 → «Готовое видео» (экран 9) → «Добавить музыку из проекта» под дорожкой (экран 11) → «Собрать фильм» (экран 12) → «Открыть» (экран 13).
Другие входы: в «Файлах» отметьте несколько картинок галочками → «Собрать видео». Файл фильма .film появляется в дереве и открывает редактор с того же места.
Кадры: на десктопе кадры перетаскиваются мышью; «⋯» у кадра — заменить, вставить после, сдвинуть, удалить (с возвратом). «+» над карточкой перехода вставляет кадр между двумя.
Таймлайн: выделенный клип подрезается за оранжевые ручки по краям; кружки на стыках показывают склейку и открывают её. Экран 7 — переключите «Исход генерации» и нажмите «Сгенерировать».
