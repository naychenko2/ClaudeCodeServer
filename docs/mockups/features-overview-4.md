## Коротко по точкам

1. **Шапка.** Сейчас не видно, кому писать. А: чип «ведёт · Софья (локальная)» и ссылка «Ключевой чат» после
   ветки — статус и счётчики не двигаются, мета-строка и так переносится. Нет оркестратора или чата — элемент
   не рисуется.
2. **Производство.** Сейчас одна задача видна дважды (исполнители, потом шаги). А: карточка на задачу в порядке
   старта, цепочка «работа → вернул → доработка → принят», счётчик циклов (2+ — тоном предупреждения), текущий
   узел обведён акцентом, над активной задачей линия «сейчас», причина возврата — строкой.
3. **Связка.** Под исполнителем ревью/проверки — чип оцениваемой задачи со статусом; План — «по разрезу»,
   Разрез — «по эпику», Финал — «фичу целиком: N из M принято», Мерж — «после финала ✓ · ветка → master».
4. **Статистика.** Подпись перестаёт зависеть от ширины сегмента: в А у этапа своя строка, минуты справа,
   подсказка с разбивкой «работа · ожидание · простой» по наведению или касанию.
5. **Планы и макеты.** В: сетка карточек (планы, макеты с миниатюрой), клик — документ на всю ширину;
   макет — встроенный просмотр с «Десктоп / 360» и «Открыть отдельно».
6. **Анализ.** Четыре плитки (где сейчас, зависла ли, возвраты, длительность) + длительности этапов; при
   «зависла» — тревожная плитка и действия. Резюме моделью только по кнопке: покой, идёт, готово, ошибка.
7. **Чипы.** Чёрный `C.navInk`-чип на аватаре в `FeatureRunView` заменить на мягкий (`C.bgSelected` /
   `C.textSecondary`), как у `ModelChip` хронологии. В списке чатов чип только там, где модель отличается
   от умолчания проекта.

Токены — только `C.*` (в макете — их значения из theme.css в одном блоке `:root`); статусы — существующие
пары `*Bg`/`*Text`, новых цветов нет.
