# Композер: строка контекста, чипы действий и вклады подсистем

Конвенция для всего, что подсистема показывает вокруг поля ввода чата. Общие правила UI — в
[guidelines.md](guidelines.md); решение и контракты — [ADR-023](../adr/ADR-023-turn-context.md)
(разделы «Дополнение 1» и «Дополнение 2»); макеты — [composer-context-row-v1.html](../mockups/composer-context-row-v1.html)
([записка](../mockups/composer-context-row-v1-proposal.md)) и
[composer-actions-v1.html](../mockups/composer-actions-v1.html)
([записка](../mockups/composer-actions-v1-proposal.md)).

Полос над композером, режимов поля («Чат | Картинка») и отдельных панелей «Картинки», «Звук»
и «Видео» больше нет — новые подсистемы их не заводят.

## Строка контекста, чипы действий и панель «Контекст»

- **Строка контекста** над полем — одна, высотой в один ряд
  ([ContextRow.tsx](../../frontend/src/components/chat/ContextRow.tsx)): «Где» (ветка git и её
  меню), «С чем» (основной объект), «Чем» (исполнитель), «Плюс» (остальные приложенные объекты).
  Подписи чипов считает бэкенд одной функцией сводки, фронт их не собирает.
- **Чипы действий** под полем («Изменить», «Озвучить», «Снять») выбирают, что сделает отправка;
  набор действий объявляет вид вертикали, а не каркас композера.
- **Панель «Контекст»** в рельсе — подробности того же контекста
  ([ContextPanelHost.tsx](../../frontend/src/components/generation/ContextPanelHost.tsx)).
- Подсистема участвует только через вид контекста — слот `context-kind` (константа
  `SLOT_CONTEXT_KIND` в [registryCore.ts](../../frontend/src/lib/subsystems/registryCore.ts)),
  а не своим UI над полем.

## Чип над полем (`composer-chip`)

Чип — выбранный объект подсистемы над полем ввода («hero.png · 1 пометка ✕»). Render-вклад
сам решает, рисоваться ли: `null` — чипа нет. Собирается из примитива `Chip` с `leading`
(миниатюра 18 px), `maxW` и `onRemove` — свой пилюле-div не заводим.

Действие вклада `beforeSend` (`ComposerChipApi`) вызывается перед отправкой сообщения
агенту: вклад отдаёт файлы-вложения (снимок картинки с пометками) и сам
гасит свой чип. Пустой список — прикладывать нечего.

## Примитивы, заведённые под эту фичу

Все три — в [components/ui/](../../frontend/src/components/ui) и в витрине `#/ui-kit`.

| Примитив | Когда брать | Правила |
|---|---|---|
| `Chip` / `ChipX` | Фильтр, действие, выбранный объект (чип над полем, «+ Персонаж») | `variant="soft"` (по умолчанию; `selected`, `dashed`) или `toggle` для мультивыбора (`large` — тач-версия). `maxW` обрезает подпись многоточием, а крестик `onRemove` остаётся снаружи обрезки. `touch` — цель не ниже 32 px: у голого `ChipX` она 8×14 px, пальцем не попасть. `ChipX` отдельно — только внутри своей пилюли, клик не всплывает |
| `ProgressBar` | Прогресс генерации, загрузки, квоты | Полоса 4 px на дорожке `C.track`, `value` 0..100. Тон — роль: `accent` / `success` / `warning` / `danger`. `estimate` — прогноз, а не факт: заливка приглушённым `accentSoft`. Частые тики таймера — `transition` на `linear` |
| `Modal size="fullscreen"` | Рабочее окно во весь экран (редактор картинок) | Шапка и футер вне скролла, тело без отступов — холст от края до края; `width` игнорируется. Десктоп — карточка во весь вьюпорт с отступом `SP.lg`; мобила — без ручки шторки и скругления, с safe-area сверху и снизу. Жеста «потяни вниз» нет, поэтому крестик в шапке обязателен |
