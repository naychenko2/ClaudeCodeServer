Начать обучение?

Видеокарта будет занята примерно 2 часа. Всё это время новые картинки на локальной модели будут стоять в очереди и ждать. Отменить обучение можно в любой момент.

Новая версия не включится сама — вы выберете, подключать ли её, когда обучение закончится.

Остановить обучение?

Результат не сохранится.

Убрать фото?

Фото удалится из папки персонажа. Если это главное, главным станет следующее.

Удалить «Аня»?

Папка characters/anya/ с фото удалится из проекта

Первый экран

  • Коллаж лиц, имя, одна фраза о том, что с персонажем сейчас, шкала «Насколько похож» и одна главная кнопка: «Создать персонажа» → «Обучить персонажа» (или «Добавить фото для обучения», если их меньше 20) → ход обучения с «Отменить обучение» → «В контекст чата» / «Попробовать снова».
  • Шкала — ступени, а не процент: метрики сходства в продукте нет. Третье деление во время обучения показывает его ход.

Шторки

  • Чипы «Фото», «Версии», «Тонкая настройка» и меню «⋯». В продукте это Modal кита: на десктопе модалка по центру, на мобиле нижняя шторка. В макете они нарисованы внутри панели.
  • Каждая шторка сохраняет свою часть. Общей «Сохранить» на карточке нет.

Фото: два набора, разные задачи

  • Лицо для узнавания (3–10) уходит в сервис рисования с каждой картинкой. Только у этих фото есть метки.
  • Для обучения (20–50) нужны только видеокарте AI Home, наружу не уходят.
  • Общую папку из варианта Б сюда не закладываем: она меняет контракт обучения и будет отдельным вопросом.

Метки фото за флагом character-smart-photos

  • Под каждым фото лица — подпись «Ракурс · эмоция». Варианты подписи: «Размечаем…» и «Без меток». Нажатие на фото открывает редактор: ракурс, наклон, эмоция. Ручная правка помечается и авторазметкой не перезаписывается.
  • При выключенном флаге подписей нет, а текст согласия старый (переключатель «Флаг меток» выше).

Подписи LoRA

  • Подпись — имя файла и дата, без пути. Длинное имя обрезается многоточием, дата остаётся видна всегда (вариант «Своя версия подключена» в состоянии 4).
