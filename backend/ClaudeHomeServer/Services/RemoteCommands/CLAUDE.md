# Пульт удалённых команд (`Services/RemoteCommands`)

> Этот файл — вынесенная часть корневого `CLAUDE.md`: он загружается, только когда идёт работа с файлами этой папки.

Пункт меню аватара «Пульт управления» запускает и останавливает машинные процессы на хосте
сервера — туннель VS Code, Dify, службы Windows: та же мотивация, что у питания (машина дома,
ходят снаружи). Реестр действий живёт **только** в секции `RemoteCommands` машинного
`appsettings.Local.json` (образец с комментарием — `appsettings.Local.example.json`, правка
требует рестарта): из веб-морды команды не заводятся и не редактируются никогда — морда торчит
наружу, поле произвольной команды = RCE. **По HTTP ездит один лишь `Key`**, тексты команд
наружу не отдаются даже админу и не пишутся в логи (туда идут ключ, операция, имя
пользователя, exit code и длительность; вывод живёт в `OutputRingBuffer` и доступен только
админу).

Замков два — `[Authorize(Roles = "admin")]` и рубильник `RemoteCommands:Enabled` (false по
умолчанию); платформенного нет осознанно (команды объявляет хозяин машины под свою ОС, сервер
лишь резолвит шелл). Семантика выключенного — как у Power: `GET` всегда 200
`{enabled:false}`, мутирующие — 404. **Источник правды о состоянии — `Status`-команда, а не
память процесса**; «проверить не удалось» это честный `unknown` с причиной, а не «остановлен».
`GET`-список отдаёт кэш и не исполняет команд; на действие — одна операция разом (409), кроме
`refresh` (он вне gate и при `busy` отдаёт кэш). Режимы: `oneshot` (состояние держит система,
`Status` обязателен) и `daemon` (процессом владеет CCS, штатная остановка сервера гасит детей).
Раннер всегда локальный (не `IProcessLauncher`), формула командной строки — общая со сторожами
чатов (`Core/Services/ShellCommandLine.cs`, фикс сырых аргументов `cmd /s /c` + UTF-8 stdio).

Инварианты, REST-контракт и риски — раздел «Пульт удалённых команд» в
[docs/architecture/features.md](docs/architecture/features.md); проект решения —
[docs/research/remote-commands-plan.md](docs/research/remote-commands-plan.md).
