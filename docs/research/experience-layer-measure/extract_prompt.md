Ты — экстрактор «слоя опыта» для памяти агентов-исполнителей (по образцу Hy-Memory, сцена working/coding). Это шаг замера, а не продакшн.

Вход: выжимки транскриптов закрытых задач исполнителей проекта AI Home (бэкенд .NET + фронт React + Python-прокси к vLLM), файлы /tmp/expmeasure/dig/T{NNN}.md. Каждый файл: заголовок, постановка, итог, ход работы (T=вызов инструмента, «!»=ошибка/провал результата, A=реплика агента).

Задача: для КАЖДОЙ задачи из своего списка извлеки 0–3 записи ОПЫТА — переиспользуемого знания, которое сэкономит шаги ДРУГОМУ исполнителю на ДРУГОЙ, но похожей задаче. Порог ценности жёсткий:
- БРАТЬ: грабли и как их обойти (команда упала → что сработало); рабочие рецепты окружения (как собрать/запустить тесты/стенд/прокси, какие флаги, где логи); неочевидные факты кодовой базы (где что живёт, какой шов/контракт, какая ловушка); приёмы проверки, которые сработали.
- НЕ БРАТЬ: что именно сделано в этой задаче (это слой фактов, не опыт); общие места («читай код перед правкой»); то, что дословно уже написано в постановке задачи; вердикты ревью по конкретному коммиту.
- Если ничего не проходит порог — 0 записей, это нормально и ожидаемо для многих задач.

Каждая запись — объект:
{"src":"T{NNN}","task":"класс задач, к которым применимо (1 фраза)","search_keys":["3–6 ключей для поиска"],"solution":"что делать / чего не делать, конкретно, с командами и путями (≤400 символов)","boundary":"когда НЕ применимо (≤150)","confidence":0.0-1.0,"evidence":"где в выжимке это видно: короткая цитата/описание эпизода (≤200)"}

Не выдумывай: каждая запись должна опираться на эпизод из выжимки (evidence). Читай файлы целиком (они до ~50К символов; при необходимости кусками через offset/limit).

Запиши результат JSON-массивом всех записей твоей пачки в файл /tmp/expmeasure/exp/{BATCH}.json (Write). В ответе — только одна строка: сколько задач обработано и сколько записей получилось.
