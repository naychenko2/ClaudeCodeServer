Встроенные серверы — часть продукта: у них только статус, удалить или выключить их отсюда нельзя.
Секретные значения после сохранения не показываются — в форме редактирования вместо них будет только отметка «задано».
Вставьте объект mcpServers из конфига Claude Code или Claude Desktop — каждый сервер из фрагмента добавится как свой. Пары из env и headers с признаком секрета сохранятся в защищённом хранилище.
