# LLM-wiki: «Ночной разбор» чатов

Срез Ф2 эпика LLM-wiki ([ADR-035](../adr/ADR-035-llm-wiki-single-writer.md), §12ж; макет — [llm-wiki-v2.html](../mockups/llm-wiki-v2.html), режим «Срез Ф2 02.11»). Сверено с кодом ветки `feat/llm-wiki-nightly` 02.11.2026.

## Что делает

В окне, которое владелец задал в настройках, служба `WikiNightlyService` проходит по его чатам и разбирает те, где накопилось новое (не меньше 3 реплик человека после курсора), — тем же разбором, что кнопка «Разобрать этот чат», но с местом `wiki-nightly`. Порядок: чаты с пометкой «важный», затем по свежести. Серые чаты проверяет ступень 2 (`wiki-triage`), только когда очередь дошла до чата. Чаты исполнения задач и чаты с пометкой «не разбирать» не берутся. Тумблер по умолчанию **выключен**. Ночь работает без облака: только локальная модель (отказ локали — чат не разобран, курсор не двигается).

## Где настраивается

«Вики» → «Настройки» → «Ночной разбор»: тумблер «Разбирать по ночам», окно (часы сервера, по умолчанию 03–06), бюджет входа (700 000 токенов), пакетов за ночь (20) и на раздел (6). Пометки «Важный» / «Не разбирать» — в меню чата; список отбора — «Отбор чатов».

## Итог ночи

Карточка в том же блоке по файлу `keeper/nightly-last.json`: выбрано, разобрано, применено пакетов, во «Входящих», оценка токенов, исход (`completed`, `budget`, `open_limit`, `window_closed`, `disabled_midway`, `error`). Утром приходит уведомление «Ночной разбор: применено N, во „Входящих” M» с путём «Вики» → «Журнал»; когда ничего не разобрано и ночь обычная, уведомления нет. Откат — из «Журнала» (по пакету или по источнику).

## Не вошло в срез

- Личное / N5 (разбор личного раздела), S6d, S6k, N2–N4, N6, S8b.
- Из макета не реализованы: кнопка «Выключить» (класс/ночь), предупреждение об автовыключении, «Аудит недели».
- Расход ночи — оценка, а не факт; расход этих вызовов в учёт не попадает.
