# Канал устройства (ClaudeHomeServer.Devices)

> Этот файл — вынесенная часть корневого `CLAUDE.md`: он загружается, только когда идёт работа с файлами этой папки.
>
> Вертикаль вынесена в отдельную сборку `ClaudeHomeServer.Devices` (Этап 5). Хаб устройств
> `DeviceHub` живёт здесь же, а не в `Hubs/`; контроллеры канала (`DevicesController`,
> раздача агента) остались в Main. До 2026-09-30 вертикаль называлась `Desktop`
> (наследие ADR-008), namespace был `Services.Desktop`; внешние строки (схема аутентификации,
> claim'ы, маршруты, `data/devices.json`, ключ конфигурации `Desktop:AllowSameHostPairing`,
> `DesktopProtocol` и `DesktopDevice` в Core, **ключ тумблера `Subsystems:desktop`**) не
> менялись, чтобы не рвать связь с установленными агентами и конфигами.

Серверная половина агента локальных проектов ([ADR-016](../../docs/adr/ADR-016-local-projects.md)):
реестр устройств и сопряжение, хаб управления `/hubs/devices`, канал исполнения
`/api/devices/exec`, раздача агента, билеты localhost-API и донесения рук (§7). Руки ADR-008
(десктопный WPF-клиент, MCP-сервер `desktop`, тип чата «Десктопный», capability-токен, сеанс
рук) удалены 2026-09-30 — их заменили руки локальных проектов. Инварианты:

- **Канал устройства не принимает дефолтную JwtBearer и сервисный JWT владельца** (он лежит в
  env каждого хода, включая `tasks-executor`). Схема одна — токен устройства
  (`Authorization: Device {токен}` + `X-Device-Fingerprint`): 256 бит, на сервере только хеш,
  отпечаток машины сверяется на каждом запросе. Владелец и устройство берутся ИЗ ТОКЕНА.
- **Сопряжение и канал — только по HTTPS** (`DeviceChannelGuard`; петля без прокси — исключение),
  сопряжение с машиной самого бэкенда отказывает по отпечатку. Код — 8 символов, 5 минут,
  привязан к выпустившей веб-сессии.
- Хаб — канал управления: Hello (версия протокола, возможности, копия CLI) и push `ExecOpen` в
  КОНКРЕТНОЕ соединение (`DeviceConnectionRegistry`: одно устройство — одно соединение). Поток
  stdio идёт мимо хаба, отдельным WebSocket кадрами с номером и подтверждением.
- Первые четыре поля `DeviceHelloAck` остались от рук ADR-008 и сохранены, чтобы не менять
  формат ответа `Hello` для уже установленных агентов (SignalR сериализует JSON по именам,
  а агент полей `AckTimeoutSeconds`, `MaxResultBytes`, `MaxBatchSteps`, `ProtocolVersion` не читает).
- Стор `data/devices.json` едет в архив: у токена монотонная версия, чтобы restore не воскресил
  отозванное устройство.

Решение целиком — [ADR-016](../../docs/adr/ADR-016-local-projects.md), localhost-API и модель
угроз — [device-agent-local-api.md](../../docs/architecture/device-agent-local-api.md); история
рук ADR-008 — [ADR-008](../../docs/adr/ADR-008-desktop-agent.md).
