Очередь локальной генерации в карточках чата · картинка, звук, видео · видят все

Сценарий: человек попросил нарисовать картинку на своей видеокарте, а карточка в чате уже минуту крутит полосу и пишет «в очереди 2». Непонятно, сколько ждать и почему так долго. Отдельного чипа не заводим. Ожидание объясняет сама карточка генерации, в той же строке хода, где сегодня точка, текст и «Отменить». Меняются только текст строки, цвет точки и вид полосы, поэтому карточка по высоте не растёт. Новый блок появляется в одном случае — стенд недоступен.

v3, решения Андрея. В состоянии «Стенд недоступен» — кнопка «Сделать в облаке · ≈ $» с котировкой облачного исполнителя места (по умолчанию «Автоматически»); запуск только кликом. Нет облачного исполнителя — нет и кнопки (состояние 5б). Поведение самой задачи при упавшем стенде не меняется: карточка честно пишет «ждёт» и «недоступна с 14:32», старт не обещает.

Вид карточек повторяет код: картинка — VersionCards.tsx (Shell + RunningLine + заглушка .cc-skel 5:3), звук — ThreadCard.tsx (Frame + RunningLine + «Варианты появятся здесь…»), видео — SceneCard.tsx (шапка с Clapperboard, строка запуска, подпись хода + ProgressBar). Первая строка «Сегодня» — как карточки выглядят сейчас, для сравнения высоты. Под каждой карточкой её высота, замеренная в браузере, и разница с «Сегодня».

1. Десктоп — шесть состояний × три карточки

2. Мобила 360 и 320

Лента на телефоне — карточка на всю ширину минус поля 12. Если контейнер карточки уже 400 px, строка хода берёт короткую форму текста, и тогда она не переносится. Замер и проверка переполнения идут по каждой карточке.

Без ETA — «Карта занята долгой задачей: видео 1440p».Dot C.warning, слова «Карта занята» — C.warningText 600. 4. ETA не замерено«Шаг 12 из 25 · время не замерено» / «12 из 25 · без оценки». Если неизвестны и шаги — «Идёт · 1:40 · время не замерено», где 1:40 — прошедшее время.Со шагами — полоса accent по шагам. Без шагов — ProgressBar indeterminate (единственный случай с бегущим отрезком). Время не обещаем никогда.«Отменить».
5а. Стенд недоступен, облако естьВместо строки хода — иконка AlertTriangle и «Локальная генерация недоступна с 14:32» / «Локально недоступно с 14:32», FS.sm 600 C.dangerText. Под ней Note — только то, что есть сейчас, без обещания старта: «Задача ждёт в очереди. Можно сделать в облаке — локальная задача отменится.» Короткая форма: «Задача ждёт. В облаке — отменим локальную.» Поведение задачи не меняется: она ждёт, как и сегодня.Полосы нет. Точки нет.Button sm secondary с иконкой Cloud: «Сделать в облаке · ≈ $0.04» — одна подпись на все три карточки, цена своя (картинка $0.04, звук $0.02, сцена $1.20). Цена — котировка облачного исполнителя этого места при выборе «Автоматически», моно-цифры tabular-nums. Запуск только кликом: клик отменяет локальную задачу и ставит облачную. Рядом Button sm ghost «Отменить». Котировка ещё грузится — кнопка видна, на месте цены «≈ …», кнопка disabled. Hover C.bgSelected, tap SHADOW.press, focus SHADOW.focus; на мобиле высота 28 сохраняется, хит-зона добирается паддингом ряда до 44. Это единственное состояние, где карточка вырастает: на строку Note и ряд кнопок.
5б. Стенд недоступен, облака нетТа же строка C.dangerText. Note: «Задача ждёт в очереди.» (короткая форма та же). Ни слова про облако.Полосы нет. Точки нет.Кнопки облака нет совсем (не disabled): облачного исполнителя у места нет — предлагать нечего. Остаётся Button sm ghost «Отменить» (у звука — «Убрать из очереди»).
ОбщееИсточник текста — одна функция на все три редактора (сегодня их три: queueText, progressText, подписи useScene), чтобы формулировки не расходились. Короткая форма включается по ширине контейнера карточки < 400 px (ResizeObserver, у видео уже есть useBoxWidth), а не по useIsMobile: узкая карточка бывает и в узкой ленте на десктопе. Точка и текст — aria-live="polite" на строке, но озвучиваем только смену состояния, а не каждый шаг. Тёмная тема — те же токены (C.textMuted, C.warning, C.accent, C.dangerText), своих значений нет. Видео в режиме «Макс» показывает те же тексты внутри строки своей стадии.
