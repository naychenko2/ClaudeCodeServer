# Карточки дефектов — эталон по гайдлайнам для волны 3

Макет: [defect-cards-v1.html](defect-cards-v1.html) — светлая и тёмная темы (переключатель в шапке),
мобильная раскладка 390 CSS px отдельной секцией. Эталон для UI-ревью карточек дефектов (волна 3
реализации `wt/otsenka-vnedreniya-bagtrekinga`).

## Что в макете

| # | Раздел | Назначение |
|---|---|---|
| 1 | Карточка дефекта в списке (TaskCard.tsx) | Иконка Bug в `C.textMuted`, плашка «Закрыт без проверки» в `C.dangerBg/dangerText/dangerBorder`. Два состояния: открытый дефект, закрытый без проверки |
| 2 | Диалог создания с переключателем «Задача \| Дефект» (NewTaskDialog.tsx) | `ui/SegmentedControl` + три поля Repro (Steps обязателен, Expected/Actual опциональны) |
| 3 | Блоки Repro и Verification в деталях (TaskDetailsPane.tsx) | Белые карточки `C.bgWhite` с `C.borderLight`, R=12, шаги pre-wrap, sublabel uppercase |
| 4 | Тост отказа (NotificationToasts.tsx + toast.ts) | Все 6 точек вызова — единый формат с `kind='error'`, рамка danger |
| 5 | Мобильная панель деталей (TaskDetailsPane isMobile) | Шапка + статус-сегмент снизу + блоки Repro/Verification в той же ленте |

## Токены и контролы

- **Только** `C.*` из `design.ts` (значения обеих тем — в `theme.css`).
- Контролы — `ui/SegmentedControl`, `ui/Modal`, `ui/TextArea`, `ui/Button`. Никаких самодельных.
- Иконки — `lucide-react`, размеры из `ICON_SIZE` (xs=14, sm=16, md=18).
- Шрифты: PT Serif для заголовка модалки и заголовка h1 в деталях, Hanken Grotesk для UI, JetBrains Mono для Steps (исходник кода).

## Источник для Киры

Все 5 дефектов созданы в трекере, assignee = Кира:

1. `[Дефект] Шапка задачи: кнопки «Выполнить/Изменить/Отмена/Готово» — raw button вместо ui/Button` — **HIGH**
2. `[Дефект] NewTaskDialog: чипы проекта и приоритета — raw button вместо компонентов ui/` — **HIGH**
3. `[Дефект] TaskEditForm: подпись «проверено персоной/человеком» опирается на исполнителя, а не на автора вердикта` — **HIGH** (логический баг, влияет на отображение)
4. `[Дефект] NotificationToasts: error-тост показывает info-плитку вместо error-иконки` — **MEDIUM**
5. `[Дефект] Карточки дефектов: magic numbers — fontSize 13.5/11.5/12.5, borderRadius 2/7` — **MEDIUM** (тех-долг)

## Что НЕ в макете

- Magic numbers и raw `<button>` в коде (макет использует токены; код ещё нет — это предмет дефектов выше).
- Реализация `ProjectChip` и перевода приоритета на `SegmentedControl` — задача Киры по дефекту №2.
- Расширение типа `NotificationKind` значением `'error'` — задача Киры по дефекту №4.
- Глобальная конверсия `fontSize: 13.5` → `FS.base/FS.md` по всему проекту — отдельная задача на техдолг (здесь только файлы дефектов).
