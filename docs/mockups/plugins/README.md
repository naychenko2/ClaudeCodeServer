Эпик «Плагины и build-it-yourself UX» — `featureId 802bb754-0c03-4467-8813-af2b6e226730`, шаг `M1`.
По макетам работают шаг **2.3** (экраны 1–3, флаг `plugins-mvp`) и шаг **4.4** (экран 4, флаг `plugins-build-yourself`).

- Живой макет: [plugins-v1.html](plugins-v1.html) — галерея всех кадров, кнопка «Сменить тему».
  Отдельный кадр: `plugins-v1.html#screen=install&layout=mobile&theme=dark`.
- PNG снимает [render.mjs](render.mjs): `node docs/mockups/plugins/render.mjs` (playwright из `frontend/node_modules`).

## 1. Экран «Плагины» (`plugins-mvp`, шаг 2.3)

**Сценарий.** Человек открывает настройки проекта → раздел «Плагины»: видит, что стоит, что включено, где не хватает прав или секрета; ставит новый из папки или (во втором флаге) просит агента собрать свой.

**Где.** Новый пункт навигации настроек проекта «Плагины» (иконка `Plug` из `ui/icons`). Счётчик `CountBadge` (warning) у пункта — число плагинов, которым чего-то не хватает (не выдано запрошенное право или не задан обязательный секрет). Ноль — бейджа нет.

**Реквизиты.**
- Заголовок `FS.xl`, `FONT.serif`, `C.textHeading`; подзаголовок `FS.base`, `C.textSecondary`: «Панели, команды и навыки, которые расширяют чаты этого проекта. Без выданных прав агент плагин не вызывает.»
- Кнопки: `Button variant=primary size=sm` «Поставить из папки» (иконка папки); `Button variant=ghost size=sm` «Создать по промпту» (иконка sparkle) — **только при `plugins-build-yourself`**, без флага кнопки нет вовсе.
- Секция «Установлены · N»: подпись секции — `FS.xs`, uppercase, `C.textMuted`. Список — карточка `C.bgCard`, рамка `C.borderLight`, `R.xxl`; строки разделены `C.borderLight`, отступы `SP.md`/`SP.lg`.
- Строка плагина: плитка 36 × 36 `R.lg` (`C.accentLight`/`C.accent`, инициалы; у выключенного — `C.bgInset`/`C.textMuted`); имя `FS.base` 600 `C.textHeading`; версия `FONT.mono` `FS.xs` `C.textMuted`; вклады — чипы `MetaChip` (Панель / `/команда` / Навык / имя секрета); справа статус, `Toggle`, `IconButton` «⋯».
- Статусы справа (ровно один, по приоритету): `Button xs ghost` warning «Не задан секрет» / «Нужны права» (кликабельно → шторка «Права и секреты») → `Badge success` «Права выданы · N» → `Badge neutral` «Выключен».
- dev-плагин (поставлен из папки с отслеживанием): версия `dev`, `Badge` info «из папки · следит за правками», путь моно `C.textMuted`.
- Секция «Черновики от агента · N» (только `plugins-build-yourself`): карточка с пунктирной рамкой `C.dashed`, плитка `C.planLight`/`C.planText`, `Badge` plan «Черновик», строка-источник «Агент собрал в чате «…» · 14 мин назад · проверка пройдена», `Button xs ghost` «Открыть» → чат с карточкой черновика (экран 4), проскролленный к ней.
- Меню «⋯» (`Menu`): «Права и секреты…», «Обновить из папки» (только у установленных из папки), «Открыть файлы», разделитель, «Удалить плагин…» (`C.dangerText`, через `ConfirmDialog`).

**Состояния.**
- *Пусто*: `EmptyState` в пунктирной рамке — плитка 48 `R.xxl` с вилкой, «Плагинов пока нет», «Поставьте готовый из папки или попросите агента собрать свой.», две кнопки full-width (вторая — при флаге build-yourself; без него текст «…или попросите агента…» убирается).
- *Есть плагины*, *есть черновики* — как на кадре.
- *Загрузка*: 3 строки-скелета `C.bgInset` вместо списка, кнопки активны.
- *Ошибка*: `Notice tone=danger` «Не удалось получить список» + причина + «Повторить». 503 от выключенной подсистемы — текст «подсистема плагинов выключена» (честный 503 по правилу отключаемости).
- *Hover строки*: фон `C.bgSelected`. *Focus* — `SHADOW.focus` на интерактивных.
- *Локальный проект* (`ProjectCapabilities.Plugins = false`): вместо экрана `Notice info` «Плагины для локальных проектов пока недоступны» — без кнопок.

**Переходы.** «Поставить из папки» → выбор папки проекта (существующий диалог выбора каталога файлового менеджера) → сервер валидирует пакет → экран 2. Тумблер — мгновенно, оптимистично, откат с тостом при ошибке. «Не задан секрет» / «Права и секреты…» → экран 2 в режиме «изменить» (заголовок «Права «…»», кнопка «Сохранить»).

**Мобила (360).** Полноэкранная страница с `BackButton` в шапке 52 px; кнопки сокращаются до «Из папки» / «По промпту» и делят ширину пополам. В строке остаются плитка, имя, одна строка-подсказка (вклады через «·» или warning-текст) и тумблер; «⋯» нет — тап по строке открывает шторку «Права и секреты», «Удалить» — в той же шторке внизу. Черновик — строка с шевроном.

## 2. Диалог согласия (`plugins-mvp`, шаг 2.3)

**Сценарий.** Перед установкой человек видит, что добавится и что плагин просит; выдаёт права поштучно и задаёт секреты, не видя их значений.

**Реквизиты (desktop — `Modal`, mobile — шторка).**
- Шапка: плитка + «Установить «{name}»?» `FS.lg` + моно-строка `{version} · {путь} · sha256 {коротко}`.
- «Что добавится» — чипы вкладов из `contributes` (панель, команды, навыки).
- «Права, которые просит плагин» — по строке на каждый элемент `requested`: `Checkbox` + человеческое название (жирным) + моно-ключ `C.textMuted`.
  - `notes:read` → «Читать заметки проекта», `tasks:read` → «Читать задачи проекта», `net:{host}` → «Ходить в сеть: только {host}», `secret:{name}` в списке прав не показывается — у секретов свой блок.
  - Права `net:*` — иконка глобуса `C.warning` и предупреждение `C.warningText`: «Данные уйдут за пределы AI Home. Выдавайте, если доверяете автору.»
  - **Умолчание галок:** все права, кроме `net:*`, отмечены; `net:*` — снят (см. В1).
- «Секреты» — строка на каждый `requires.secrets`: ключ моно, `Badge warning` «не задан» или `Badge success` «задан · {дата}», кнопка `Button xs ghost` «Задать» / «Заменить». По нажатию строка разворачивается в поле `type=password` (плейсхолдер точками) + «Сохранить» + крестик. **Значение секрета никогда не приходит с сервера** — только флаг `isSet` и дата; поле всегда пустое.
- `Notice tone=info` с иконкой щита: «Агент не сможет вызывать плагин без выданных прав. Права и секреты можно поменять позже: «Настройки проекта → Плагины».»
- Футер `C.bgInset`: `Button ghost` «Отмена», `Button primary` — подпись по числу галок: «Установить» (все), «Установить · прав N из M» (часть), «Установить без прав» (ни одной).

**Состояния.** Loading («Устанавливаем…», `C.accentSoft`, кнопки и Esc заблокированы); ошибка валидации — `Notice danger` над футером, кнопка установки скрыта («Пакет не прошёл проверку: …», «Ничего не установлено»); пакет изменился (sha256 не совпал) — `Notice warning` «Файлы в папке поменялись» + «Обновить», кнопка установки disabled до обновления; focus чекбокса — `SHADOW.focus`.

**Режим «изменить»** (открыт со строки установленного плагина): те же блоки, заголовок «Права «{name}»», без «Что добавится», кнопка «Сохранить».

**Ширина.** Контенту тесно в `MODAL_W.form` 440 (моно-ключи + бейджи секретов), на кадре — 520. См. В3.

**Мобила.** Шторка `R.sheet`, `SHADOW.sheet`, грабер; права без иконок, секреты в одну строку; кнопки в столбик full-width, основная сверху. Контент шторки скроллится, кнопки прилипают к низу.

## 3. Слот панели плагина в sidebar (`plugins-mvp`, шаг 2.3)

**Сценарий.** Панель плагина живёт островом в боковой колонке рядом с остальными панелями; человек сразу видит, работает она или сломалась, и может перезапустить её сам.

**Реквизиты.** `Island`: шапка 40 px `ISLAND.headerBg`, мини-плитка 20 × 20 `R.sm`, имя, `IconButton` «Перезагрузить панель» (иконка refresh, видна при hover шапки и всегда на тач-устройствах), «⋯» (Права…, Открыть в «Плагинах», Скрыть панель). Тело — sandbox-iframe на `C.bgCard`; футер `C.bgInset` `FS.xs` «Права: …» + версия моно (футер — см. В4).

**Состояния.**
- *Пусто* (нет ни одного плагина с панелью): остров «Панели плагинов», пунктир `C.dashed`, «Здесь будут панели плагинов», «У установленных плагинов панелей нет.», `Button dashed` «Открыть «Плагины»». Пустой остров показываем, только если плагины вообще стоят; без плагинов слота нет совсем (см. В5).
- *Загрузка* — скелет из 4 полос `C.bgInset`, до первого сообщения моста; таймаут 3 с → ошибка.
- *Загружена* — содержимое плагина.
- *Ошибка моста* — точка `C.danger` в шапке; в теле `Notice danger` «Панель не отвечает» + причина («Мост не получил ответа за 3 с.» / «Панель отправила неверное сообщение» / «Версия моста не поддерживается»), моно-код (`bridge_timeout`, `bridge_bad_message`, `bridge_version`), кнопки «Перезагрузить» и «Подробнее» (журнал последних сообщений моста в `Modal`).
- *Отказ по праву* — не ломает панель: `Notice warning` поверх контента «Нет права {key}» + ссылка «Выдать…» → экран 2 в режиме «изменить». Закрывается крестиком.

**Мобила.** Панели плагинов — пункты списка «Панели»; тап открывает панель на весь экран с шапкой 52 px (назад, плитка, имя, перезагрузить, ⋯). Ошибка и пусто — те же `Notice`/пунктир на всю ширину, кнопка перезагрузки — `Button md ghost` full-width.

**Тёмная тема.** iframe плагина получает тему через мост (`theme: 'light' | 'dark'` в приветствии); собственный фон панели плагину рисовать не нужно — подложка `C.bgCard` наша.

## 4. Карточка черновика (`plugins-build-yourself`, шаг 4.4)

**Сценарий.** Агент собрал плагин в чате; человек одним взглядом видит, что изменится после установки, смотрит файлы и решает — принять, отклонить или отдать агенту на доработку.

**Где.** Карточка в ленте чата, под сообщением агента (по результату `draft_create`/`validate`). Рамка `C.planBorder` — «черновик» в гамме плана, не accent.

**Реквизиты.**
- Шапка: плитка `C.planLight`/`C.planText` (sparkle), имя, `Badge plan` «Черновик», моно `{id} {version}`, подпись «Собран агентом · ещё не установлен · виден только вам»; справа `Badge success` «Проверка пройдена» или `Badge danger` «N ошибок».
- «Что будет после установки» — `FS.lg`, `FONT.serif`. Список вкладов: иконка, название жирным, одна строка пояснения `C.textMuted`, справа `Badge neutral` с типом (`panel` / `command` / `skill`).
- «Попросит права» и «Секреты» — две колонки (на мобиле — чипы в ряд); `net:*` цветом `C.warningText`; секрет с `Badge warning` «не задан».
- Футер `C.bgInset`: слева `ghost` «Посмотреть файлы», `ghost` «Править»; справа `ghost-danger` (прозрачный, `C.dangerText`, рамка `C.dangerBorder`) «Отклонить», `primary` «Принять…». Многоточие — потому что дальше диалог согласия.

**Состояния.**
- *Проверка не пройдена*: `Notice danger` «Принять пока нельзя» со списком ошибок (моно-путь файла + текст); «Принять…» disabled с подсказкой «Сначала исправьте ошибки проверки»; вместо «Править» — `secondary` «Попросить агента исправить» (отправляет в чат готовую реплику с ошибками).
- *Итоговые*: «Установлен · {version}» (карточка сворачивается в строку с бейджем и ссылкой «Открыть в «Плагинах»»), «Отклонён» (свёрнута, `C.textMuted`), «Черновик обновлён агентом» (бейдж plan, кратко подсвечен `SHADOW.selected`), «Черновик устарел — есть новая версия» (старая карточка: кнопки скрыты, ссылка на новую).
- *Loading* при «Принять» — диалог согласия; при «Отклонить» — кнопка спиннер, без подтверждения (черновик остаётся в `_drafts/` до очистки — см. В6).

**Переходы.** «Посмотреть файлы» → правая шторка (desktop, ширина `MODAL_W.wide` 720) или полноэкранная шторка (мобила): дерево файлов слева/сверху, содержимое моно справа/снизу, только чтение, кнопка «Предпросмотр панели» (тот же остров экрана 3 в модалке). «Править» → фокус в поле ввода чата с префиксом «Поправь плагин «…»: ». «Принять…» → экран 2 → после установки карточка в состоянии «Установлен». **Принять/установить может только человек кнопкой** — у агента такого инструмента нет.

**Мобила.** Шапка в две строки (имя, бейджи под ним), вклады без пояснений, права и секреты — чипы; футер в столбик: «Принять…» full-width сверху, ниже ряд «Файлы / Править / Отклонить» по трети ширины.

## Открытые вопросы (решить до старта Киры)

- **В1. Умолчание галок прав.** Предлагаю: все отмечены, кроме `net:*`. Альтернатива — всё снято (строже, но человек будет жать «всё подряд»). Нужен выбор Софьи.
- **В2. Обязательный секрет не задан — ставить ли плагин?** На макете кнопка активна, а плагин потом висит со статусом «Не задан секрет». Альтернатива — блокировать «Установить», пока обязательные секреты пусты. Нужно и решение, и признак «обязательный» в манифесте (`requires.secrets[].required`?) — вопрос к Денису/Александру.
- **В3. Ширина диалога согласия.** 440 (`MODAL_W.form`) тесно, на кадре 520. Либо новый шаг шкалы `MODAL_W.consent = 520` (добавить в `design.ts` до вёрстки), либо `MODAL_W.wide` 720 с двумя колонками. Предлагаю новый шаг.
- **В4. Футер острова с правами и версией.** Полезен для доверия, но съедает высоту в узкой колонке. Оставить или унести в меню «⋯»?
- **В5. Пустой слот без плагинов.** Предлагаю не показывать остров вовсе, пока нет ни одного плагина с панелью (пустой остров — только когда плагины стоят, но панелей у них нет). Подтвердить.
- **В6. Судьба отклонённого черновика.** Удалять из `_drafts/` сразу или хранить N дней с возможностью «Вернуть»? От этого зависит, нужна ли кнопка «Вернуть» на свёрнутой карточке.
- **В7. Тексты прав.** Человеческие названия для `notes:read`, `tasks:read`, `net:{host}` на макете — мои черновики; финальный словарь прав (и куда он кладётся — бэк отдаёт `title` или фронт держит карту) — к Софье и Денису.
- **В8. Где «Панели» на мобиле.** Макет считает, что панели плагинов — пункты существующего списка панелей мобильной раскладки. Если отдельного списка нет — нужен шаг на навигацию.
- **В9. Таймаут моста 3 с** — значение с потолка; подтвердить с бэком/протоколом моста v1.
