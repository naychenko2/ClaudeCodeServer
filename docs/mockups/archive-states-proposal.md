# Архив чатов — три состояния из origin: пустое состояние, плашка, тост

Макет: [archive-states-v1.html](archive-states-v1.html) — светлая и тёмная темы (переключатель в
шапке), мобильная раскладка 390 CSS px отдельной секцией. Дополняет, а не заменяет
[archive-chats-v1.html](archive-chats-v1.html): там — раздел «Архив», карточка и автоправило;
здесь — три элемента, которые доносим из origin поверх модели v4.

## Тексты (утверждены задачей, переносятся дословно)

| Место | Текст |
|---|---|
| Пустое состояние, заголовок | `Все чаты в архиве` |
| Пустое состояние, подзаголовок | `Список пуст: живых чатов нет, архив не считается.` |
| Пустое состояние, кнопка ghost | `Открыть архив` |
| Пустое состояние, кнопка primary | `Создать первый чат` — **только в глобальном списке** |
| Плашка открытого архивного чата | `Этот чат в архиве` + кнопка `Вернуть из архива` |
| Тост | `Чат убран в архив` + действие `Отменить` |

Внимание: в макете v1 плашка звучала «Чат в архиве» с подсказкой — новая формулировка «Этот чат
в архиве» приходит из origin и заменяет её; подсказка второй строкой убрана, кнопка рядом сама
объясняет действие.

## Решения по форме

**Пустое состояние** — готовый `ui/EmptyState`, дефолтный (не compact) вариант: кружок 56×56
(R=16) с lucide `archive` цветом `C.accent` на `C.bgPanel`, заголовок serif 21/500
`C.textPrimary`, подзаголовок 13.5 `C.textSecondary` (max-width 280), ряд кнопок с gap 8 и
`margin-top:12`. Приоритет: «Создать первый чат» — единственное accent-пятно экрана (primary +
`SHADOW.button`), «Открыть архив» — ghost: действие вторичное, ведёт в раздел «Архив» внизу
списка. В списке проекта primary-кнопки нет — создание живёт в шапке списка, дублировать
нельзя (два primary на экране размывают приоритет).

**Плашка** — паттерн «состояние над лентой» из v1 без изменений по форме: `C.bgInset`, рамка
`C.border`, R=12, `padding:10px 14px`, gap 10, иконка `archive` 22px в `C.textMuted`, текст
13/600 `C.textHeading`, кнопка `Button` secondary sm с иконкой `archive-restore` 13px. Тон
нейтральный: архив — состояние, а не ошибка; `warning`-варианта у этой плашки нет.

**Тост** — каркас `NotificationToasts` целиком: `C.bgCard` + 1px `C.border` + R=12 +
`SHADOW.dropdown`, стек в правом верхнем углу (`top/right:14`, `z-index: Z.modal+10`,
автоскрытие 8 с, потолок 4). Отличие одно: вместо диплинка — действие «Отменить» текстовой
кнопкой 12/600 цветом `C.accent` (главное действие тоста — accent уместен). «Отменить»
возвращает чат из архива тем же PUT и гасит тост; подтверждающего тоста нет — чат просто
появляется в списке. Плитка-иконка 36×36 (R=10, `C.bgSelected`, `archive` 15px `C.textMuted`)
повторяет плитку системных уведомлений, но в нейтральной гамме: это не алерт.

## Темы и мобиле

Новых цветов не заведено: все три состояния собраны из существующих `C.*` / `R` / `SP` /
`SHADOW`, тёмная тема переключается теми же переменными без единого ручного переопределения.
На мобиле (ориентир 360 CSS, фрейм 390): кнопки пустого состояния — в столбец в полную ширину;
плашка переносит кнопку «Вернуть из архива» новой строкой в полную ширину; тост занимает ширину
вьюпорта минус поля — это уже заложено в `max-width: min(360px, 100vw − 28px)` стека.

## Что макет не решает

Плашка предупреждения «контекст мог устареть» из v1 остаётся как есть и сюда не входит. Поведение
«Открыть архив» (развернуть секцию + скролл) — деталь реализации Киры, в макете показан только
результат: человек оказывается в разделе «Архив».
