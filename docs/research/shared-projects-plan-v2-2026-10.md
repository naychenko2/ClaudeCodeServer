## 3. Контракты фронт ↔ бэк

Фиксируются на сверке **А7 до W2**. После неё Кира пишет `S1-F2` и компоненты по этому блоку, не дожидаясь бэка.
Любая правка блока — через Александра, с пометкой в обеих карточках.

**Общее.**
- Тело любой ошибки — `{ code: string, message: string, ...детали }`. Фронт ветвится **только по `code`**, статус —
  для логов.
- Флаг — `shared-projects`.
- id пользователя — строка `userId` из `users.json`. Отображаемое имя — `displayName`, если пусто — `username`.

**К1. Проект** (`GET /api/projects`, `GET /api/projects/{id}`) — `S1-3a`, `S2a-7`.

| Поле | Тип | Кто видит | Примечание |
|---|---|---|---|
| `myRole` | `'owner' \| 'editor' \| 'reader'` | вызывающий | вычисляется, не хранится |
| `ownerDisplayName` | `string` | все участники | для «проект Андрея» |
| `members` | `ProjectMember[]` | все участники | `{ userId, username, displayName, role: 'editor'\|'reader', addedAt }`; владелец в списке не лежит |
| `formerMembers` | `{ userId, displayName }[]` | все участники | для подписи «больше не в проекте» |
| `mcpServersForMembers` | `string[]` | владелец | подмножество `mcpServersOn`; пишет только владелец (`owner_only`) |

Личный проект: `members` пуст или его нет; `myRole = 'owner'`.
