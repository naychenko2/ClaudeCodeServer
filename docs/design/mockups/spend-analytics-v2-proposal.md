# Аналитика токенов v2 — предложение по макетам

Спека: `.omc/specs/deep-interview-token-spend-analytics-v2.md` (worktree wt-analytics).
Автор макетов: Майя. **Актуальный артефакт согласования — кликабельный прототип
`spend-analytics-v2-prototype.html`** (итерация 2, см. раздел «Прототип» ниже): по нему
Андрей даёт финальное одобрение всего дизайна. Финальный статический макет
`spend-analytics-v2-final.html` и варианты A/B/C остаются референсом прошлых итераций.

## Проблема

Деньги уходят незаметно: провайдеров и источников стало много (ходы чатов и задач, фоновые
one-shot, fal.ai, бесплатные модели), а ответа на вопрос «куда ушёл каждый доллар» в продукте
нет. Прошлый заход (ветка worktree-work-3) показал «сколько всего» — вкладки с плоскими
списками и KPI-карточками, — но не дал ни глубины (drill-down до хода), ни ощущения качества:
всё в одном тесном оверлее, мелкие кегли, без темы «островов», мобильная раскладка условная.

Требования из спеки, которые держат все три варианта:

- **Путь до хода.** В пределах детального окна любая сумма раскрывается до конкретного хода
  (пользователь → проект → чат/задача → ход) с in/out/cache и ценой.
- **Честная граница окна.** Детально — последние N дней (конфиг), старше — только дневные
  агрегаты. UI не притворяется: зона агрегатов на графиках приглушена и отделена пунктиром,
  строки за окном помечены 🔒 с объяснением, drill-down в них не заманивает.
- **Приватность.** Админ видит цифры и *названия* чужих проектов/чатов/задач, но клик по ходу
  ведёт в «паспорт хода» (метрики), а не в чат. Подпись «содержимое сообщений недоступно» —
  прямо в интерфейсе.
- **Все источники.** Ходы (accent), фоновые one-shot (info), fal.ai (plan), бесплатные модели
  (success, всегда 0 $ — и это видно, включая «экономию к ценам claude»). Цвета серий — только
  из токенов темы, легенда единая во всех вариантах.
- **Полный контур.** Дашборд + виджет на «Домой» (клик ведёт в дашборд) + бейдж стоимости в
  шапке чата (обновляется по окончании хода, у бесплатной модели — зелёный «0 $»).
- **Оба режима.** Персональный («мои траты») у всех; тумблер «Мои / Все пользователи» — только
  у админа.
- Обе темы (light/dark через переменные theme.css), мобильная раскладка 390px (tap вместо
  hover), состояния: пустое «трат ещё нет», загрузка-скелетон, ошибка с повтором, «фильтры
  отсекли всё».

## Решение — три альтернативы

### A — «Проводник» (`spend-analytics-v2-a-explorer.html`)

Метафора файлового менеджера. Один остров: KPI-полоса → столбиковый график по дням со стеком
источников → список текущего уровня с хлебными крошками. Клик по строке проваливает на уровень
ниже, у каждой строки полоса «доля в родителе» — что съедает бюджет, видно без чтения цифр.
Клик по дню на графике фильтрует проводник.

- Сильное: самый простой ментальный маршрут — «иду по крошкам вниз до хода»; идеально ложится
  на мобилу (один столбец, «‹ Назад»); минимум новых паттернов — выглядит как знакомые списки.
- Слабое: виден только один уровень за раз; сравнение «братьев» на разных уровнях требует
  ходить туда-сюда.

### B — «Инспектор» (`spend-analytics-v2-b-inspector.html`)

Master-detail: слева дерево (пользователи → проекты → чаты/задачи → ходы) с раскрытием на
месте, справа — постоянная панель деталей выбранного узла. Для агрегатов — метрики, стек
источников, топ моделей, динамика; для хода — «паспорт хода» с разложением цены на
input/output/cache и спарклайном «этот ход на фоне соседей». На мобиле панель — bottom-sheet.

- Сильное: контекст не теряется — видно и всю иерархию, и детали одновременно; «паспорт хода»
  с разложением цены — самый глубокий ответ на «куда ушёл доллар»; один шаблон панели на все
  уровни (дёшево в реализации).
- Слабое: самая плотная раскладка — требует ширины (на ноутбуке 13″ дерево придётся поджать);
  два фокуса внимания.

### C — «Полотно» (`spend-analytics-v2-c-canvas.html`)

Дашборд без фиксированной иерархии: герой-метрика с area-графиком месяца, ниже — карточки
разрезов (чаты/задачи, модели, источники, пользователи, персоны) и таблица ходов среза. Клик
по ЛЮБОМУ элементу любой карточки добавляет фильтр-чип в шапку — всё полотно пересчитывается.
Drill-down не «вниз», а «сужением»: срез собирается любым путём — от модели, от персоны, от дня.

- Сильное: отвечает на вопросы, которых иерархия не умеет («сколько стоил opus по всем
  проектам?», «во что обходится Майя?») — за один клик; срез всегда виден чипами; самый
  «аналитический» и самый эффектный на широком экране.
- Слабое: свободная комбинация фильтров сложнее в реализации (каждая карточка пересчитывается
  от любого чипа) и требует привыкания; путь именно «до хода» на два клика длиннее, чем в A/B.

## Отличия одним взглядом

| | A «Проводник» | B «Инспектор» | C «Полотно» |
|---|---|---|---|
| Метафора | файловый менеджер | дерево + паспорт узла | BI-полотно с чипами |
| Drill-down | проваливание, крошки | раскрытие на месте | сужение среза фильтрами |
| «Куда ушёл доллар» | путь вниз до хода | паспорт хода + разложение цены | таблица ходов среза |
| Перекрёстные вопросы (модель×проект) | нет | частично (фильтры над деревом) | да, главная сила |
| Плотность/сложность UI | низкая | высокая | средняя |
| Сложность реализации | низкая | средняя | высокая |
| Мобила | лучший | дерево + шторка | столбец карточек |

## Рекомендация Майи

Если выбирать один — **B «Инспектор»**: он единственный, где «каждый доллар» получает паспорт
(разложение цены хода на input/output/cache), и при этом иерархия из спеки видна целиком.
Гибрид тоже возможен: скелет B + фильтры-чипы из C над деревом (они там уже нарисованы) —
тогда перекрёстные вопросы закрываются без отдельного полотна.

## Финал — гибрид B+C (`spend-analytics-v2-final.html`)

Выбор Андрея: скелет «Инспектора» (дерево + постоянный паспорт узла/хода) + фильтры-чипы
из «Полотна», с двумя обязательными уточнениями.

**Только токены, никаких денег.** Стоимость в $ убрана из интерфейса полностью (подписки
делают деньги неактуальными): итог узла в дереве, метрики паспорта, топ моделей, виджет
«Домой» и бейдж чата — всё в токенах (итог узла = in + out + cache read + cache create,
разбивка всегда рядом). Следствия без денежной рамки:

- «Из чего сложилась цена» хода → «Состав хода по типам токенов» (cache read обычно
  доминирует — подпись объясняет, что это переиспользованный контекст, а не новый расход);
- бесплатные модели — просто зелёная серия источника с бейджем «бесплатная», без «0 $»
  и «экономии»; их токены равноправно складываются в объём;
- у fal.ai токенов нет — он показан счётчиком генераций («12 генераций») вне шкалы
  токенов: в дереве у строки-операции, в легенде источников отдельным пунктом.

**Pivot-иерархия.** Порядок уровней дерева пользователь собирает сам, как в сводных
таблицах: цепочка чипов-уровней в шапке дерева (⋮⋮ перетащить, × убрать, «+ уровень»
добавить, «Сбросить к умолчанию»). Разрезы-уровни: пользователь (только админ-режим),
проект, чат/задача, персона, провайдер, модель, источник. Дефолт — пользователь → проект
→ чат/задача → ход. Дружба с границей окна:

- **«Ход» — всегда терминальный уровень**: в середину цепочки не ставится (в меню
  «+ уровень» пункт заблокирован подписью «только последним · в окне»), чип нарисован
  пунктиром в info-цветах с подписью окна — это «особый» уровень, живущий только внутри
  детального окна;
- pivot без «хода» заканчивается агрегатами — тогда паспорт узла предлагает кнопку
  «Показать ходы среза · в окне 30 дней»;
- узлы целиком старше окна — 🔒 с плашкой «только дневные агрегаты», динамика в паспорте
  приглушена и отделена пунктирной линией (как и раньше).

Фильтры-чипы (строка «Срез:» из варианта C) и pivot независимы: фильтр сужает данные,
pivot задаёт группировку. На мобиле обе строки — горизонтальный скролл, перестановка
уровней — долгий tap (drag на touch не нужен); паспорт — bottom-sheet.

Приватность сохранена: клик по чужому ходу открывает паспорт (метрики), подпись
«содержимое сообщений недоступно» на месте. Состояния: пусто, загрузка-скелетон, ошибка,
«фильтры отсекли всё» (с кнопкой сброса среза), «узел за окном». Обе темы, 390px.

## Прототип — Обзор → Анализ (`spend-analytics-v2-prototype.html`)

Итерация 2 по обратной связи Андрея на финал: гибрид B+C хорош как инструмент, но слишком
глубок для входа в раздел, а персональный вид не был проработан. Раздел стал
**двухуровневым**:

- **«Обзор»** — стартовый экран в духе варианта C «Полотно»: герой-метрика периода,
  столбики по дням со стеком источников и честной границей окна, карточки разрезов
  (пользователи — только админ, проекты, модели, чаты и задачи, источники, персоны,
  дорогие ходы). Ничего не настроено — экран полезен с первого взгляда.
- **«Анализ»** — финальный гибрид B+C: pivot-дерево + паспорт узла/хода, фильтры-чипы,
  раскладки-пресеты. Клик по ЛЮБОМУ элементу обзора открывает анализ с уже применённым
  контекстом (модель → фильтр модели, день → фильтр дня, «разложить →» → этот разрез
  первым уровнем pivot, дорогой ход → сразу его паспорт с раскрытым путём). Назад —
  вкладкой «Обзор»; явное переключение всегда в шапке.

Это не набор нарисованных состояний, а работающее демо: все суммы реально пересчитываются
из встроенного датасета (seeded-генерация, без сети), фильтры/pivot/периоды/роль меняют
оба экрана.

**Что кликать (сценарии приёмки):**

1. Кнопки-сценарии над прототипом: «Куда ушли токены opus-5?», «Во что обходится Майя?»,
   «Что вчера съело больше всего?», «До самого дорогого хода чата» — каждая приводит
   в анализ с готовым контекстом.
2. Обзор: клик по строке любой карточки → анализ с фильтром; клик по дню графика →
   анализ дня; «разложить →» в шапке карточки → pivot по этому разрезу; строка в
   «Дорогих ходах» → паспорт хода.
3. Анализ: раскрытие дерева до хода (паспорт хода: in/out/cache, состав, соседние ходы);
   чужой ход у админа — «🔒 содержимое сообщений недоступно», свой — «Открыть чат →»;
   чат целиком старше окна — 🔒 и «только дневные агрегаты».
4. Pivot: пресеты «Кто и где / По моделям / По персонам / По источникам», × на чипе
   уровня, меню «+ уровень» («Ход» — только последним, в окне), «Сбросить».
5. Фильтры: «+ фильтр» → разрез → значение (с суммами), комбинация чипов, «Сбросить срез»;
   недостижимый срез (фильтр дня + период «Неделя») → состояние «под срез ничего не попало».
6. Роль в чёрной панели: **Админ** (все пользователи, тумблер «Мои/Все», уровень
   «Пользователь») / **Пользователь** (только своё: «мои проекты», «мои модели», без
   пользователей где-либо) / **Новичок** (empty-state «Трат ещё нет» на обоих экранах).
7. Тема светлая/тёмная; мобильный фрейм 390px — те же переходы, паспорт — bottom-sheet.

Границы прототипа: демо-окно детализации N=14 дней; перестановка уровней pivot — через
пресеты и «+ уровень»/× (drag в прототипе не эмулируется); виджет «Домой» и бейдж чата
не дублируются — они без изменений показаны в `spend-analytics-v2-final.html`.

## Как смотреть

Каждый файл самодостаточен: открыть в браузере, кнопка справа вверху переключает светлую и
тёмную тему. Внутри секции: дашборд (оба режима), виджет «Домой», бейдж чата, мобильные
фреймы 390px, все состояния. Шрифты тянутся с Google Fonts; без сети сработают фолбэки
(Georgia / system-ui / monospace).
