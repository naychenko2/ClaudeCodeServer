# ADR-025: «Формат» — размер и пропорции картинок и видео

- **Статус:** реализовано, смержено 2026-10-07. Разрез — Александр, решения Андрея 2026-10-06; финальное ревью Александра 2026-10-07 (правки Б2.8 внесены). За флагом `media-format` (dark launch, выключен по умолчанию). Нарезка на блоки Б1–Б4 — [media-format-implementation-plan-2026-10.md](../research/media-format-implementation-plan-2026-10.md).
- **Основа:** макет [media-format-v1.html](../mockups/media-format-v1.html) и записка [media-format-v1-proposal.md](../mockups/media-format-v1-proposal.md) (тексты интерфейса, 9 сценариев), [ADR-023](ADR-023-turn-context.md) (строка контекста), [ADR-014](ADR-014-internal-subsystems.md) (границы вертикалей), [ADR-021](ADR-021-audio-editor-and-generation-panel.md), [ADR-022](ADR-022-video-editor.md).
- **Контракты и JSON-примеры:** [ADR-025-contracts.md](ADR-025-contracts.md) — тест `MediaFormatContractExamplesTests` держит их синхронными с типами.

## Контекст

Единого места, где человек или агент задают размер результата, нет, и заданное не доходит до модели:

- `ImageEditCaps` знает лимиты **входа**, но не выходные пропорции и размеры; `AspectRatio` приходит только из REST-запуска, MCP `image_generate` его не передаёт; `Edit.Ratio` из префов сервер валидирует, но нигде не применяет.
- fal картинки: `aspect_ratio` уходит только у kontext и nano-banana, `image_size` — нигде. Котировка fal за мегапиксель считается по размеру исходника. Higgsfield: проба `get_cost` идёт без пропорций. local: по одному размеру на пропорцию (`ComfyWorkflows.ImageSizes`).
- Видео: `VideoCaps.Aspects` есть, разрешения нет (у fal — частный `params.resolution`, у local — `size`); local H3 пропорции игнорирует (ориентацию даёт первый кадр); котировка строится без параметров, цена от разрешения не зависит. Кадры A/B уходят как есть.
- Фильм собирается всегда в 1280×720 (`FilmFormat.AspectSize`, `FilmAssembler`), сцена в 1080p при склейке уменьшается.

## Решения

1. **Общий тип в Core, `ClaudeHomeServer.Services.Media`** (namespace уже в `CoreAllowedNamespaces`): `MediaFormatCaps`, `FormatTierSpec`, `ExactSizeSpec`, `MediaFormat` (желание), `ResolvedFormat` (действующий), `MediaFormatResolver`, `AspectCrop`. Две копии по вертикалям разошлись бы, а ссылка вертикаль → вертикаль запрещена. `ImageEditCaps` и `VideoCaps` получают поле `Format: MediaFormatCaps?`; `null` — «Как у модели» (модель размеров не сообщает), текущее поведение без регрессий.
2. **Одна точка правды — каталог модели у драйвера**, арифметика (ближайшая пропорция, ступень, округление «Точно…», причины, фразы `Note`) — **только `MediaFormatResolver`**. Фронт её не повторяет: ручка `format` отдаёт посчитанное.
3. **Ступени «Стандарт / Высокое / Макс»** отображаются каталогом на родные размеры модели. Ступень без размера модели **серая с причиной**; автоматического апскейла нет. Единственное исключение — `PostStep = upscale` у «Макс» local MiniMax H3 (1440p = съёмка `full` + латентный апскейл на своей GPU, решение 1 Андрея). **fal MiniMax H3:** по живой схеме «480P и 768P — родные режимы, 2K и 4K — увеличение 768P-основы», поэтому «Стандарт» = `480P`, «Высокое» = `768P`, «Макс» серая с причиной «2K и 4K у модели — увеличение, а не родной размер»; умолчание без желания — по-прежнему родные 768P (`DefaultTier`). Прежняя версия каталога выдавала 2K/4K за родные ступени — это отклонение отменено. `PostStep` вводится в контракте сразу (КТ-1), иначе контракт ломался бы на КТ-2.
4. **Хранится только желание** (`MediaFormat`), действующий формат считается на каждом чтении (каталог, котировка, хвост хода, запуск). Подмена при смене модели временная по построению: вернул модель с 16:9 — вернулся 16:9. Писать подставленное значение запрещено.
5. **Хранение.** Картинки — `ImageProjectPrefs.Format` (аддитивно, PUT сливает, `Validate` проверяет белые списки, событие `image_prefs_changed`). Видео — `VideoPrefsDto.Format` и `VideoSceneSettingsDto.Format`; `Aspect` остаётся зеркалом. Фильм — `schema` 1 без новых полей: формат фильма — пропорции и размер первой сцены. В сторе `ChatContext` формата нет: он зависит от «Чем», а «Чем» живёт в префах вертикали.
6. **«Как у исходника» (`mode = source`)** — умолчание правки (`edit`/`inpaint`/`removeBackground`), бывший `matchSourceSize`; Поле запуска `matchSourceSize` (вернуть размер оригинала после скачивания) — **не синоним** `source`, а отдельный флаг запуска: формат `source` объявляет «как у исходника» в чипе и котировке, `matchSourceSize` приводит варианты к размеру исходника уже после модели (у «Дорисовать» и «Улучшить» не действует). Связывать их не нужно: оба описывают одно намерение на разных стадиях. Другие пропорции — явный выбор: **«Дорисовать края»** = `outpaint`, **«Обрезать»** = шаг без ИИ. Модель сама не растягивает и не режет.
7. **Обрезка — одна серверная точка для человека и агента.** `AspectCrop.Rect` + `transform` (`crop`); результат — **новая версия** картинки, карточка в ленте та же. У агента — `image_generate(op = crop, aspect, anchor)`: бесплатно, провайдера и котировку не трогает, формат проекта не меняет (решение 4 Андрея; пункт «инструмента обрезки у агента нет» черновика отменён). `op = edit` с чужими пропорциями у агента — отказ с подсказкой про `outpaint` и `crop`.
8. **Агент.** `image_generate` получает `aspect`, `quality` (`standard|high|max`), `width`, `height`, `anchor`; видео — `quality`. У аргументов формата оговорка `NotWithoutAsk`. **Схемы MCP статичны:** пропорции модели в `enum` не попадают (описание — постоянная строка «смотри `image_state`»), состав `tools/list` не меняется; сторож — `McpSchemaParityTests` + `McpToolsetStabilityTests`. Явный формат агента пишется в префы проекта с `By = Agent` (✦, тихая строка из сервиса префов, решение 2); ручная запись снимает ✦. `video_shoot` с `aspect`/`quality` пишет формат и в сцену тем же путём, что `video_scene_set`; формат, унаследованный из префов, ✦ не получает (`VideoSceneFormat.SameWish` сравнивает режим, пропорции, ступень и размер, без автора и времени).
9. **Хвост хода.** `IContextKindProvider.DescribeFormat(scope, primary)` (необязательный, реализация по умолчанию) → строка «Формат: …» в хвосте и в `context_state`, **и в режиме «Чат»**, с правилом «не передавай aspect/quality/width/height без просьбы человека». `image_state` перечисляет пропорции и ступени текущей модели.
10. **Умолчание без сохранённого формата — «Как у модели»** (решение 3).
11. **Фильм** собирается в формате первой сцены (Б2): размер первого клипа, чётный, потолок 4096; сцены другого формата — `scale…decrease + pad black`; замок пропорций — на сервере (`409 film_format_locked`, `force`); тот же `BuildConcurrencyGate`, таймаут растёт с площадью.

## Как формат доходит до модели

| Драйвер | Пропорции | Ступень / точный размер |
|---|---|---|
| fal картинки | `aspect_ratio` | `image_size {width,height}` у моделей с `Exact`; ступень — параметр модели по живой схеме |
| Higgsfield картинки | `params.aspect_ratio` | `params.resolution`, если есть в схеме |
| local картинки | выбор размера по пропорции | `LocalImageRequest.Width/Height` → `EmptyLatentImage`, кратно 16 |
| fal видео | `body[model.Aspect]` | `body[WireParam] = WireValue` |
| Higgsfield видео | `aspect_ratio` | `resolution` из схемы |
| local H3 | подрезка кадра | `size = half/full`, «Макс» = `full` + апскейл |

Котировка получает `ResolvedFormat`: ступень входит в цену; если живой прайс по ступеням не различается — цена = прайс × `PriceFactor` с пометкой `approx`.

## Инварианты и сторожа

| Инвариант | Сторож |
|---|---|
| Округление и «ближайший» — только `MediaFormatResolver` | юниты резолвера (сценарии 2, 3, 9) |
| Хранится желание, а не подмена | тест A(16:9) → B → A |
| Формат реально уходит в модель | тела запросов драйверов на фейках, мутация «убрать параметр» |
| Цена учитывает размер | тесты котировки |
| Схемы MCP статичны | `McpSchemaParityTests` + `McpToolsetStabilityTests` |
| Границы вертикалей | тип в Core; видео режет кадр через `IImageRaster`, апскейл — через `ILocalVideoMedia`; `SubsystemBoundaryTests` без новых allow |
| Модель сама не тянет и не режет | отказ `edit` с чужими пропорциями у агента |
| Контракт JSON | `MediaFormatContractExamplesTests` |
| Совместимость | префы, нити, сцены и `.film` без формата читаются; `BackupSchema.Version` не меняется |

## Решения Андрея по открытым вопросам разреза

1. «Макс» у local H3 — **1440p через апскейл** (`PostStep`); у остальных моделей без родного размера — серая с причиной.
2. Явный формат от агента **меняет формат проекта** с ✦.
3. Умолчание — **«Как у модели»**.
4. У агента **есть обрезка** `op = crop`.

## Цена ступеней

`FormatTierSpec.PriceFactor` — множитель цены, когда живой прайс по ступеням не различается; цена тогда `approx`. Проверено `get_pricing` 2026-10-07: у fal Veo 3.1 Lite и MiniMax H3 одна цена `$0,05/с` без разбивки по разрешению, достоверных множителей нет — они остаются `1`, а цена любой ступени fal-видео помечена оценочной (`PriceVaries`). У Higgsfield видео цена приходит из `get_cost` с реальной ступенью, у картинок fal множители 1,5 и 2 — оценка.

## Поведение без флага `media-format`

Флаг прячет интерфейс, но сервер обязан вести себя как в master там, где человек нового не видит:

- **Подрезка кадров видео — только по явному формату** (`format` в запросе, сцене или префах); желание, собранное из прежнего поля `aspect`, кадр не трогает и растр не требует.
- **Явные пропорции запуска старого UI (`aspectRatio`) выше сохранённого формата**; сохранённый подставляется, только если явных нет. Сама подстановка формата префов в котировку генерации идёт только при включённом флаге.
- Описания `local_*` перенаправляют в редактор только у `local_generate_image`, `local_edit_image`, `local_face_detail`, `local_image_to_video`.
- Остаётся видимым без флага и безопасно: строка «Формат:» хвоста хода и в `image_state`/`video_state` (честно пишет «как у модели», пока формат не задан); MCP-аргументы формата (агент не передаёт их без просьбы, схемы статичны, запись ✦ в префы — только по явному решению агента); замок формата фильма на сервере (`409 film_format_locked` — фронт без флага показывает его тостом); сборка старых фильмов в формате первой сцены.

## Цена

- Первая пересборка старого фильма после выкатки выйдет в размере первой сцены, а не в 720p; метка «устарел» не зажигается (хеш входов прежний).
- `edit` с чужими пропорциями у агента теперь отказ (раньше пропорции молча терялись).
- В `local` картинок размер задаётся таблицей, а не произвольным: «Точно…» округляется кратно 16.
