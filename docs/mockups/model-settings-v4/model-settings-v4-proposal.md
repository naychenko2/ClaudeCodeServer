# Настройка моделей v4 — предложение

## Проблема

Пользователь открывает настройку моделей — и не может ей доверять. Аудит master на 14.08.2026 нашёл 30 проблем (реестр A1–E5): настройка выглядит заданной, а работает иначе (уровень задачи подписан чужой моделью — A1); клик по чипу обещает смену модели, а открывает редактор цепочки (A3); цепочки правятся только из раскрытого слота, удалить или переименовать нельзя (B1, B2); бюджет подмен существует в коде и тестах, но не имеет ни одного потребителя (B3); раздел открывается на деньгах, а не на настройке (D1); «Исключения» спрятаны на два уровня вглубь (D2); в одном окне живут два словаря слоёв (E4) и запрещённые слова «слот», «CLI» (E1, E2). И главное: обещание «правка цепочки действует везде сразу» неверно для начатых разговоров — и об этом нигде не сказано (C1).

## Решение

Четыре принципа, на которых построена переработка:

1. **Настройка говорит правду.** Каждое место, где выбирается модель, показывает серверное превью «Сейчас пойдёт» — ту же дорогу, что пойдёт боевой ход. Чьи настройки сработают — подписано явно (задача: «развернётся по настройкам Глеба»). Заморозка модели начатого чата названа в карточке нового чата и в композере, а не скрыта.
2. **Один словарь.** «Слот» → «уровень», «CLI» → «выберет Claude Code сам», «Исключения» → «Особые правила для специальностей», «пресет» → «цепочка». Одна пара слоёв везде: «Для всех / Только для меня» (+ «Пользователю…» — только админу). Полный лист замен — [../../design/model-settings-copy.md](../../design/model-settings-copy.md).
3. **Структура отвечает на вопрос пользователя.** Порядок вкладок — от настройки к деньгам: «Модели по умолчанию» (стартовая) → «Особые правила» → «Применение моделей» → «Цепочки» → «Квоты и деньги». Цепочки получили свою вкладку с жизненным циклом: имя при создании, бейдж слоя, список мест при удалении, строка бюджета подмен со степпером; мёртвый шаг помечается заранее и **условно** — только когда (шагов − 1) > бюджета, постоянная надпись врала бы (первый шаг — не подмена, поэтому 5 шагов при бюджете 4 отрабатывают целиком).
4. **Меньше вложенности, видимое наследование.** Панель внутри панели убрана: один клик по чипу — одна панель выбора (поиск + цепочки + модели + «Собрать новую цепочку» с живым переходом на вкладку). У персоны — три поля «Сильная / Средняя / Слабая» с источником наследования прямо в поле («Наследуется от специальности…», «Своё значение · вернуть наследование»), а не лестница осей и не скрытые дефолты.

## Прототипы

Кликабельные, обе темы (переключатель в шапке), мобильная раскладка шторками:

- [index.html](index.html) — раздел целиком: пять вкладок, карточки уровней с хвостом цепочки и счётчиком мест, единая панель выбора, вкладка «Цепочки» с бюджетом, диалоги создания/удаления/подтверждения общей цепочки;
- [special-rules-groups.html](special-rules-groups.html) — **итоговая вкладка «Особые правила» на реальных данных прода**: 14 специальностей × 3 уровня = 42 правила, картина по уровням (полосы), группы одинаковых наборов, все три слоя (полный/пустой/частичный), редактирование роли и мастер добавления в пределах двух уровней вложенности, мобильные шторки;
- [special-rules-variants.html](special-rules-variants.html) — варианты A «Список правил» и B «Карточки специальностей» (итерация 3, фантазийные 5 правил). **Отменены итерацией 4**: оба рисовались на выдуманном объёме и не отвечали на вопрос «как у меня всё устроено» при реальных 42 правилах; оставлены как история;
- [persona.html](persona.html) — форма персоны: блок «Модели» из трёх полей с видимым наследованием (E5), мастер создания с необязательным шагом «Специальность» и предзаполненными полями (B6), предупреждения о самоссылке шага и сабагенте в чужом чате (B8, C5);
- [task.html](task.html) — форма задачи: честная подпись владельца настроек (A1), «Сейчас пойдёт» по маршруту исполнителя, вариант «Я сам» с пустым уровнем;
- [chat.html](chat.html) — карточка нового чата с плашкой-сделкой о заморозке (C1), композер с «Сейчас пойдёт» и freeze-note, кликабельная пометка подмены с путём цепочки (B5).

Покрытие реестра: A1–A3, A5, A6, B1–B3, B5–B9, C1, C2, C4, C5, D1–D3, D5, E1–E5 плюс решение от 14.08 (упрощение модели настройки: три поля персоны вместо «Уровня модели»/«Всегда работает моделью», специальность без «Уровня по умолчанию», явный дефолт «сильная» у места «Исполнитель задач», условное предупреждение о бюджете). Вне объёма итерации (по решению человека): B4 (выбор цепочки в чате) — следующей итерацией; C3 закрыт текстом-подсказкой; дефолт бюджета 4 не меняется; A4 (смерть черновика цепочки) закрывается в реализации — редактор цепочки живёт внутри карточки на вкладке «Цепочки», без вложенных панелей, теряющих состояние.

## Итерации правок

- **Итерация 1 (14.08.2026)** — первая сдача: четыре прототипа + лист текстов. Ждёт показа человеку.
- **Итерация 2 (14.08.2026)** — перевыдача по решению человека: у персоны убраны «Уровень модели» и «Всегда работает моделью» (0 из 175 на проде) — блок «Модели» стал тремя полями с видимым наследованием и «вернуть наследование»; мастер создания: шаг «Специальность» необязателен («Пропустить»), поля предзаполнены наследованием. У специальности убран «Уровень по умолчанию» (0 из 14) — вкладка стала матрицей «Специальность × Сильная/Средняя/Слабая» с первой строкой «Любая специальность» и dashed-ячейками «Как …». Место «Исполнитель задач» получило собственный дефолт — сильную модель: в задаче появился явный вариант «По умолчанию», задача без уровня не дешевеет молча. Предупреждение о бюджете подмен стало условным: первый шаг цепочки подменой не считается, цепочка из 6 шагов при бюджете 4 помечает мёртвым только шестой. Лист текстов пересобран: убранные настройки не упоминаются нигде.
- **Итерация 3 (14.08.2026)** — три приоритетные правки человека:
  1. **Потолок цепочки — пять моделей** (серверный `HardMaxSubstitutions`, 400 на шестой). Шестой шаг убран из всех примеров; кнопка «Добавить шаг» на пятом шаге гаснет с подписью «В цепочке не больше пяти моделей». Условное предупреждение о бюджете теперь демонстрируется честно — на вручную опущенном бюджете: степпер «Подмен за один ход» в index.html кликабелен, при бюджете 2 шаги 4–5 приглушаются и появляется пересчитанная строка-предупреждение (и в цепочке, и в хвосте уровня «Сильная»).
  2. **Из списков «Используется в 4 местах» убрана строка «Чат … — модель чата»** — выбор цепочки в чате (B4) в эту итерацию не входит; место заменено реальным: «Персона «Александр» — поле «Сильная»» (в списке цепочки и в диалоге удаления).
  3. **Вкладка «Особые правила» переработана** — матрица «специальность × уровень» давала горизонтальный скролл и показывала 42 ячейки при пяти заданных. Сделаны **два кликабельных варианта** ([special-rules-variants.html](special-rules-variants.html)): **A «Список правил»** — видны только заданные поля строками-фразами, редактор раскрывается под строкой, мастер добавления из трёх шагов в одной панели; **B «Карточки специальностей»** — каждая роль карточкой со сводкой, незаданные свёрнуты в «Без своих правил — 10 специальностей». Оба — без скролла на любой ширине, со слоями, «Любой специальностью», «Сейчас пойдёт» и честной таблицей «что выигрывает / чем платит». В index.html встроен вариант A как рабочий эталон; **выбор между A и B — за человеком**.
- **Итерация 4 (14.08.2026)** — «Особые правила» перерисованы на реальном объёме прода (решение человека: «показать реальное количество данных и адаптировать под этот объём»). Данные — `specialty-settings.json` с боя: 14 специальностей × 3 уровня = 42 правила + 3 поля «Любой специальности», все в слое «Только для меня» (общий слой пуст, у пользователя Марина — 4 поля из 45). Варианты A/B отменены: оба рисовались на пяти фантазийных правилах. Новая раскладка — [special-rules-groups.html](special-rules-groups.html):
  1. **Проверка гипотезы.** Гипотеза «4–5 профилей и пара особых ролей» подтвердилась частично: различных троек 9 (14 → 9, −36%), самая большая группа — 3 роли. Зато повторяемость ярко выражена **поуровнево**: сильную закрывают 2 цепочки на 11 ролей из 14, среднюю — «Средний — экономный» ×9, слабую — две цепочки на все 14. Поэтому:
  2. **Картина по уровням** — три пропорциональные полосы «Сильная/Средняя/Слабая» с долями цепочек; клик по сегменту подсвечивает его карточки. Отвечает на вопрос «как у меня в целом устроено» без прокрутки.
  3. **Группы одинаковых наборов** (9 ролей в 4 группах) с предупреждением «Изменение применится к N ролям» и действием «выделить» (роль получает копию набора) + **отдельные наборы** (5 ролей). Совпадение с тройкой «Любой специальности» подсвечено заметкой — такие роли можно не настраивать.
  4. **Все три слоя на реальных данных**: «Только для меня» — полный (45 полей), «Для всех» — пустой (плашка + переход на личный слой), «Пользователю Марина» — частичный (4 поля, «не задано ×N» пунктиром, наследование «Как у владельца · …»).
  5. **Вложенность ≤ 2 уровней**: редактор роли раскрывается в карточке, мастер добавления — одна панель из трёх шагов; панелей-в-панелях нет. «Сейчас пойдёт» сохранена в каждом редакторе. Мобильная раскладка — шторки, горизонтального скролла нет и на 320px.
  6. **Лист текстов обновлён** ([model-settings-copy.md](../../design/model-settings-copy.md)): строки для полос, групп, пустого и частичного слоёв; два новых согласуемых пункта — смысл бейджа-45 при полном покрытии и дефолтный слой вкладки при пустом «Для всех».
