# Панель фичи в чате: таблица токенов

Привязка: эпик `9919bd75-0b1c-4fda-8196-72354cbcba29`, шаг **М2** (lane front). Макет —
[`feature-banner-1.html`](feature-banner-1.html), записка — [`feature-banner-1.md`](feature-banner-1.md).

**Как читать.** Переменная макета `--c-x-y` = токен `C.xY` из `lib/design.ts` (`--c-bg-card` → `C.bgCard`,
`--shadow-card` → `SHADOW.card`). Сырые hex и `rgba()` в `.tsx` запрещены, их ловит `npm run lint:design`.
Литерал без токена допустим только там, где он прямо написан в таблице (как `gap: 7` в волне 2).
Кнопки, которые не идут через `ui/Button` / `ui/IconButton`, обязаны выполнить раздел 0
`features-overview-2-tokens.md` (сброс рамки longhand'ами, `fontFamily: FONT.sans`, фон, цвет, поля, фокус
`SHADOW.focus`, кнопка в кнопке запрещена).

## 8. Тёмная тема

Все цвета макета — переменные `theme.css`; отдельных значений для тёмной нет. Замер Playwright прошёл
обе темы. Единственное, что стоит глазами проверить в коде: кнопка «Ответить» на фоне `info` с текстом
`onAccent` — в тёмной `info` светлый, а `onAccent` тёмный, контраст читается (кадр `*-dark-*-open.png`).
