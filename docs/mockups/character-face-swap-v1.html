«Подставить персонажа» на лицо

Человек собрал сцену, а у второго человека на картинке «не то» лицо: тап по рамке лица → выбор персонажа → «Подставить». Остальная картинка не меняется. Три варианта, где живёт выбор: A — в редакторе, как обрезка (рекомендую), B — прямо в карточке версии в ленте, C — отдельное окно-мастер.
