# Цвета аналитики расхода: классы цены и палитра источников

- **Статус:** черновик
- **Файлы:** spend-tier-palette.md

Задача трекера `1ca36934` (без эпика). Решение — моё (Майя), реализует Полина. Просьба Андрея от 26.10:
«бесплатно / дёшево / дорого» должно читаться одинаково во всех разделах аналитики.

## Сценарий и проблема

Человек открывает «Расход», видит синюю полосу в «Источниках» и читает её как «дёшево», а оранжевую — как
«дорого». Это ошибка: синий там означает «Фоновые», оранжевый — glif. Один цвет несёт два смысла, и
человек доверяет первому, который выучил, то есть цене.

## Принцип

**Зелёный, синий и оранжевый (`C.success`, `C.info`, `C.warning`) в аналитике расхода значат только
цену.** Любая другая серия (источник, тип чата, граница окна) берёт цвет вне этой тройки. Есть одно
исключение — источник «Бесплатные»: он и есть класс «бесплатно» (бэк считает `freellm*` бесплатными,
`SpendCostTiers.IsFreeProviderKey`), так что зелёный там говорит правду, а не путает.

## 1. Палитра источников (`SPEND_SOURCES`, `spendModel.ts`)

| Источник | Было | Стало | Почему |
|---|---|---|---|
| `chat-turn` «Ходы» | `C.accent` | `C.accent` | без изменений: терракота — цвет продукта, не цены |
| `one-shot` «Фоновые» | `C.info` | **`C.textSecondary`** | фоновая работа системы → нейтральный тёплый серый; синий освобождается для «дёшево» |
| `fal` | `C.plan` | `C.plan` | без изменений |
| `glif` | `C.warning` | **`C.rose`** (новый токен) | оранжевый освобождается для «дорого» |
| `free` «Бесплатные» | `C.success` | `C.success` | то же значение, что у класса (см. принцип) |
| `tts` «Озвучка» | `C.navInk` | `C.navInk` | без изменений |

Свободных цветных токенов вне тройки нет: `accent`, `plan` и `navInk` уже заняты, `danger` читается как
ошибка, `textMuted` — откат для неизвестного источника. Поэтому нужен **один новый токен в обе темы**.

### Новый токен `rose` (+ текстовая пара)

`theme.css`:

```css
/* :root (светлая) */
--c-rose:      #B0527C;  /* серия «glif» в аналитике расхода; вне тройки цены */
--c-rose-text: #8E3D62;  /* моноширинные значения glif на подложке */

/* :root[data-theme="dark"] */
--c-rose:      #D683A6;
--c-rose-text: #E7A3C0;
```

`design.ts`, в группу статусных/серийных цветов рядом с `plan`:

```ts
rose:     'var(--c-rose)',      // серия glif в аналитике расхода (вне цветов цены)
roseText: 'var(--c-rose-text)', // значение glif текстом
```

Тон 333° по кругу: далеко и от терракоты `accent` (15°), и от `danger` (10°), и от индиго `plan` (250°),
поэтому рядом в стеке glif с ними не сливается.

Следом в `spendModel.ts`:
- `sourceTextColor`: ветка `glif` → `C.roseText` (было `C.warningText`); у `one-shot` текстовый цвет —
  тот же `C.textSecondary`.
- Комментарий у `SpendOverview.tsx:96` («у glif — warning») поправить на rose.

### Мелкие пересечения рядом (тоже внутри аналитики)

| Место | Было | Стало |
|---|---|---|
| `KindTag` «задача» (`spendUi.tsx:33`) | `C.infoBg` / `C.info` | `C.bgSelected` / `C.textSecondary` (у «чат» остаётся `accentLight`/`accent`) |
| `WindowBadge` «Детально: N дней» (`spendUi.tsx:184`) | `C.infoBg` / `C.info` | `C.bgInset` / `C.textSecondary` |
| Пунктир границы окна в `DaySpark` (`SpendAnalysis.tsx:634`) | `C.warning` | `C.textMuted` |

Синяя «задача» в строке модели выглядит как пометка «дёшево»; граница окна оранжевым — как «дорого».
Это служебные пометки, им достаточно нейтрального.

## 2. Подписи классов

Один вид: **прилагательное, согласованное с тем, к чему относится.**

| Где | free | cheap | expensive |
|---|---|---|---|
| Легенда, столбик дня, метрика (`COST_TIERS.label`) — про модели, мн. ч. | Бесплатные | **Дешёвые** | **Дорогие** |
| Пилюля на карточке провайдера/квоты (`COST_TIER_PILL`) — про провайдера, м. р. ед. ч. | бесплатный | **дешёвый** | **дорогой** |

Наречия «дёшево/дорого» уходят: рядом с «Бесплатные» они ломали ряд. Регистр как сейчас: в легенде с
заглавной, в пилюле строчными. Порядок везде один: бесплатные → дешёвые → дорогие (`COST_TIER_KEYS`);
обратный порядок остаётся только у стека столбика (`TIER_KEYS`, снизу вверх).

## 3. Где показываем класс, где нет

| Поверхность | Решение | Почему |
|---|---|---|
| Значение токенов в строках карточек (`SpendOverview.tsx:115`) | **Не красим по классу.** Значение остаётся `C.accent`, у бесплатного источника `C.successText` | Класс в строке уже несёт полоса (`rowBarColor` по классу у моделей и провайдеров). Второй носитель на цифре даст оранжевые и синие числа вперемешку, и столбец перестанет читаться как столбец величин. Зелёное значение у «Бесплатных» оставляем: оно совпадает со смыслом |
| Бейдж расхода в чате (`SpendBadge.tsx:47-48`) | **Оставляем «бесплатно / нет»**, три класса не вводим | Бейдж показывает сумму по всему чату, а в одном чате бывают модели разных классов, так что у суммы класса нет. Зелёный бейдж при бесплатном последнем ходе честен, `accent` у остальных — не цвет цены |
| Виджет «Домой» (`SpendWidget.tsx`) | **Без классов** | Кольцо — одна величина (доля). Делёж на классы раздует виджет, а ответ «сколько дорогого» живёт в «Обзоре» в один тап |
| Мини-график дня в «Анализе» (`DaySpark`, `SpendAnalysis.tsx:640`) | **Без классов**, `accent`/`accentMuted` как есть | Столбики по 2 px при высоте 44 px: три сегмента на них не различить. Разбивка по классам есть в большом столбике дня «Обзора» |

Правило на будущее: класс показываем там, где на экране **одна модель или провайдер** (строка, пилюля)
или **есть место под стек с легендой** (столбик дня). На суммах по смешанным моделям класса нет.

## Контраст (WCAG; графика ≥ 3:1, текст ≥ 4.5:1)

Фоны: светлая — `bgCard #FBF8F2` / `bgMain #F4F0E8`; тёмная — `#2E2A25` / `#201C18`.

| Токен | Светлая (card / main) | Тёмная (card / main) |
|---|---|---|
| `rose` (новый) | 4.56 / 4.25 | 5.19 / 6.17 |
| `roseText` (новый) | 6.62 / 6.17 | 7.05 / 8.38 |
| `textSecondary` («Фоновые») | 4.93 / 4.59 | 6.08 / 7.23 |
| `accent` | 2.95 / 2.75 | 5.50 / 6.54 |
| `plan` | 5.22 / 4.87 | 4.47 / 5.31 |
| `success` | 3.75 / 3.50 | 6.05 / 7.19 |
| `info` | 4.27 / 3.98 | 5.01 / 5.95 |
| `warning` | **2.58 / 2.41** | 6.93 / 8.24 |

Новые цвета проходят в обеих темах. **Старый долг, не этой правкой:** в светлой теме `C.warning`
(«дорого») и `C.accent` не дотягивают до 3:1 как графика. Сегмент и точка всегда стоят рядом с
подписью класса, поэтому смысл не теряется (1.4.11 требует контраста, когда цвет — единственный
носитель). Если «дорого» понадобится одним цветом без подписи, у текста брать `C.warningText`.
