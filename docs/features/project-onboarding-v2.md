## Что осталось от приёмки

Требования к поведению, которые были условиями снятия флага, остаются требованиями:

- **Ни одной перезаписи чужого файла.** В отчётах применения существующие файлы попадают
  в `skipped`, а не в `created`, — затёртый `CLAUDE.md` считается дефектом.
- **Живут все три пресета** (`docs` / `dev` / `personal`). Мёртвый пресет убираем из
  каталога, а не тащим дальше.
- Приём каркаса меряется метрикой `ccs.intro.preset_applied`
  (`ServerMetrics.RecordPresetApplied`) с тегом `reason`: устойчивое преобладание
  `reason=none` значит, что чинить надо состав каркаса.
