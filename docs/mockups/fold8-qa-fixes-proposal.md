## Принцип решения

| # | Проблема | Существующая механика | Что делаем |
|---|---|---|---|
| 1 | Скролл доски есть (`overflowX: 'auto'`), но спрятан `cc-hide-scrollbar`; колонки `minmax(280px,1fr)` не влезают в 832 никогда | Адаптивные минимумы по брейкпоинту есть в других разделах (пилюли v4, гит-бар) | Планшет/мобила: минимум колонки 240px (3 колонки = 748px — влезают без скролла). При неизбежном переполнении (4+ колонок, телефон): видимый тонкий скроллбар + edge-fade со стрелкой |
| 2 | `hubGrid: minmax(0,1fr) 300px` без брейкпоинта; на ~390px контента колонки воюют | Режим `activityExpanded` уже рисует ленту на всю ширину | На `isTablet \|\| isMobile` сетка → `1fr`: витрина сверху, «Активность» — полноценный блок ниже во всю ширину с собственным скроллом |
| 3 | FAB при overlap с композером ужимается до 36px, но не уезжает — режет пилюлю; авто-команда рисуется тяжёлой карточкой `AgentMessageView` | `--cc-fab-bottom` уже поднимает FAB в PanelZone; компактные разделители `staffNote`/`systemDirective` уже в ленте | Одиночный (не-embedded) ChatPanel ставит `--cc-fab-bottom = высота композера + 12`; авто-слэш-команды → компактный разделитель по прецеденту `systemDirective` |
| 4 | `case 'error'` рисует баннер во всю ширину независимо от возраста | Дневные разделители в ленте есть; группировки нет | Ошибки прошлых дней → группа «Завершённые с ошибкой (N)» под кат, строки-компакты с тихим «↻»; сегодняшние — баннеры как раньше |
| 5 | Tooltip `title=` работает только на десктопе; long-press меню названия не содержит | ConfirmDialog удаления уже показывает полное название | Шапка контекстного меню: полное название с переносом строк + мета (источник · дата), для заметок и папок |

## Спецификация для реализации (Кира)

### 1. Доска календаря — `frontend/src/features/tasks/board/TaskBoard.tsx:155-166`

- `colMin = isTablet || isMobile ? 240 : 280`; сетка `repeat(N, minmax(colMin, 1fr))`, `gridMinWidth = N * (colMin + 16)`. При N=3 на 832: 768 < 800 — скролла нет.
- Снять `cc-hide-scrollbar` со скролл-контейнера; видимая полоса 6px (бегунок `C.divider`, трек прозрачный) — стили в `index.css` рядом с существующими scrollbar-правилами.
- Edge-fade: абсолютный градиент 28px `transparent → C.bgMain` + круглая подсказка «→» 22px (`C.bgWhite`, рамка `C.border`, `SHADOW.card`), `pointerEvents: 'none'`. Показывается при `scrollLeft + clientWidth < scrollWidth − 1`, гаснет в конце; левый fade симметрично при `scrollLeft > 0`. Слушатель scroll + ResizeObserver.
- Десктоп ≥1200px: колонки 280px, поведение прежнее.

### 2. Персоны — `frontend/src/features/personas/PersonasHub.tsx` + `PersonaActivityFeed.tsx`

- `hubGrid.gridTemplateColumns = isTablet || isMobile ? '1fr' : 'minmax(0,1fr) 300px'`, gap 20/28. В одноколоночном режиме «Активность» рендерится после витрины.
- Проверить карточку персоны на предмет фиксированной ширины/`min-width` > колонки (источник перелива на скриншоте) — убрать; карточка обязана сжиматься до 200px.
- «Активность» во всю ширину: обёртка `C.bgCard` + `R.xxl` + `SHADOW.card`; лента `maxHeight: 300` (мобила 220) + `overflowY: 'auto'`; «Показать всё» → существующий `activityExpanded`, механику не трогаем.
- Инвайт-карточка в одноколоночном режиме — в потоке, не поверх витрины.

### 3. AC FAB + авто-команды — `ChatPanel.tsx`, `ChatItemView.tsx`, `AiLauncher.tsx`

- FAB: в не-embedded `ChatPanel` (guard по пропу `embedded`, правило из комментария `ChatPanel.tsx:106-110`) — `ResizeObserver` на композере → `root.style.setProperty('--cc-fab-bottom', composerHeight + 12 + 'px')`; при уходе композера — `'20px'`. На Стене и при прочих препятствиях поведение прежнее (ужимание 54→36 остаётся, но на композер больше не срабатывает).
- Авто-команды: ветка `item.auto && !teamMech` в `ChatItemView.tsx` — если текст начинается с `/`, рендерить компактный разделитель по образцу ветки `systemDirective` (линии `C.border` + плашка `C.bgSelected`, FS 12): для cancel — «⟳ Цикл прерван · команда `/oh-my-claudecode:cancel`», прочие — «⚙ Команда · `/имя`». Не-командные авто-сообщения остаются `AgentMessageView`.

### 4. История ошибок — `ChatPanel.tsx` (построение ленты) + `ChatItemView.tsx` (новый case)

- До рендера: `error` с датой < сегодня склеиваются в `{ type: 'error_group', date, items }` по каждому дню; сегодняшние проходят как раньше. Одиночная ошибка прошлого дня — компактная строка без группы.
- `case 'error_group'`: заголовок-кат (`C.bgCard`/`C.borderLight`, `R.lg`, ▶ с поворотом по `PANEL_ANIM`, счётчик-плашка `C.dangerBg`/`C.dangerBorder`/`C.dangerText`, дата muted справа), раскрытие — локальный useState. Строки: `C.dangerBg`/`C.dangerBorder`, `R.md`, текст FS.sm с ellipsis + `title`; повтор — иконка-кнопка 26×26, условия `canRetry && online` и обработчик те же, что у баннера.
- Не трогаем: сегодняшний баннер, `session_ended`, логику `canRetry`.

### 5. Контекстное меню заметки — `frontend/src/features/notes/NotesList.tsx:600-679`

- Перед первым пунктом `ctxMenu` — шапка: `padding: '7px 10px 6px'`; название `FS.sm / 600 / C.textHeading / whiteSpace: 'normal' / wordBreak: 'break-word'`; мета `FS.xs / C.textMuted` (источник · дата). Дальше существующий divider. То же для `kind === 'folder'`.
- Шапка `pointerEvents: 'none'`. Потолок позиционирования меню `innerHeight − 240` → `− 280`.

### Общее

- Новых токенов не вводим нигде: все цвета/размеры из существующих шкал `C.*`, `FS`, `SP`, `R`, `SHADOW`.
- Touch: hover ни на что не завязан; tap-цели ≥ 32px сохранены (строки группы ошибок 26px — кнопка внутри строки 36px).
- Тёмная тема: правки чисто компоновочные + шкальные цвета — обе темы работают без дополнительных значений.
- Переполнение: длинные названия колонок/заметок/ошибок — ellipsis + полный текст в шапке меню или по тапу.

## Проверка после реализации

1. `npx tsc -b` + `npm run lint:design` — зелёные.
2. Ручной прогон на 832 (Fold 8, обе темы): доска 3 колонок без скролла и обрезки; 4 колонки — fade + полоса; персоны — витрина и «Активность» без наложений; FAB не перекрывает пилюли при росте композера 1–5 строк; авто-cancel — разделитель; ошибки 13.08 — под катом, свежая — баннер; long-press заметки — шапка с полным названием.
3. Регрессия: десктоп ≥1200 (двухколоночные персоны, колонки доски 280, FAB 20px), мобила ≤600 (одноколоночная витрина, fade доски), режим «Стены» (два чата — FAB по-прежнему в углу 20px).
