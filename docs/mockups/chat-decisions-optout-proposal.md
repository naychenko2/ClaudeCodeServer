# Тумблер «Не сохранять решения из этого чата» — предложение

Макет: [chat-decisions-optout-v1.html](chat-decisions-optout-v1.html) (обе темы — переключатель в шапке страницы).

## Проблема

История решений пишется из каждого проектного чата по умолчанию — но бывают чаты,
которые не должны оставлять след: эксперименты, черновые пробы, чувствительные темы.
По ADR-004 §6 нужен opt-out на уровне чата, который уважают и запись решений, и
экспорт в репозиторий. Вопросы дизайна:

1. **Где живёт настройка.** Единого диалога «Настройки чата» в продукте нет — настройки
   распределены: пилюли `NewChatSetup` в пустом чате (модель/усилие/время жизни/теги),
   `ExpiryButton` в шапке начатого, тумблер цикла в композере. Нужно вписаться в
   существующую канву, а не изобретать новый диалог.
2. **Доступность после старта.** Пилюли пустого чата исчезают с первым сообщением —
   если настройка только там, передумать позже нельзя (та же ловушка, из-за которой
   «Время жизни» переехало в шапку кнопкой `ExpiryButton`).
3. **Понятность режима.** Если человек включил исключение и забыл, он будет ждать записи
   в панели «История решений» и не найдёт их — выглядит как поломка.

## Решение

Две точки входа по готовому паттерну «Времени жизни» (пилюля `NewChatSetup` + кнопка
`ExpiryButton` в шапке, общий блок — как `ExpiryPicker`):

1. **Пустой чат** — четвёртая пилюля «История решений» в ряду настроек (только у
   проектных чатов: личные в историю не пишутся в принципе). Значение пилюли —
   «Сохраняются» / «Не сохраняются». Клик раскрывает инлайн-карточку со строкой
   «подпись + Toggle + подсказка».
2. **Начатый чат** — кнопка с иконкой `history` в шапке (паттерн `ExpiryButton`):
   прозрачная иконка в дефолте; при исключении — обведённая пилюля с иконкой accent
   и подписью «Не сохраняются» (на мобиле — только иконка). Клик открывает поповер
   `Menu` с той же строкой тумблера.

**Тексты** — из согласованной заметки «Тексты — Паспорта изменений (UI, empty-state,
«Что нового»)»: подпись «Не сохранять решения из этого чата», подсказка «Записи из
этого чата не попадут в историю решений и не уедут в репозиторий». Формулировка через
«не сохранять», потому что дефолт — записи ведутся: включённый тумблер читается как
осознанное исключение. Слов «паспорт»/«досье»/«летопись» нет.

**Индикация режима** — два тихих сигнала, без бейджей в списке чатов и тостов:

- обведённая пилюля-кнопка в шапке (постоянный индикатор рядом с заголовком чата);
- заметка в панели «История решений», когда панель открыта из чата-исключения:
  «Решения из этого чата не сохраняются. Изменить можно в шапке чата…» — нейтральная
  карточка, не warning: это выбранный человеком режим, а не неполадка.

**Новый микротекст сверх заметки** (предложение, требует согласования): сноска во
включённом состоянии «Уже записанные решения останутся в истории — настройка действует
на новые записи». Снимает главный страх «а что со старыми записями?» в момент включения.

## Состояния и края (в макете)

- Тумблер off/on с одной и той же подсказкой (объясняет настройку, не статус);
  сноска про уже записанное — только в on.
- Пилюля пустого чата в обоих значениях; карточка 380px десктоп / 100% мобила.
- Кнопка шапки: дефолт / исключён; поповер 300px десктоп / 260px мобила.
- Панель «История решений» с заметкой-объяснением поверх пустого состояния.
- Мобильная раскладка 360px для всех поверхностей; обе темы.

## Спецификация для реализации

Готовые контролы: `Toggle` (ui), `Menu` (ui). Новое: общий компонент строки
«подпись + Toggle + подсказка» (по образцу `ExpiryPicker`), пилюля в `NewChatSetup`,
кнопка в `ChatHeaderBar` (по образцу `ExpiryButton`), заметка в панели истории решений.
Токены и поведение — таблица в разделе 6 макета.

## Итерации

- **v1** — первый проход: размещение (пилюля + шапка), состояния тумблера, индикация
  (кнопка + заметка в панели), мобила, обе темы. Открытый вопрос: текст сноски
  «Уже записанные решения останутся…» — согласовать с владельцем текстов.
