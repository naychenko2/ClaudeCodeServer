Тема:

AC-кнопка и авто-карточки у композера

Два смежных дефекта из QA-прогона Fold 8. AC↔«Собеседник»: при подошедшем композере кнопка ассистента не уезжает вверх, а ужимается до 36px и остаётся в углу поверх композера — обрезает пилюлю «Собеседник» (скриншот recheck-05-chat-privetstvie.png). F3: авто-отправленная команда /oh-my-claudecode:cancel рисуется полноценной карточкой «АС Автоматически» и визуально сливается с карточкой метрик хода. Оба живут в одной зоне — нижние 200px чата, — чиним их одним решением.

До (прод)

FAB 36px сидит в углу на --cc-fab-bottom: 20px и ложится прямо на ряд пилюль композера. Авто-команда — большая карточка с акцентной кромкой, над ней метрики хода: два «технических» блока подряд конкурируют за внимание.

После — FAB над композером, авто-команда разделителем (рекомендую)

Когда композер — ближайшее препятствие, --cc-fab-bottom поднимается на высоту композера + 12px: кнопка парит над его верхней кромкой в полном размере 54px, пилюли свободны. Механизм переменной уже существует (PanelZone.tsx:603) — переносим его в одиночный чат. Авто-команда уходит из весовой категории сообщений в компактный центрированный разделитель — точно по прецеденту staffNote («⚑ …») и systemDirective («⟳ Цикл: продолжение N/M»), которые уже живут в ленте.

Краевые случаи

Композер вырос (многострочный ввод, черновик с вложениями) — FAB поднимается вместе с ним: отсчёт от фактической высоты, не константа. Композера нет на экране (лента прокручена, экран чтения) — --cc-fab-bottom возвращается к 20px, кнопка в привычном углу. Режим «Стены» (несколько ChatPanel на экране) — переменную трогает только не-embedded инстанс (правило уже закреплено комментарием в ChatPanel.tsx:106-110), на Стене поведение прежнее. Мобила — там FAB по умолчанию и так 36px, подъём тот же, пилюли композера в один ряд скроллятся под ним свободно.

Спецификация для Киры

1. Подъём FAB. В одиночном чате (не-embedded ChatPanel): ResizeObserver на композере → root.style.setProperty('--cc-fab-bottom', composerHeight + 12 + 'px'); при размонтировании/уходе композера — обратно на '20px'. Guard по embedded обязателен (Стена: инстансы не перебивают друг друга). Ужимание 54→36px (useFabObstacleOverlap) остаётся для прочих препятствий, но с поднятой точкой отсчёта на композер оно больше не срабатывает.
2. Разделитель для авто-команд. ChatItemView.tsx, ветка item.auto && !teamMech: если текст — слэш-команда (начинается с /), рендерить не AgentMessageView, а компактный разделитель по образцу ветки systemDirective (линии C.border + плашка C.bgSelected, borderRadius: 999, FS 12): «⟳ Цикл прерван · команда /oh-my-claudecode:cancel» — для cancel; прочие авто-команды: «⚙ Команда · /имя». Не-командные авто-сообщения (текст от агента) остаются карточкой AgentMessageView.
3. Токены. Новых значений нет: плашка C.bgSelected/C.border/C.textSecondary, FAB C.accent + SHADOW.fab, отступ 12px = SP.md. Обе темы работают через переменные без доработок.
4. Проверка. 832 и 480: FAB не перекрывает пилюли при любом росте композера (1–5 строк); Стена — два чата рядом, FAB в углу 20px как раньше; десктоп ≥1200 регрессии нет.
