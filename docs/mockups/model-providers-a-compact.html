2. Было → стало (по боли)

Было: «Модели по умолчанию»
Полоса чипсов-пилюль «Claude Opus 5 / Sonnet 5 / Haiku», «GLM-4.7 / Air / Flash»… — каждая в две строки, 4–6 штук занимают весь экран; контекст «Общие / пользователь» прячется в меню-кнопке; правка слота разворачивает список пресетов + полный список моделей прямо в потоке.
Стало
Быстрый выбор тройки — один селект «Все три уровня через: …» (в пунктах те же тройки). Слоты — строки с компактным триггером справа; панель выбора открывается под строкой (пресеты → топовые модели → «все модели…»). Контекст — видимые пилюли «Общие · Андрей · Мария · Ещё 2», переключение в один клик.
Было: «Специальности» и «Пресеты»
Девять раскрывашек, внутри каждой — сетка 2×3 «Для всех / Только для меня» на каждый уровень: до одной ячейки — 2 клика и экран скролла. Пресеты развёрнуты всегда: редактор шагов на весь экран даже у чужих (общих) пресетов, которые ты только читаешь.
Стало
Специальности — таблица: строка = специальность, колонки = уровни, ячейка = триггер. Двуслойность поднята наверх в переключатель «Для всех / Только для меня» — ячейки перестали быть сдвоенными. Права/инструменты — за «⚙» в строке-детали. Пресеты свёрнуты: имя + цепочка чипсами одной строкой + слой («для всех»). Раскрытие — только у редактируемого.
