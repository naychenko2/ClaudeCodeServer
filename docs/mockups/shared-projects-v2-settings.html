Что тут

Андрей хочет позвать Марию в проект «Лендинг пекарни». Он открывает привычную модалку «Редактировать проект» (шестерёнка в крошке) — и находит там новую секцию «Участники» рядом с «Руководителем проекта». Отдельного экрана нет: это ещё один аккордеон той же модалки. Мария, открыв ту же модалку, видит проект Андрея только для чтения: кто в нём есть и кнопку «Покинуть проект».
