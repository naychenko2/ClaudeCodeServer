Вариант A — эволюция текущего поповера

Тот же компактный триггер «Фильтр» над списком, но поповер пересобран: поиск, срезы по статусу (В работе / Ждут меня / С ошибкой) вместо «последних 5 минут», новый тумблер «Скрывать чаты выполненных задач» (включён по умолчанию — это и есть «архив задач»), секция «Показать только» и честный футер со счётчиком скрытых. Минимальный дифф от текущей реализации — меняется только содержимое поповера.
