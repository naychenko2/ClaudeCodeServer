# Просмотрщик нот («MIDI»)

Ноты из `.mid` видно на нотной ленте, и их можно послушать: в файлах проекта и в карточке версии
редактора звука. Поставка — **только просмотр**: правки нот, сохранения, смены инструмента и сборки в
WAV нет. За флагом `midi-editor` («MIDI-просмотрщик» в «Экспериментальных функциях», по умолчанию
выключен).

Код — `frontend/src/components/midi/`; разрез решения и этапы — карточка задачи
`ca9cc8d8-fef7-4025-950b-b58586697f27` (разрез Александра); соседний раздел —
[редактор звука](audio-editor.md).

## Что умеет

- **Нотная лента** на canvas: клавиатура слева, такты по размеру из файла, ноты цветом дорожки,
  яркость ноты — по velocity. Если в файле только ударные (канал 10), вместо клавиш — названия ударов.
- **Проигрывание**: «Играть / Пауза», «В начало», время `m:ss / m:ss`, бегущая линия. Клик по линейке
  над лентой переносит позицию. **Пробел** — играть или пауза, когда фокус внутри просмотрщика (на
  кнопке пробел нажимает её саму).
- **Дорожки** — строка чипов, только если дорожек две и больше: имя (или «Дорожка N»), число нот,
  **M** — заглушить, **S** — только эта; повторное S снимает соло. Смена заглушения во время игры
  перезапускает звук с той же позиции, заглушённые ноты на ленте бледнеют.
- **Масштаб**: при открытии трек целиком влезает в ширину, дальше «Мельче» / «Крупнее».
- **Скачать** и **Развернуть** — кнопки появляются, если их даёт место встройки.
- Ошибки: «Файл не похож на MIDI» (нет сигнатуры `MThd`), «Файл MIDI повреждён», «Не удалось
  загрузить файл» — с «Повторить» и «Скачать как есть»; пустой файл — «В файле нет нот». Звук не
  включился — «Не удалось включить звук».

## Где живёт

- **Файлы проекта** — `.mid` и `.midi` открываются просмотрщиком, как картинка или markdown. У
  локального проекта байты читаются тем же путём, что и медиа, то есть и через агента устройства.
- **Редактор звука** — версия «в MIDI» (результат операции «в MIDI»): у неё нет основного звука, но
  есть файл роли `midi` (`midiFileOf` в `features/audioEditor/thread/model.ts`). Такая версия
  показывает ноты прямо в карточке, «Развернуть» открывает их крупно.

Один компонент `MidiEditor` на оба места (`variant: 'inline' | 'full'`); модуль «Звук» получает его из
`shell-kit`. Без флага всё как раньше: в файлах `.mid` — бинарник, в звуке — строка со скачиванием.
**В редакторе звука нужны оба флага** — `audio-editor` и `midi-editor`.

## Устройство

- **Разбор** — `@tonejs/midi` (`midiModel.ts`): плоская модель без React и без Tone.js, дорожки без
  нот отбрасываются, темп и размер — первые из файла (по умолчанию 120 BPM и 4/4).
- **Звук** — Tone.js (`midiPlayer.ts`). Грузится **динамическим `import('tone')` по первому нажатию
  «Играть»**: в основной бандл и в кит не попадает. `AudioContext` запускается `Tone.start()` из жеста
  клика, а не при монтировании.
- **Синтез без саундфонтов** (`synthBank.ts`): GM-программа дорожки сводится к семейству, у семейства
  простой тембр — piano/keys на треугольной волне, strings/pad на пиле с фильтром, brass/lead на
  квадрате, bass на синусе октавой ниже; не больше 32 голосов. Ударные (канал 10): бочка (ноты 35, 36)
  — `MembraneSynth`, остальное — шум `NoiseSynth`. Сетевых семплов нет.
- **Один плеер на страницу**: Transport у Tone один, поэтому стор «кто играет» модульный — старт
  второго просмотрщика останавливает первый, размонтирование гасит свой звук и синты.
- **На iPhone** звук глушится аппаратным беззвучным режимом — это не баг, подсказка стоит на кнопке
  «Играть».

## Инварианты, которые легко сломать

- **Статического `import 'tone'` нет нигде**: в `midiPlayer.ts` и `synthBank.ts` — только
  `import type`, сам Tone приходит параметром. Обычный импорт утащит Tone.js в основной чанк.
- **Экспорт `MidiEditor` из `shell-kit` ленивый** (`React.lazy`) — иначе `@tonejs/midi` и нотная лента
  едут в чанк кита.
- **Цвета нотной ленты — только токены `C.*`** (и `GROUP_COLORS` для дорожек). Canvas CSS-переменные
  сам не читает: значения снимаются через `getComputedStyle`, и лента перерисовывается по
  `subscribeThemeMode` при смене темы.

## Чего нет в этой поставке

Правка нот и сохранение (новой версией в звуке, перезаписью файла в проекте), смена инструмента
дорожки, сборка в WAV, правка у локальных проектов — этапы 2–4 из разреза Александра (карточка
`ca9cc8d8-fef7-4025-950b-b58586697f27`). Макет будущей правки — `docs/mockups/midi-editor-v1.html` и
`midi-editor-v1-proposal.md` (на 2026-10-02 лежат в общем дереве, в git ещё не добавлены).
