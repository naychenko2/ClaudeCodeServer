Тумблер «Не сохранять решения из этого чата»

Настройка чата, которая исключает его из истории решений: записи не появятся в панели у файла и не уедут в репозиторий. Живёт в двух местах, как «Время жизни»: пилюля в пустом чате и кнопка в шапке начатого. Все тексты — из согласованной текстовой заметки. Переключатель темы — выше.

1. Пустой чат: пилюля в ряду настроек

Рядом с «Моделью», «Усилием» и «Временем жизни» появляется четвёртая пилюля — История решений. Показывается только у проектных чатов (как пилюля «Теги»): личные чаты в историю решений не пишутся в принципе, настройка там лишняя. Клик раскрывает инлайн-карточку с тумблером — тот же паттерн, что у «Времени жизни».

Не сохранять решения из этого чата

Записи из этого чата не попадут в историю решений и не уедут в репозиторий.

Пилюля — pill() NewChatSetup: иконка accent 15px (lucide history), подпись 9.5px uppercase C.textMuted, значение 13px/600 C.textHeading. Значение по умолчанию — «Сохраняются»: дефолт продукта — решения пишутся, выключатель читается как исключение. Карточка — C.bgWhite + R.xl + SHADOW.card, ширина 380. Тумблер — Toggle из ui. Пунктир — маркер «новый элемент», в продукте его нет.

2. Состояния тумблера

Формулировка через «не сохранять», а не «сохранять»: дефолт — записи ведутся, поэтому включённый тумблер должен читаться как осознанное исключение. Подсказка под строкой не меняется от состояния — она объясняет настройку, а не статус.

Включён — чат исключён из истории

Уже записанные решения останутся в истории — настройка действует на новые записи.

Трек C.accent, бегунок справа. Пилюля: «Не сохраняются». Сноска про уже записанное появляется только во включённом состоянии — снимает главный страх «а что со старыми записями?».

3. Начатый чат: кнопка в шапке

Пилюли NewChatSetup доступны только до первого сообщения — начатому чату настройка нужна в шапке. Кнопка повторяет паттерн ExpiryButton: иконка открывает поповер Menu с тем же блоком тумблера. Когда чат исключён, кнопка становится обведённой пилюлей — как у временного чата, но иконка в accent: режим считывается с места, не открывая поповер.

4. Как человек понимает, что чат не пишется

Два спокойных сигнала, ни один не кричит. Первый — обведённая пилюля в шапке (раздел 3.1). Второй — заметка в панели «История решений» у файла: если человек пришёл сюда из чата-исключения и удивляется пустоте, панель сама объясняет почему. Заметка нейтральная, не C.warning: это выбранный человеком режим, а не неполадка.

История решений
Решения из этого чата не сохраняются. Изменить можно в шапке чата — кнопка с иконкой истории.
Записей пока нет
Из других чатов решения по этому файлу появятся здесь после первого коммита.

Заметка — первым блоком тела панели: карточка C.bgCard + C.borderLight + R.lg, иконка accent, текст 11.5px C.textSecondary. Показывается, только когда панель открыта из чата с включённым «не сохранять»; в остальных случаях панель не меняется.

Почему не бейдж в списке чатов и не тост: исключение из истории — тихий фоновый режим, как «временный чат» до появления ExpiryButton. Человеку достаточно увидеть его там, где он с этим режимом сталкивается: в шапке своего чата и в панели, где он ждёт записи. Бейдж в списке чатов превратил бы редкую настройку в перманентный шум для всех чатов.

Tooltip кнопки в шапке дублирует состояние словами: «Решения этого чата не сохраняются. Нажмите, чтобы изменить.» — для скринридера и наведения.
