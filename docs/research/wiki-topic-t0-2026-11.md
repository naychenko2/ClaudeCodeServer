`BaselineK1 = 0,404` — K1 вики при `MinScore = 11`. K2 = 0 — правда корпуса: 715 вхождений `[[…]]`, все ведут на карточки источников. `ConnectivityOk` ночи: K1 новых страниц ≥ `BaselineK1` − 0,10.

## Воспроизведение боевым кодом (после A6-1)

Первый замер QA-1 дал K1 = 0,567: индекс «По теме» строился глобально, а T0 считал по разделу. После правки (индекс по видимым разделам страницы, как при показе) бенч на той же копии: **K1 = 0,4036** (0,404 ± 0,0005), K0 = 0,0623, доля «По теме» при индексе по разделу 0,484 против 0,739 при глобальном. Время замера на 337 страницах — ≈ 11 с (холодный проход ≈ 19 с).

## Оговорки

- N и df считаются по всем страницам видимых разделов, включая карточки источников (38 % корпуса): шкала оценок сдвинута вверх относительно «только знания»; при смене состава индекса пороги перемерить.
- Точность измерена на парах одного раздела, не между проектами; живой интерфейс замером не проверялся.
