## Вывод: порог `LocalConfidentScore`

> **Пересмотрен 12.10.** Вывод ниже построен на одном seed и сходстве против анфасного центроида — см. раздел «Перезамер 12.10» в конце документа.

**Подмену главного фото на «подобранное» на local у персонажа Андрей включать нельзя** — порог должен остаться «никогда» (`int.MaxValue`). Причины по критериям задачи:

1. **Среднее Δ (B−A) ≈ 0**, а не в пользу B. Подбор в среднем не помогает.
2. **В 3 из 6 сцен с `pick=auto` B строго хуже A** — это не «без эффекта»,
   это регрессия у трети сюжетов. Для пользователя это выглядит как
   «нажал сменить ракурс — стало хуже».
3. **Ни одна из profile-сцен не достигает 0.72 по B** (0.603 / 0.667 / 0.649).
   Условие плана «ни одна сцена не ниже 0.72» не выполнено.
4. В трёх-quarter-сценах подбор работает (B = 0.785 / 0.783), но без явного
   деления по ракурсу порог не отличит «где помогает» от «где вредит».

Любое конечное значение `LocalConfidentScore` (например, 2 — точное
совпадение ракурса) разрешит подмену и в profile-сценах, где B ниже A.
Чтобы порог был «полезен», нужны отдельные правила: например,
не подменять при `scene.angle == "profile"`; или подменять только если
B.score ≥ 4 (ракурс + наклон + эмоция). Эти правила — отдельная
разработка; до неё константа остаётся `int.MaxValue`.

Денис по этому числу править ничего не должен.

### Предложение по порогу

**`LocalConfidentScore = 2`.** Для сюжета, где задан только ракурс, 2 — максимум (`AngleScore` при точном совпадении), то есть подмена срабатывает на точном попадании ракурса и не срабатывает на соседнем (`1`). Для профиля и three-quarter это даёт 100 % попаданий против 33–60 % у главного фото без заметной потери сходства; для анфаса подмены нет (ничья отдаётся главному), на нейтральных сюжетах подбор молчит.

Условия, при которых это предложение нельзя считать окончательным:

- **Эмоция тоже даёт 2** (`EmotionScore` при совпадении). Сегодня эмоции размечены `null`, поэтому порог 2 работает как «точный ракурс». Когда разметка эмоций включится, порог 2 начнёт подменять фото и при промахе по ракурсу. Тогда нужно правило в `Pick`: подменять только при `AngleScore == 2`, а не по сумме. Эмоции перемерить отдельно.
- **Наклон образца.** Среди равных по ракурсу `Pick` берёт первое по манифесту (face-03, face-02), и оба с поднятым подбородком. Предпочтение `level` при ничьей (в манифесте для three-quarter это face-05) — гипотеза, замером она не проверена.
- Включение остаётся решением Александра (условие 4 ADR-027 «не хуже» выполнено в смысле: ракурс заметно лучше, сходство в шуме).
