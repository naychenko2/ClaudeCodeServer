# Редизайн раздела «Поставщики моделей»

## Проблема
Сегодня весь раздел — одна модалка (`ModelProvidersModal.tsx`, 963 строки) с тремя
уровнями подряд: провайдеры → слоты по умолчанию → таблица «Кто что выполняет».
Уже тесно. Функциональная спека (`docs/features/model-providers-rework.md`,
блоки A–G) добавляет:

- **специальности** — 12 функциональных ролей персон, три новые прямо для
  исполнителей (универсальный / бэкенд / фронтенд), у каждой — модель по
  умолчанию (глобально + личный override) и шаблон прав/инструментов;
- **правила выбора модели** — вместо одной модели теперь три формата значения
  в каждом месте: конкретная модель, именованный пресет правил, своя цепочка
  фолбэка (до 5 записей) — и это касается ВСЕХ мест: слотов, специальностей,
  персон, задач, таблицы «Кто что выполняет»;
- **именованные пресеты правил** — их надо где-то заводить, переименовывать,
  удалять;
- **видимость подмены модели в ленте чата** — новый паттерн сообщения.

Один плоский экран это уже не выдержит: либо навигация уезжает вглубь, либо
раздел перестаёт быть модалкой. Три макета ниже — три разных ответа на вопрос
«как разложить это по уровням», не три косметических темы одного и того же.

## Три варианта

### A — «Вкладки» (`variant-a-tabs.html`)
Остаёмся в модалке (`MODAL_W.wide`), но уровни расходятся по горизонтальным
вкладкам: Провайдеры · Специальности · Пресеты правил · Применение. Внутри
вкладки — аккордеон: строка специальности/действия разворачивается на месте,
без ухода на отдельный экран. Минимальное расстояние с сегодняшним кодом —
структура `Modal` та же, добавляется `SegmentedControl` сверху и разворот
внутри строк вместо второго попапа.

**Плюс:** дешёвая миграция кода, всё видно на одном экране без «проваливаний».
**Минус:** при большом количестве специальностей (12) и пресетов вкладка
превращается в длинный скролл — глубина не помогает.

### B — «Хаб-раздел» (`variant-b-hub.html`)
Уходим из модалки в полноценный раздел по «Рецепту нового раздела» из гайда:
`CanvasBackdrop` + `IslandScaffold` (сайдбар со списком уровней + центр с
содержимым выбранного). Специальности и пресеты получают место как у
`KnowledgePage`/`PersonasPage` — списки со своей карточкой в центре, а не
попапом внутри попапа.

**Плюс:** единственный вариант, где 12 специальностей и растущий список
пресетов не давят на модалку; открывается прямой линк на раздел.
**Минус:** самая большая миграция — новый маршрут, новый пункт хаб-навигации,
своя мобильная раскладка `list | item`.

### C — «Мастер вглубь» (`variant-c-drilldown.html`)
Модалка остаётся компактной (`MODAL_W.form`), но без вкладок: главный экран —
список групп-карточек (как в `persona-tool-picker-v1`), клик по любой
проваливается на следующий «слой» с хлебной крошкой назад. Один уровень
видим одновременно — что на десктопе, что на мобиле работает одинаково,
шторка ничего не меняет в логике.

**Плюс:** самый понятный на мобиле (уже привычный паттерн шторки), не
требует нового маршрута.
**Минус:** больше кликов до цели у опытного пользователя — сравнить два
пресета друг с другом занимает два прохода туда-обратно.

## Что показано в каждом варианте (блоки A–G)
- Список специальностей (12, три новые — с бейджем «новая»);
- модель по умолчанию для специальности: глобально + личный override;
- подстановка шаблона прав/инструментов при выборе специальности с
  индикатором «изменено вручную» и кнопкой возврата к шаблону;
- единый контрол выбора модели: конкретная модель / именованный пресет /
  своя цепочка (редактор до 5 записей, drag-порядок, потолок явно виден);
- управление именованными пресетами (список, создание, дублирование,
  удаление);
- таблица «Кто что выполняет» на новом контроле;
- превью ленты чата: «Ответила GLM-4.7 — Opus была недоступна» (подмена
  посреди уже начатого ответа) и переиспользованная пометка «Продолжено на
  подписке «…»» — стиль подписи взят один в один из `ChatItemView.tsx`
  (центрированная пилюля с двумя чертами по бокам), новая подмена оформлена
  тем же паттерном, но с warning-тоном — это подмена модели, а не миграция
  всего чата.

Все три — светлая/тёмная тема (кнопка в шапке) и мобильная раскладка (кнопка
«Мобильная раскладка 390px», плюс реальные `@media` для честного узкого окна).
