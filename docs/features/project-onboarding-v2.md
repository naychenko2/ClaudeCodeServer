## Критерии снятия флага

Флаг снимаем, когда выполнено всё:

1. **Каркас чаще принимают, чем отвергают.** Метрика `ccs.intro.preset_applied`
   (`ServerMetrics.RecordPresetApplied`) с тегом `reason`: доля `reason=none` меньше
   половины на выборке от 10 знакомств. Больше половины — значит каркас людям не нужен
   в предложенном виде, и снимать флаг нельзя, надо чинить состав.
2. **Живут все три пресета.** Каждый из `docs` / `dev` / `personal` выбран хотя бы раз.
   Мёртвый пресет убираем из каталога, а не тащим в общий выпуск.
3. **Ни одной перезаписи чужого файла.** В отчётах применения существующие файлы
   попадают в `skipped`, а не в `created`; жалоб на затёртый `CLAUDE.md` нет.
4. **QA-прогон без блокеров**, включая отказ, повторный клик (409) и проект,
   созданный до фичи (каркас не предлагается).

Пока хоть один пункт не выполнен — флаг остаётся, фича доступна по приглашению.
